## Розділ 1. Унарні та бінарні оператори

* **Унарні оператори (1 операнд):**
  * `+x` (унарний плюс) ➔ швидке перетворення рядка на число: `+"10"` ➔ `10`.
  * `-x` (унарний мінус) ➔ зміна знаку: `-(-5)` ➔ `5`.
  * `!x` (логічне заперечення) ➔ `!true` ➔ `false`.
  * `++`, `--` ➔ інкремент/декремент.
* **Бінарні оператори (2 операнди):** `+`, `-`, `*`, `/`, `%`, `**`.
* **Оператор присвоювання (`=`):** записує значення справа у коробку зліва.

## Розділ 2. Привиди та дивацтва JS

```javascript
let a;
console.log(a);        // undefined (немає значення)
console.log(typeof a); // "undefined"

let user = null;
console.log(user);     // null (навмисна порожнеча)
console.log(typeof user); // "object" (баг 1995 року!)

let calc = "Привіт" * 3;
console.log(calc);        // NaN (Not-a-Number)
console.log(typeof calc); // "number"
console.log(NaN === NaN); // false!
console.log(Number.isNaN(calc)); // true
```

## Розділ 3. Турнір «Битва прогнозів» (12 раундів)

| № | Рядок коду | Результат | Пояснення принципу |
| :-: | :--- | :--- | :--- |
| **1** | `console.log(+"25");` | `25 (number)` | Унарний плюс зводить до числа. |
| **2** | `console.log(+"Hello");` | `NaN` | Текст не можна привести до числа. |
| **3** | `console.log(typeof (+"25"));` | `"number"` | Тип результату — number. |
| **4** | `console.log(-(-10));` | `10` | Зміна знаку на протилежний. |
| **5** | `console.log(!true);` | `false` | Логічне NOT. |
| **6** | `console.log(10 + "5");` | `"105"` | Плюс склеює з рядком. |
| **7** | `console.log(10 + (+"5"));` | `15` | Плюс спочатку перетворив рядок на 5. |
| **8** | `console.log(typeof null);` | `"object"` | Баг 1995 року. |
| **9** | `console.log(typeof undefined);` | `"undefined"` | Рядок "undefined". |
| **10** | `console.log(typeof NaN);` | `"number"` | За стандартом IEEE-754 це number. |
| **11** | `console.log("20" - 5);` | `15` | Мінус примусово робить рядок числом. |
| **12** | `console.log(typeof (typeof 10));` | `"string"` | `typeof 10` дає `"number"`, а його тип — `string`. |
