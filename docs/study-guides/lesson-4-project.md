## Розділ 1. Теорія: Розгалуження та тернарний вираз

```javascript
let age = 17;
let access;

// Класичний if / else
if (age >= 18) {
  access = "Доступ дозволено";
} else {
  access = "Доступ обмежено";
}

// Лаконічний тернарний оператор
let accessCompact = (age >= 18) ? "Доступ дозволено" : "Доступ обмежено";
```

## Розділ 2. Практичний проєкт «Профіль користувача»

```javascript
const name = "Alex";
const age = 17;
const city = "Kyiv";
const isStudent = true;

// Тернарний вираз для статусу:
const statusText = isStudent ? "Студент денної форми" : "Не студент";

console.log(`Ім'я: ${name}\nВік: ${age}\nМісто: ${city}\nСтатус: ${statusText}`);
```

## Розділ 3. Лабораторний баг-фіксинг

```javascript
// Зламаний код:
// Const user-score = "100";
// let bonus = 50;
// user-score = user-score + bonus;

// Виправлений професійний код:
let userScore = 100;
const bonus = 50;
userScore += bonus;
console.log("Рахунок: " + userScore); // 150
```

## Розділ 4. Битва з кодом (A / B / C)

1. `console.log("10" + 20);` ➔ **"1020"** (плюс склеює).
2. `console.log("20" - 10);` ➔ **10 (число)** (мінус конвертує).
3. `console.log((16 >= 18) ? "Так" : "Ні");` ➔ **"Ні"**.
4. `let s = 10; s += 5; console.log(s);` ➔ **15**.
5. `console.log(typeof (+"42"));` ➔ **"number"**.
6. `console.log(2 + 2 * 2);` ➔ **6**.
7. `console.log(typeof null);` ➔ **"object"**.
8. `console.log(true + true);` ➔ **2** ($1 + 1 = 2$).
