## Розділ 1. Рядки проти чисел

```javascript
console.log(5 + 5);     // 10 (число)
console.log("5" + "5"); // "55" (рядок)
console.log("5" + 5);   // "55" (рядок: неявна конкатенація)
```

## Розділ 2. Скорочені форми та інкремент

* `x += 5;` ➔ `x = x + 5;`
* `x -= 3;` ➔ `x = x - 3;`
* `x *= 2;` ➔ `x = x * 2;`
* `x /= 4;` ➔ `x = x / 4;`
* `x %= 2;` ➔ залишок від ділення
* `++x` (префіксний) ➔ спочатку збільшує, потім повертає.
* `x++` (постфіксний) ➔ спочатку повертає, потім збільшує.

## Розділ 3. Таблиця пріоритетів операторів

1. **Групування:** `( ... )` (найвищий пріоритет)
2. **Унарні:** `typeof`, `+x`, `-x`, `!x`, `++`, `--`
3. **Множення, ділення, остача:** `*`, `/`, `%`, `**`
4. **Додавання та віднімання:** `+`, `-`
5. **Порівняння:** `>`, `<`, `>=`, `<=`, `===`, `!==`
6. **Присвоювання:** `=`, `+=`, `-=`, `*=` (найнижчий пріоритет)

## Розділ 4. Практикум «Чек у кафе зі знижкою»

```javascript
const pizzaPrice = 180;
let pizzaCount = 2;
const colaPrice = 40;
let colaCount = 3;

let total = (pizzaPrice * pizzaCount) + (colaPrice * colaCount); // 360 + 120 = 480
total -= 50; // застосували купон на знижку (скорочена форма)
console.log("До сплати: " + total + " грн"); // 430 грн
```
