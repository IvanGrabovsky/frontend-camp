## Розділ 1. Що таке змінна та природа даних

> 💡 **Інтуїція та аналогія:**  
> *Змінна — це іменована коробка в оперативній пам'яті комп'ютера, на яку наклеєно стікер з назвою (ідентифікатор), а всередині зберігаються дані.*  
> *У сучасному JS є два ключові слова: `let` (коробка, вміст якої можна міняти) та `const` (запечатана коробка, значення якої заборонено змінювати). Застарілий `var` більше не використовується через баги видимості та hoisting.*

### Академічна теорія:
1. **Цілі та речовинні числа (IEEE-754):** Усі числа належать до єдиного типу `number`.
2. **Безпечний діапазон:** Від `Number.MIN_SAFE_INTEGER` до `Number.MAX_SAFE_INTEGER` ($2^{53}-1$).
3. **Відсутність char:** Будь-який окремий символ (наприклад, `"A"`) — це звичайний рядок (`string`) довжиною 1.
4. **Логічний тип (boolean):** Тільки `true` або `false`.

## Розділ 2. Класифікація трьох типів помилок

| Тип помилки | Характеристика | Приклад у коді |
| :--- | :--- | :--- |
| **1. SyntaxError** | Порушено правила граматики. Код взагалі не стартує. | `let 1player = "Ivan";` |
| **2. TypeError / Runtime** | Код синтаксично правильний, але впав під час неприпустимої дії. | `const city = "Lviv"; city = "Kyiv";` |
| **3. Logical Error** | Код працює без виключень, але бізнес-результат хибний. | `"50" + 100` дає `"50100"` замість `150` |

## Розділ 3. Практикум: «Паспорт розробника»

```javascript
const firstName = "Ivan";     // string
const symbolTest = "A";       // string (у JS немає окремого char!)
let age = 17;                 // number
let height = 1.78;            // number
let isStudent = true;         // boolean

console.log("Ім'я: " + firstName + " | тип: " + typeof firstName);
console.log("Вік: " + age + " | тип: " + typeof age);
console.log("Зріст: " + height + " | тип: " + typeof height);
console.log("Студент: " + isStudent + " | тип: " + typeof isStudent);
```

## Розділ 4. Бліц-самоперевірка (10 питань)

1. Чи є в JS окремий тип float? ➔ **Ні, єдиний тип number.**
2. Який тип має один символ `"$"`? ➔ **string.**
3. `let user-name = "Max";` — яка це помилка? ➔ **SyntaxError (дефіс сприймається як мінус).**
4. `const a = 10; a = 20;` — яка це помилка? ➔ **TypeError (перезапис константи).**
5. Хотіли порахувати площу, але написали $S = a + b$. Що це? ➔ **Logical Error.**
6. Що поверне `typeof (10 > 5)`? ➔ **"boolean".**
7. Як назвати змінну для максимальної кількості спроб? ➔ **maxAttemptsCount.**
8. Що поверне `typeof Number.MAX_SAFE_INTEGER`? ➔ **"number".**
9. Що виведе `let x; console.log(typeof x);`? ➔ **"undefined".**
10. Яка різниця між `"false"` та `false`? ➔ **Перше — рядок, друге — boolean.**
