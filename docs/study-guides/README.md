# 📚 Навчальні матеріали та посібники · Frontend Camp

У цій директорії зібрано повний комплект навчальних посібників, прикладів коду та інтерактивних практикумів для опанування модуля **«Змінні, типи даних та оператори у JavaScript»**.

---

## 📑 Зміст уроків:

1. **[Урок 1: Змінні, типи даних та класифікація помилок](./lesson-1-variables.md)**
   * Аналогія коробок оперативної пам'яті.
   * `let` / `const` vs застарілий `var`.
   * Стандарти чисел IEEE-754, безпечні діапазони, відсутність типу `char`.
   * Правила стилю `camelCase`.
   * Класифікація помилок: `SyntaxError` vs `TypeError` vs `Logical Error`.
   * Блок-схеми та практикум «Паспорт розробника».

2. **[Урок 2: Унарні та бінарні оператори, таємниці типів](./lesson-2-data-types.md)**
   * Класифікація за кількістю операндів (унарні vs бінарні).
   * Чарівний унарний плюс `+x` для приведення до числа.
   * Неявне зведення типів (*Type Coercion*).
   * Особливості JS: `undefined` vs `null`, монстр `NaN`, баг `typeof null === "object"` 1995 року.
   * Турнір «Битва прогнозів» на 12 раундів.

3. **[Урок 3: Арифметичні оператори, скорочені форми та пріоритети](./lesson-3-values.md)**
   * Конкатенація рядків vs додавання чисел.
   * Скорочені форми присвоювання (`+=`, `-=`, `*=`, `/=`, `%=`).
   * Префіксний та постфіксний інкремент (`++x` vs `x++`).
   * Офіційна таблиця пріоритетів дій (Precedence & Associativity).
   * Практикум: розрахунок чека кафе зі знижкою.

4. **[Урок 4: Практичний проєкт, розгалуження та тернарний оператор](./lesson-4-project.md)**
   * Розгалуження `if / else if / else`.
   * Тернарний оператор `?:`.
   * Багатоваріантний вибір `switch / case`.
   * Матриця Falsy vs Truthy.
   * Підсумковий курсовий проєкт: «Термінал замовлень CyberStore».
   * Лабораторний баг-фіксинг та самоперевірка «A / B / C».
