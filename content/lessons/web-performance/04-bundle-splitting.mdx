<Callout type="warning" title="Ціна великого JS бандлу">
  Бандл розміром 1 МБ у стисненому вигляді перетворюється на 4-5 МБ розпакованого коду, що може заблокувати головний потік (Main Thread) на мобільних пристроях на кілька секунд (руйнуючи показник INP).
</Callout>

<section>
  <h2>1. Динамічні імпорти (Dynamic Imports)</h2>
  <p>
    Замість статичного <code>import Modal from './Modal'</code>, який включає весь важкий код у головний чанк, ми завантажуємо модулі за вимогою:
  </p>

```typescript
// React.lazy та dynamic у Next.js
import dynamic from 'next/dynamic';

const HeavyChart = dynamic(() => import('@/components/HeavyChart'), {
  loading: () => <p>Завантаження графіка...</p>,
  ssr: false, // Якщо компонент потрібен тільки в браузері
});
```

  <h2>2. Деревовидалення (Tree Shaking)</h2>
  <p>
    Сучасні збирачі (Webpack, Turbopack, Rollup, Vite) автоматично видаляють невикористовуваний dead code за умови використання ES-модулів (<code>import / export</code>):
  </p>

```typescript
// ❌ Погано: затягує всю бібліотеку (деревоподібне видалення ускладнене)
import _ from 'lodash';

// ✅ Чудово: імпортуємо тільки потрібний метод або використовуємо lodash-es
import debounce from 'lodash-es/debounce';
```

  <h2>3. Аналіз бандлу (Bundle Analyzer)</h2>
