<Callout type="pro" title="Формати нового покоління: AVIF & WebP">
  Формат <strong>AVIF</strong> забезпечує на 50% кращу компресію, ніж традиційний JPEG, та на 20-30% кращу, ніж WebP, зберігаючи високу чіткість деталей.
</Callout>

<section>
  <h2>1. Тег `&lt;picture&gt;` та прогресивне завантаження</h2>

```html
<picture>
  <!-- 1. Найновіший та найефективніший формат -->
  <source srcset="/hero.avif" type="image/avif" />
  <!-- 2. Сучасний WebP з відмінною підтримкою -->
  <source srcset="/hero.webp" type="image/webp" />
  <!-- 3. Fallback для старих браузерів -->
  <img
    src="/hero.jpg"
    alt="Frontend Camp Banner"
    width="1200"
    height="600"
    loading="lazy"
    decoding="async"
  />
</picture>
```

  <h2>2. Боротьба з Layout Shifts (CLS)</h2>
  <p>
    Завжди вказуйте атрибути <code>width</code> та <code>height</code> (або CSS <code>aspect-ratio</code>) для кожного зображення! Це дозволяє браузеру заздалегідь виділити точне місце в макеті до завантаження байтів картинки.
  </p>

  <h2>3. Оптимізація веб-шрифтів</h2>
  <ul>
    <li><code>font-display: swap</code> — негайно показує системний шрифт, поки кастомний вантажиться (запобігає FOIT — Flash of Invisible Text).</li>
    <li><strong>Підмножини (Subsetting):</strong> завантажуйте лише потрібні гліфи (наприклад, тільки <code>latin + cyrillic</code>), вилучаючи непотрібні символи.</li>
    <li><strong>Preload ключового шрифту:</strong> <code>&lt;link rel="preload" href="/fonts/inter.woff2" as="font" type="font/woff2" crossorigin&gt;</code>.</li>
  </ul>

  const totalJpegGb = (jpegSizeKb * visitorsPerMonth) / (1024 * 1024);

  };
}
