      <p><strong>Змінна</strong> — це іменоване місце в пам'яті, де зберігається значення. JavaScript має три способи оголосити змінну: `var` (застарілий), `let` (для значень що змінюються) і `const` (для констант).</p>
      <p><strong>Тип даних</strong> визначає що може зберігатись у змінній: число, рядок, булеве значення, `null`, `undefined`, об'єкт, або `Symbol`.</p>

      <p>Змінна — як підписана коробка. `const` — запаяна коробка (не можна змінити вміст). `let` — відкрита коробка (вміст можна замінити). Тип даних — це те що всередині: число, текст, або «нічого» (`null`).</p>
    </section>

    <section>
      <h2>let та const</h2>
      

```javascript
// const — значення не змінюється (рекомендований за замовчуванням)
const name = 'Іван';
const age  = 25;
const PI   = 3.14159;

// let — значення може змінитись
let score = 0;
score = 10;   // OK
score += 5;   // OK → 15

// ❌ const — не можна перевизначити
const MAX = 100;
MAX = 200; // TypeError: Assignment to constant variable
```



      <h2>Типи даних</h2>
      

```javascript
// Примітивні типи
const str  = 'Привіт, світе!';   // string
const num  = 42;                  // number
const big  = 9007199254740993n;   // bigint
const bool = true;                // boolean
const empty = null;               // null — навмисна відсутність

const id = Symbol('unique');      // symbol

// typeof — визначити тип
typeof 'text'   // 'string'
typeof 42       // 'number'
typeof true     // 'boolean'
typeof null     // 'object' ← відома помилка JS!
typeof undefined // 'undefined'

// Template literals — рядки з виразами
const greeting = `Привіт, ${name}! Тобі ${age} років.`;
const multiline = `
  Рядок перший
  Рядок другий
`;
```

      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Використовувати `var`</strong>: function-scope і hoisting створюють несподівані баги. Завжди використовуй `const`/`let`.</li>
        <li><strong>Плутати `null` і `undefined`</strong>: `null` — ти навмисно встановив «нічого». `undefined` — значення ще не задано.</li>
        <li><strong>`typeof null === 'object'`</strong>: відома помилка JS з 1995 року. Для перевірки null використовуй `=== null`.</li>
        <li><strong>Перевизначати `const` об'єкти</strong>: `const arr = []` — не можна змінити <em>посилання</em> на масив, але можна змінювати його <em>вміст</em>: `arr.push(1)` — це OK.</li>
      </ul>

          <p className="hw-review-item__good"><span className="hw-review-label">✅</span> `const`/`let` — block scope (видимі тільки в межах блоку `{}`). `var` — function scope і hoisting (підіймається на початок функції зі значенням `undefined`). `const` не дозволяє перевизначення (але мутацію об'єктів — дозволяє).         <li>Nullish coalescing: `const val = input ?? 'default'` — повертає `'default'` тільки якщо `input` є `null` або `undefined` (не `0` або `''`).</li>
