# 04. Змінні та типи даних

<article className="lesson-card">
  <h2>Що таке змінна та типи даних?</h2>
  <p><strong>Змінна</strong> — це іменована комірка в оперативній пам'яті комп'ютера (RAM), яка зберігає певне значення під час роботи програми. JavaScript має три способи оголошення змінних: сучасні <code>const</code> (для констант) і <code>let</code> (для значень, що змінюються), а також застарілий <code>var</code> (який не рекомендується використовувати у сучасному коді).</p>
  <p><strong>Тип даних</strong> визначає природу інформації, що зберігається: число (<code>number</code>), текстовий рядок (<code>string</code>), логічне значення (<code>boolean</code>), навмисна порожнеча (<code>null</code>), невизначений стан (<code>undefined</code>), великі цілі числа (<code>bigint</code>), унікальні ідентифікатори (<code>symbol</code>) або складні структури (<code>object</code>).</p>
</article>

<section className="analogy-block">
  <div className="analogy-block__title"><span className="analogy-block__icon">📦</span> Аналогія: Коробки з підписами на складі пам'яті</div>
  <p>Уявіть оперативну пам'ять комп'ютера як гігантський поштовий склад:</p>
  <ul>
    <li><strong>Ідентифікатор (назва змінної)</strong> — це яскрава наклейка на коробці (наприклад, <code>playerName</code>).</li>
    <li><strong><code>const</code></strong> — це запечатана металева коробка із замком: поклавши туди значення один раз, замінити його неможливо.</li>
    <li><strong><code>let</code></strong> — це відкрита картонна коробка: вміст можна діставати й класти новий будь-яку кількість разів.</li>
    <li><strong>Значення та тип</strong> — це сам предмет усередині коробки (числове табло, роздрукований текст або пустий простір).</li>
  </ul>
</section>

<section>
  <h2>Оголошення змінних: const проти let проти var</h2>

```javascript
// 1. const — безпечне значення за замовчуванням (неможливо переприсвоїти)
const maxLives = 3;
const serverUrl = "https://api.frontendcamp.dev";
const pi = 3.14159;

// 2. let — значення, яке змінюється у ході алгоритму
let currentScore = 0;
currentScore += 10; // OK: рахунок збільшився до 10
currentScore = 25;  // OK: перезапис значення

// ❌ Спроба перезаписати const викличе помилку виконання:
// maxLives = 5; // TypeError: Assignment to constant variable.
```

  <Callout type="tip" title="Золоте правило професійного розробника">
    Завжди починайте оголошення будь-якої змінної з <code>const</code>. Якщо далі в алгоритмі виникає реальна необхідність змінити значення — лише тоді змінюйте на <code>let</code>. Це запобігає випадковим мутаціям даних і робить код передбачуваним.
  </Callout>

  <h2>Правила іменування змінних (Code Style)</h2>
  <ul>
    <li><strong>Стандарт вебу:</strong> стиль <code>camelCase</code> (перше слово з малої літери, кожне наступне — з великої: <code>userProfileAge</code>, <code>totalOrderPrice</code>).</li>
    <li><strong>Заборонено:</strong> починати назву з цифри (<code>let 1player;</code> ❌), використовувати дефіси чи пробіли (<code>let user-name;</code> ❌ — дефіс сприймається як знак мінуса), використовувати зарезервовані слова (<code>let class;</code> ❌).</li>
    <li><strong>Самодокументованість:</strong> уникайте однолітерних назв (<code>let a = 10;</code> ❌) на користь зрозумілих (<code>let remainingAttempts = 10;</code> ✅).</li>
  </ul>

  <h2>Система типів даних у JavaScript</h2>

```javascript
// 1. number — єдиний числовий тип (цілі та дробові числа IEEE-754)
const age = 17;
const price = 299.99;
const negative = -42;

// 2. string — текст будь-якої довжини (окремого типу char у JS НЕМАЄ!)
const userName = "Олексій";
const singleChar = "A"; // це також звичайний рядок довжиною 1

// 3. boolean — логічний перемикач
const isOnline = true;
const hasPremium = false;

// 4. undefined — змінну створено, але значення ще не присвоєно
let notAssigned; // undefined

// 5. null — усвідомлена порожнеча (розробник явно вказав "тут нічого немає")
const avatarUrl = null;

// 6. bigint — для чисел, що виходять за безпечні межі Number.MAX_SAFE_INTEGER
const giantNumber = 9007199254740993n;

// 7. symbol — унікальний примітивний ідентифікатор
const secretKey = Symbol("token");
```

  <Callout type="warning" title="Особливості чисел та відомий баг typeof null">
    <p>1. Усі числа в JS — це 64-бітні числа з плаваючою крапкою за стандартом <strong>IEEE-754</strong>. Безпечний діапазон цілих чисел обмежений <code>Number.MIN_SAFE_INTEGER</code> ($-(2^{53}-1)$) та <code>Number.MAX_SAFE_INTEGER</code> ($+(2^{53}-1)$).</p>
    <p>2. <code>typeof null === "object"</code> — це історичний баг мови з 1995 року. Насправді <code>null</code> є повноцінним примітивом. Для перевірки на null завжди пишіть <code>value === null</code>.</p>
  </Callout>

  <h2>Шаблонні рядки (Template Literals)</h2>
  <p>Замість застарілої склейки рядків плюсом, використовуйте зворотні лапки <code>` `</code> та вирази <code>${"..."}</code>:</p>

```javascript
const studentName = "Марія";
const course = "Frontend Development";
const grade = 98;

// Сучасна інтерполяція рядків
const message = `Студент ${studentName} успішно завершив модуль "${course}" з результатом ${grade}%!`;
console.log(message);
```
