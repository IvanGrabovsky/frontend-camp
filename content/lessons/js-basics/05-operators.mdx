# 05. Оператори, вирази та таємниці зведення типів

<article className="lesson-card">
  <h2>Що таке оператори та вирази?</h2>
  <p><strong>Оператор</strong> — це спеціальний знак або ключове слово, яке виконує операцію над одним чи кількома значеннями (<strong>операндами</strong>). Вираз (<code>expression</code>) — це будь-яка комбінація змінних, констант та операторів, яка обчислюється рушієм у єдине результуюче значення.</p>
  <p>Усі оператори поділяються за кількістю учасників на <strong>унарні</strong> (1 операнд) та <strong>бінарні</strong> (2 операнди). Розуміння неявного зведення типів (<em>Type Coercion</em>), пріоритетів дій та суворого порівняння (<code>===</code>) рятує від 90% типових багів початківців.</p>
</article>

<section className="analogy-block">
  <div className="analogy-block__title"><span className="analogy-block__icon">⚖️</span> Аналогія: Оператори як судді та правила гри</div>
  <p>Уявіть футбольний матч:</p>
  <ul>
    <li><strong>Суворе порівняння (<code>===</code>)</strong> — це строгий суддя з VAR: він перевіряє і колір форми (тип даних), і номер гравця (значення). Якщо хоч щось не сходиться — фол (<code>false</code>).</li>
    <li><strong>Нестроге порівняння (<code>==</code>)</strong> — ліберальний суддя, який намагається перевдягнути одного з гравців (неявно конвертує тип), що призводить до казусів на полі.</li>
    <li><strong>Унарний плюс (<code>+x</code>)</strong> — чарівний пропуск, який миттєво перетворює текстовий квиток <code>"42"</code> на справжнє число <code>42</code>.</li>
  </ul>
</section>

<section>
  <h2>Класифікація: Унарні та Бінарні оператори</h2>

```javascript
// 1. УНАРНІ ОПЕРАТОРИ (1 операнд)
const strNum = "42";
console.log(+strNum);       // 42 (унарний плюс: швидке зведення до number)
console.log(-(-10));        // 10 (унарний мінус: інверсія знаку)
console.log(!true);         // false (логічне заперечення NOT)
console.log(typeof 100);    // "number" (унарний оператор перевірки типу)

// 2. БІНАРНІ ОПЕРАТОРИ (2 операнди)
const sum = 10 + 5;         // 15
const product = 4 * 8;      // 32
const remainder = 10 % 3;   // 1 (залишок від ділення)
const power = 2 ** 8;       // 256 (піднесення до степеня)

// 3. ОПЕРАТОР ПРИСВОЮВАННЯ (=)
let score = 100; // значення справа записується в коробку зліва
```

  <h2>Скорочені форми присвоювання та інкремент</h2>

```javascript
let balance = 100;

balance += 50; // balance = balance + 50 (150)
balance -= 20; // balance = balance - 20 (130)
balance *= 2;  // balance = balance * 2  (260)
balance /= 4;  // balance = balance / 4  (65)

// Інкремент (++) та декремент (--)
let level = 1;
level++; // 2 (постфіксний: збільшує на 1)
++level; // 3 (префіксний: спочатку збільшує, потім повертає)
```

  <h2>Неявне зведення типів (Type Coercion) та монстр NaN</h2>
  <p>Коли ви змішуєте різні типи, JS намагається автоматично перетворити їх:</p>

```javascript
// ⚠️ Плюс поруч із рядком ПЕРЕМАГАЄ як конкатенація:
console.log("10" + 5);      // "105" (рядок!)
console.log(10 + "5");      // "105" (рядок!)
console.log(10 + 20 + "5"); // "305" (спочатку 10+20=30, потім 30+"5"="305")

// Але мінус, множення та ділення ПРИМУСОВО роблять рядок числом:
console.log("20" - 5);      // 15 (number!)
console.log("6" * "2");     // 12 (number!)

// Монстр NaN (Not-a-Number)
console.log("Привіт" * 3);  // NaN
console.log(typeof NaN);    // "number"
console.log(NaN === NaN);   // false (NaN не дорівнює нічому у світі, навіть самому собі!)
console.log(Number.isNaN(NaN)); // true (надійний спосіб перевірки)
```

  <h2>Сучасні оператори: ?? (Nullish) та ?. (Optional Chaining)</h2>

```javascript
// 1. ?? (Nullish Coalescing) — підставляє дефолтне значення ТІЛЬКИ для null або undefined
const userScore = 0;
const displayScore = userScore ?? 10; 
console.log(displayScore); // 0 (бо 0 — це дійсне число, а не null!)

// Для порівняння оператор || вважає 0 за хибне:
console.log(userScore || 10); // 10 (помилка: втратили реальний нуль!)

// 2. ?. (Optional Chaining) — безпечний доступ до вкладених полів
const user = { name: "Іван" };
console.log(user?.address?.city); // undefined (не викидає фатальну помилку TypeError)
```
