# 06. Умовні оператори, тернарний вираз та підсумковий проєкт

<article className="lesson-card">
  <h2>Що таке умовні оператори?</h2>
  <p><strong>Умовні оператори</strong> дозволяють програмі приймати рішення та обирати різні шляхи виконання алгоритму залежно від вхідних даних чи стану системи. Замість лінійного виконання код отримує розгалуження (<em>branching</em>).</p>
  <p>Основними інструментами ухвалення рішень у JavaScript є класична конструкція <code>if / else if / else</code>, компактний <strong>тернарний оператор (<code>?:</code>)</strong> та багатоваріантний вибір <code>switch / case</code>.</p>
</article>

<section className="analogy-block">
  <div className="analogy-block__title"><span className="analogy-block__icon">🚦</span> Аналогія: Розумний світлофор та турнікет</div>
  <p>Уявіть роботу електронного турнікета в метро:</p>
  <ul>
    <li><strong><code>if (hasTicket && isBalancePositive)</code></strong> — «якщо є дійсний квиток і на балансі є кошти ➔ відкрити зелений прохід».</li>
    <li><strong><code>else if (isVipPass)</code></strong> — «інакше, якщо це спеціальний службовий пропуск ➔ відкрити сервісний коридор».</li>
    <li><strong><code>else</code></strong> — «у всіх інших випадках ➔ заблокувати прохід та увімкнути червоний сигнал».</li>
    <li><strong>Тернарний оператор (<code>?:</code>)</strong> — це дисплей турнікета, який миттєво підбирає напис: <code>hasTicket ? "Ласкаво просимо!" : "Поповніть карту"</code>.</li>
  </ul>
</section>

<section>
  <h2>Конструкція if / else if / else</h2>

```javascript
const userAge = 17;
let accessStatus;

if (userAge >= 18) {
  accessStatus = "Повний доступ надано";
} else if (userAge >= 14) {
  accessStatus = "Доступ з обмеженнями (підлітковий профіль)";
} else {
  accessStatus = "Доступ заблоковано (потрібен дозвіл батьків)";
}

console.log(accessStatus);
```

  <h2>Тернарний оператор (умова ? вираз1 : вираз2)</h2>
  <p>Тернарний оператор — це єдиний оператор у JavaScript, який приймає <strong>три операнди</strong>. Він ідеально підходить для присвоєння значень у змінну в один рядок:</p>

```javascript
const age = 20;
const isAdult = age >= 18 ? "Повнолітній" : "Неповнолітній";

// Використання для статусу студента
const isStudent = true;
const statusText = isStudent ? "Студент денної форми" : "Випускник / Не студент";
console.log(`Статус: ${statusText}`);
```

  <Callout type="warning" title="Коли не варто зловживати тернарним оператором">
    Не вкладайте більше двох рівнів тернарних операторів (<code>a ? b : c ? d : e</code>), оскільки такий код стає важким для читання іншими розробниками. Якщо умов більше двох — використовуйте <code>if / else if</code> або <code>switch</code>.
  </Callout>

  <h2>Множинний вибір через switch / case</h2>

```javascript
const userRole = "editor";

switch (userRole) {
  case "admin":
    console.log("Доступ до панелі керування та видалення користувачів");
    break;
  case "editor":
    console.log("Доступ до створення та редагування статей");
    break;
  case "viewer":
    console.log("Доступ лише для перегляду контенту");
    break;
  default:
    console.log("Невідома роль: доступ обмежено");
}
```

  <h2>Матриця значень: Falsy проти Truthy</h2>
  <p>У JavaScript всього <strong>8 значень</strong> перетворюються на <code>false</code> у логічному контексті:</p>
  <ul>
    <li><code>false</code></li>
    <li><code>0</code> та <code>-0</code>, <code>0n</code></li>
    <li><code>""</code> (порожній рядок)</li>
    <li><code>null</code></li>
    <li><code>undefined</code></li>
    <li><code>NaN</code></li>
  </ul>
  <p><strong>Усе інше — це Truthy!</strong> (У тому числі порожній масив <code>[]</code>, порожній об'єкт <code>{}</code> та рядок з пробілом <code>" "</code>).</p>
</section>
