      <h2>Promise</h2>
      

```javascript
// Promise — обіцянка що буде значення у майбутньому
const promise = new Promise((resolve, reject) => {
  setTimeout(() => resolve('готово!'), 1000);
});

promise
  .then(result => console.log(result))  // 'готово!'
  .catch(err => console.error(err))     // якщо reject
  .finally(() => console.log('done')); // завжди

// Promise.all — паралельно
const [users, posts] = await Promise.all([fetchUsers(), fetchPosts()]);
```



      <h2>async/await та fetch</h2>
      

```text
// async функція завжди повертає Promise
async function getUsers() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/users');

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    const users = await response.json();
    return users;
  } catch (error) {
    console.error('Помилка:', error.message);
    throw error;  // пробросити далі
  }
}

// POST запит
async function createPost(data) {
  const res = await fetch('https://api.example.com/posts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data),
  });
  return res.json();
}
```

      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Не перевіряти `response.ok`</strong>: `fetch()` не кидає помилку при статусах 4xx/5xx! Обов'язково: `if (!response.ok) throw new Error(...)`.</li>
        <li><strong>Забути `await`</strong>: `const data = response.json()` без `await` — ти отримаєш Promise, а не дані.</li>
        <li><strong>Не обробляти помилки</strong>: `async/await` без `try/catch` — необроблений rejection може «впасти» мовчки.</li>
        <li><strong>Послідовні await замість паралельних</strong>: якщо два запити незалежні — використовуй `Promise.all()` а не два окремих `await`.</li>
