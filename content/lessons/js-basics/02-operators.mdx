Розуміння <strong>суворого порівняння</strong> (`===` vs `==`) та <strong>короткого замикання</strong> є ключовим для уникнення типових багів.</p>

      <p>Уяви гру де є правила: «+» додає очки, «===» — суворий суддя що перевіряє і значення і тип, «==» — ліберальний суддя що спочатку конвертує типи. Логічний `&&` — як «і те, і це», `||` — «або те, або це».</p>

      <h2>Арифметичні та присвоювання</h2>
      

```javascript
let x = 10;
x + 3   // 13    x - 3  // 7
x * 2   // 20    x / 4  // 2.5
x % 3   // 1  ← залишок від ділення
x ** 2  // 100 ← степінь

// Скорочені присвоювання
x += 5;  // x = x + 5 = 15
x -= 3;  // x = 12
x++;     // x = 13 (після виразу)
++x;     // x = 14 (до виразу)
```



      <h2>Порівняння: === vs ==</h2>
      

```javascript
// === суворе — перевіряє значення І тип
1 === 1     // true
1 === '1'   // false ← різні типи
0 === false // false

// == нестрогe — конвертує типи (не рекомендоване)
1 == '1'   // true  ← JavaScript зробив '1' → 1
0 == false // true  ← false → 0
null == undefined // true  ← особливий випадок

// ЗАВЖДИ використовуй === і !==
```



      <h2>Логічні оператори та коротке замикання</h2>
      

```javascript
// && — AND: повертає перше falsy або останнє значення
true && 'hello'   // 'hello'
false && 'hello'  // false  ← зупинився на false
const user = { name: 'Іван' };
user && user.name  // 'Іван'  ← безпечний доступ

// || — OR: повертає перше truthy або останнє значення
null || 'default'   // 'default'
'value' || 'default' // 'value'

// ?? — Nullish Coalescing: тільки null/undefined
0 || 'default'  // 'default' ← 0 falsy!
0 ?? 'default'  // 0         ← 0 не null/undefined

// ?. — Optional Chaining
const city = user?.address?.city; // undefined замість помилки
```

        <li><strong>Використовувати `==` замість `===`</strong>: неявна конверсія типів — джерело важко відловлюваних багів.</li>
        <li><strong>Плутати `||` і `??`</strong>: `||` вважає `0`, `''`, `false` falsy-значеннями. `??` — тільки `null`/`undefined`.</li>
        <li><strong>Не використовувати `?.`</strong>: доступ до властивості без перевірки (`user.address.city`) кидає помилку якщо `address` є `undefined`.</li>
