# 01. Що таке JavaScript та запуск першого коду

<article className="lesson-card">
  <h2>Що таке JavaScript?</h2>
  <p><strong>JavaScript (JS)</strong> — це повноцінна динамічна мова програмування, яка є головною рушійною силою сучасного вебу. Якщо <strong>HTML</strong> відповідає за скелет і структуру сторінки, а <strong>CSS</strong> — за її зовнішній вигляд та стиль, то <strong>JavaScript</strong> «оживляє» інтерфейс: реагує на кліки користувача, відправляє та отримує дані без перезавантаження, створює анімації та керує бізнес-логікою.</p>
  <p>Сьогодні JavaScript працює не лише у браузері, але й на серверах (Node.js, Deno, Bun), у мобільних додатках (React Native), настільних програмах (Electron, Tauri) та навіть у пристроях IoT.</p>
</article>

<section className="analogy-block">
  <div className="analogy-block__title"><span className="analogy-block__icon">🚗</span> Аналогія: Автомобіль</div>
  <p>Уявіть створення автомобіля:</p>
  <ul>
    <li><strong>HTML</strong> — це металевий каркас, кузов, двері, сидіння та кермо.</li>
    <li><strong>CSS</strong> — це колір фарби, шкіряний салон, підсвічування панелі та тонування скла.</li>
    <li><strong>JavaScript</strong> — це двигун, трансмісія, бортовий комп'ютер, натискання на педаль газу та спрацьовування подушок безпеки.</li>
  </ul>
</section>

<section>
  <h2>Коротка історія та стандарти ECMAScript</h2>
  <p>
    JavaScript був створений у 1995 році програмістом <strong>Бренданом Айком (Brendan Eich)</strong> у компанії Netscape всього за <strong>10 днів</strong>. Спочатку мова називалася <em>Mocha</em>, потім <em>LiveScript</em>, і зрештою отримала маркетингову назву <em>JavaScript</em> (на хвилі популярності мови Java, хоча ці дві мови зовсім різні за філософією).
  </p>
  <p>
    Сьогодні розвитком мови займається міжнародний комітет <strong>TC39</strong> під стандартом <strong>ECMAScript</strong>. Щороку виходить нова версія стандарту (наприклад, ES6/ES2015 став фундаментальним оновленням мови, додавши <code>let</code>/<code>const</code>, стрілкові функції, класи та модулі).
  </p>

  <h2>Де і як виконується JavaScript?</h2>
  <p>
    JavaScript виконується спеціальною програмою — <strong>рушієм (JS Engine)</strong>:
  </p>
  <ul>
    <li><strong>V8</strong> — рушій від Google у Chrome, Brave, Edge та Node.js.</li>
    <li><strong>SpiderMonkey</strong> — рушій у Mozilla Firefox.</li>
    <li><strong>JavaScriptCore (Nitro)</strong> — рушій від Apple у Safari.</li>
  </ul>
  <p>
    Рушій читає вихідний код, транслює його у машинний код за допомогою <strong>JIT-компіляції (Just-In-Time)</strong> та блискавично виконує.
  </p>

  <h2>Підключення JavaScript до веб-сторінки</h2>
  <p>Є три основні способи підключити JS до HTML:</p>

```html
<!-- 1. Вбудований скрипт у тілі HTML -->
<script>
  console.log("Привіт із вбудованого скрипта!");
</script>

<!-- 2. Зовнішній файл (найкраща практика) з defer для безпечного завантаження -->
<script src="app.js" defer></script>

<!-- 3. Сучасний ES-модуль -->
<script type="module" src="main.js"></script>
```

  <Callout type="info" title="Чому defer важливий?">
    Атрибут <code>defer</code> наказує браузеру завантажувати скрипт у фоновому режимі, не блокуючи побудову DOM-дерева, та виконати його тільки після повного розбору структури HTML сторінки.
  </Callout>

  <h2>Консоль розробника та методи виводу</h2>
  <p>
    Консоль браузера (відкривається клавішею <strong>F12</strong> або <strong>Cmd+Option+I</strong> у вкладці <em>Console</em>) — це головний інструмент дебагу та швидких експериментів розробника.
  </p>

```javascript
// 1. Стандартний вивід інформації
console.log('Привіт, Frontend Camp!');

// 2. Інформаційне повідомлення
console.info('Завантаження модуля успішне');

// 3. Попередження (жовтий колір у консолі)
console.warn('Увага: пароль занадто простий!');

// 4. Помилка (червоний колір з трасуванням стеку)
console.error('Помилка: сервер недоступний');

// 5. Вивід структурованих даних у вигляді таблиці
console.table([
  { id: 1, name: 'Анна', role: 'Frontend Dev' },
  { id: 2, name: 'Максим', role: 'UI/UX Designer' }
]);
```

  <h2>Коментарі в коді</h2>
  <p>Коментарі не виконуються рушієм і служать для пояснення логіки або тимчасового відключення коду:</p>

```javascript
// Однорядковий коментар — пояснює наступний рядок

/*
  Багаторядковий коментар:
  Тут можна описати деталі алгоритму,
  авторство або складну математичну формулу.
*/
```

<section className="tip-block tip-block--warn">
  <div className="tip-block__title"><span>⚠️</span> Типові помилки початківців</div>
  <ul>
    <li><strong>Регістрозалежність (Case Sensitivity)</strong>: <code>console.log</code> та <code>Console.Log</code> — це різні речі! У JS регістр має вирішальне значення. <code>Console</code> з великої літери викличе помилку <code>ReferenceError</code>.</li>
    <li><strong>Плутанина між одинарними, подвійними лапками та апострофами</strong>: переконайтеся, що відкриваюча лапка збігається із закриваючою: <code>"текст'</code> — це синтаксична помилка.</li>
    <li><strong>Спроба маніпулювати DOM до його завантаження</strong>: якщо викликати скрипт у <code>&lt;head&gt;</code> без <code>defer</code>, елементи сторінки ще не існують, і JS їх не знайде.</li>
  </ul>
</section>
