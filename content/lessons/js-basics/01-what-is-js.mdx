<article className="lesson-card">
  <h2>Що таке JavaScript?</h2>
  <p><strong>JavaScript (JS)</strong> — це повноцінна динамічна мова програмування, яка є головною рушійною силою сучасного вебу. Якщо <strong>HTML</strong> відповідає за скелет і структуру сторінки, а <strong>CSS</strong> — за її зовнішній вигляд та стиль, то <strong>JavaScript</strong> «оживляє» інтерфейс: реагує на кліки користувача, відправляє та отримує дані без перезавантаження (AJAX / Fetch), створює динамічні анімації та керує бізнес-логікою.</p>
  <p>Сьогодні JavaScript працює не лише у браузері, але й на серверах (Node.js, Deno, Bun), у мобільних додатках (React Native), настільних програмах (Electron, Tauri) та хмарних serverless функціях.</p>
</article>

  <h2>Коротка історія та стандарти ECMAScript</h2>
  <p>
    JavaScript був створений у 1995 році програмістом <strong>Бренданом Айком (Brendan Eich)</strong> у компанії Netscape всього за <strong>10 днів</strong>. Спочатку мова називалася <em>Mocha</em>, потім <em>LiveScript</em>, і зрештою отримала маркетингову назву <em>JavaScript</em> (на хвилі популярності Java, хоча ці мови абсолютно різні).
  </p>
  <p>
    Сьогодні розвитком мови займається міжнародний комітет <strong>TC39</strong> під стандартом <strong>ECMAScript</strong>. Щороку виходить нова версія стандарту (наприклад, ES6/ES2015 став фундаментальним стрибком мови, додавши <code>let</code>/<code>const</code>, стрілкові функції, класи та модулі).
  </p>

  <h2>Підключення JavaScript до веб-сторінки</h2>

```html
<!-- 1. Вбудований скрипт у тілі HTML -->
<script>
  console.log("Привіт із вбудованого скрипта!");
</script>

<!-- 2. Зовнішній файл (найкраща практика) з defer для безпечного завантаження -->
<script src="app.js" defer></script>

<!-- 3. Сучасний ES-модуль -->
<script type="module" src="main.js"></script>
```

  <Callout type="info" title="Чому defer важливий?">
    Атрибут <code>defer</code> наказує браузеру завантажувати скрипт у фоновому режимі, не блокуючи побудову DOM-дерева, та виконати його тільки після повного розбору структури HTML сторінки.
  </Callout>

  <h2>Консоль розробника та методи виводу</h2>

```javascript
// 1. Стандартний вивід інформації
console.log('Привіт, Frontend Camp!');

// 2. Інформаційне повідомлення
console.info('Завантаження модуля успішне');

// 3. Попередження (жовтий колір у консолі)
console.warn('Увага: пароль занадто простий!');

// 4. Помилка (червоний колір з трасуванням стеку)
console.error('Помилка: сервер недоступний');

// 5. Вивід структурованих даних у вигляді таблиці
console.table([
  { id: 1, name: 'Анна', role: 'Frontend Dev' },
  { id: 2, name: 'Максим', role: 'UI/UX Designer' }
]);
```
