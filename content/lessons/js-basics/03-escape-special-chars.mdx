# 03. Спецсимволи, екранування (\n, \t) та форматування тексту

<article className="lesson-card">
  <h2>Навіщо потрібне екранування (Escaping)?</h2>
  <p>У мовах програмування лапки <code>'</code> та <code>"</code> використовуються для позначення меж текстового рядка. Але що робити, коли сам текст містить лапки, або коли потрібно зробити перенесення на новий рядок чи відступ табуляцією всередині одного виклику?</p>
  <p>Для цього використовується <strong>екранування (escape sequence)</strong> — спеціальна комбінація символів, що починається зі зворотного слешу <code>&#92;</code> (backslash). Символ <code>&#92;</code> вказує рушію: <em>«Наступний символ особливий, інтерпретуй його не як службовий синтаксис, а як спеціальну команду або символ!»</em></p>
</article>

<section className="analogy-block">
  <div className="analogy-block__title"><span className="analogy-block__icon">🪄</span> Аналогія: Магічна паличка перевтілення</div>
  <p>
    Зворотний слеш <code>&#92;</code> — це як магічна паличка. Звичайна літера <code>n</code> — це просто літера, але якщо перед нею поставити <code>&#92;n</code>, вона перетворюється на невидиму клавішу <strong>Enter</strong> (перехід на новий рядок). Звичайна літера <code>t</code> перетворюється на клавішу <strong>Tab</strong> (відступ). А службова лапка <code>&#92;"</code> перестає завершувати рядок і стає просто розділовим знаком у тексті.
  </p>
</section>

  <h2>Приклади використання в коді</h2>

```javascript
// 1. Перенесення рядків та лапки
console.log("План на день:\n1. Вивчити JavaScript\n2. Написати код\n3. Відпочити");

// 2. Екранування лапок в цитаті
console.log('Шевченко писав: "Учітесь, читайте, і чужому научайтесь, й свого не цурайтесь".');
console.log("Іван сказав: \"Сьогодні п\'ятниця!\"");

// 3. Форматування чека таблицею за допомогою табуляції \t
console.log("НАЗВА\t\tК-СТЬ\tЦІНА");
console.log("Ноутбук\t\t1 шт\t35000 грн");
console.log("Мишка USB\t2 шт\t1200 грн");
console.log("Клавіатура\t1 шт\t2800 грн");

// 4. Шляхи до файлів у Windows (подвійний слеш)
console.log("Шлях проекту: C:\\Users\\grabovsky\\projects\\frontend-camp");

// 5. Юнікод символи та емодзі
console.log("\u00A9 2026 Frontend Camp. Всі права захищено.");
```

  <h2>Альтернатива: Шаблонні рядки (Template Literals)</h2>
  <p>
    У сучасному JavaScript (ES6) з'явилися <strong>шаблонні рядки</strong> у зворотних лапках. Вони автоматично підтримують перенесення рядків без необхідності писати <code>&#92;n</code>:
  </p>

```javascript
// Зручний багаторядковий запис без \n
const receipt = `
============================
🧾 ФІСКАЛЬНИЙ ЧЕК
Кава Latte:\t\t65 грн
Круасан:\t\t50 грн
----------------------------
РАЗОМ:\t\t\t115 грн
============================
`;

console.log(receipt);
```

<section className="tip-block tip-block--warn">
  <div className="tip-block__title"><span>⚠️</span> Часті помилки зі спецсимволами</div>
  <ul>
    <li><strong>Плутанина між прямим <code>/</code> (slash) та зворотним <code>&#92;</code> (backslash)</strong>: екранування працює виключно зі зворотним слешем <code>&#92;</code>. Комбінація <code>/n</code> буде надрукована буквально як два символи <code>/n</code>.</li>
    <li><strong>Забуте подвоєння слешу у файлових шляхах</strong>: якщо написати <code>"C:&#92;new_folder&#92;test"</code>, JS сприйме <code>&#92;n</code> як перенесення рядка, а <code>&#92;t</code> як табуляцію! Завжди пишіть <code>"C:&#92;&#92;new_folder&#92;&#92;test"</code> або використовуйте прямі слеші <code>"C:/new_folder/test"</code>.</li>
    <li><strong>Втрата закриваючої лапки через екранування в кінці</strong>: якщо рядок закінчується зворотним слешем перед лапкою <code>"C:&#92;&#92;test&#92;"</code>, слеш заекранує саму лапку і викличе синтаксичну помилку. Правильно: <code>"C:&#92;&#92;test&#92;&#92;"</code>.</li>
  </ul>
</section>
