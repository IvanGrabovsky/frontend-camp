<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p><strong>App Router</strong> — сучасна система маршрутизації Next.js (з версії 13), де кожна папка в директорії `app/` відповідає сегменту URL. Файли зі спеціальними іменами (`page.tsx`, `layout.tsx`, `loading.tsx`, `error.tsx`) мають зарезервовані ролі.</p>
      <p>До App Router існував Pages Router (`pages/` директорія) — він досі підтримується, але App Router є рекомендованим підходом.</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">🗂️</span> Аналогія з файловою системою</div>
      <p>App Router — це як структура папок у провіднику: кожна папка = один сегмент URL. `app/blog/[id]/page.tsx` → `/blog/123`. Файл `layout.tsx` у папці — це «рамка» яка обгортає всі дочірні сторінки.</p>
    </section>

      <h2>Структура app/ директорії</h2>

      

```javascript
app/
├── layout.tsx          ← root layout (обов'язковий)
├── page.tsx            ← /  (головна сторінка)
├── loading.tsx         ← UI завантаження для /
├── error.tsx           ← UI помилки для /
│
├── about/
│   └── page.tsx        ← /about
│
├── blog/
│   ├── page.tsx        ← /blog
│   ├── layout.tsx      ← layout для /blog і всіх підсторінок
│   └── [slug]/
│       └── page.tsx    ← /blog/my-post (динамічний)
│
└── (auth)/             ← Route Group (не впливає на URL)
    ├── login/page.tsx  ← /login
    └── register/page.tsx ← /register
```

      <h2>Root Layout — обов'язковий</h2>
      

```javascript
// app/layout.tsx — кореневий layout
import type { Metadata } from 'next';


export const metadata: Metadata = {
  title: 'My App',
  description: 'Generated by Next.js',
};


export default function RootLayout({
  children,
}: { children: React.ReactNode }) {
  return (
    <html lang="uk">
      <body>{children}</body>  {/* ← тут рендерится page.tsx */}
    </html>
  );
}
```



      <h2>Route Groups і Parallel Routes</h2>
      

```javascript
// (group) — не впливає на URL, тільки організація
app/(marketing)/about/page.tsx  → /about
app/(dashboard)/settings/page.tsx → /settings
// Різні layout для marketing і dashboard


// @slot — Parallel Routes (одночасно кілька сторінок)
app/
├── layout.tsx         ← { children, @modal }
└── @modal/
    └── login/page.tsx ← /login відкривається в modal
```

      <ul>
        <li><strong>Відсутній root layout</strong> — Next.js вимагає `app/layout.tsx` з `<html>` і `<body>`.</li>
        <li><strong>Плутанина pages/ і app/</strong> — не змішуй Pages Router і App Router в одному проекті без чіткого розуміння.</li>
        <li><strong>`error.tsx` без `'use client'`</strong> — Error Boundary повинен бути Client Component.</li>
        <li><strong>Route Group впливає на URL</strong> — ні! `(marketing)/about` → `/about`, а не `/marketing/about`.</li>
