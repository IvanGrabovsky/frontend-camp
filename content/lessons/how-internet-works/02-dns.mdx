<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p><strong>DNS (Domain Name System)</strong> — розподілена база даних, яка перетворює людиночитані домени (`google.com`) на IP-адреси (`142.250.185.46`). Без DNS ти мусив би знати числові адреси кожного сайту.</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">📖</span> Аналогія з телефонною книгою</div>
      <p>DNS — це <strong>телефонна книга інтернету</strong>. Ти знаєш ім'я (домен), книга дає номер (IP). Але вона глобальна, автоматично оновлюється і кешується на кожному рівні.</p>
    </section>

    <section>
      <h2>Ієрархія та повний ланцюжок запиту</h2>

      

```text
// Ланцюжок DNS при першому запиті
Браузер (кеш?) → ОС (кеш / /etc/hosts?)
  → Рекурсивний резолвер (провайдер / 8.8.8.8)
    → Root DNS  ("com? → 192.5.6.30")
    → TLD .com  ("example.com? → ns1.example.com")
    → Authoritative ("example.com A → 93.184.216.34, TTL 3600")
← IP повертається і кешується на кожному рівні
```



      <h2>Типи DNS-записів</h2>
      <div className="syntax-params">
        <table className="params-table">
          <thead><tr><th>Тип</th><th>Призначення</th><th>Приклад</th></tr></thead>
          <tbody>
            <tr><td>`A`</td><td>Домен → IPv4</td><td>`example.com → 93.184.216.34`</td></tr>
            <tr><td>`AAAA`</td><td>Домен → IPv6</td><td>`example.com → 2606:2800:...`</td></tr>
            <tr><td>`CNAME`</td><td>Псевдонім домену</td><td>`www → example.com`</td></tr>
            <tr><td>`MX`</td><td>Поштовий сервер</td><td>`example.com → mail.example.com`</td></tr>
            <tr><td>`TXT`</td><td>Текст (SPF, DKIM, верифікація)</td><td>`"v=spf1..."`</td></tr>
            <tr><td>`TTL`</td><td>Час кешування (секунди)</td><td>`3600` = 1 год</td></tr>
          </tbody>
        </table>
      </div>

      

```text
# Команди в терміналі
dig google.com A              # A-запис
dig google.com +trace         # повний ланцюжок
dig @8.8.8.8 google.com A    # через Google DNS
dig @1.1.1.1 google.com A    # через Cloudflare DNS
```

    <section className="tip-block tip-block--warn">
      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>«DNS-зміна миттєва»</strong> — ні. Поширення: хвилини–24+ год залежно від TTL.</li>
        <li><strong>«CNAME на root-домен»</strong> — неможливо. На `@` тільки A/AAAA/MX/TXT/NS.</li>
        <li><strong>«Один домен — одна IP»</strong> — ні. Round-robin DNS: кілька A-записів для балансування.</li>
        <li><strong>«DNS безпечний»</strong> — базовий DNS не шифрується (UDP 53). Є DoH та DoT.</li>
      </ul>
    </section>
