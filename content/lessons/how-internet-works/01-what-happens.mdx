  <h2>Повний шлях — 9 кроків</h2>

```text
// Крок 1 — Парсинг URL
https://example.com:443/about?lang=ua#team
│       │           │   │     │        └─ fragment (hash)
│       │           │   │     └─ query string (параметри)
│       │           │   └─ path (шлях)
│       │           └─ port (порт)
│       └─ host (домен)
└─ scheme (протокол)
```

  <ol className="steps">
    <li><strong>Парсинг URL</strong> — браузер розбиває рядок на scheme, host, port, path, query, fragment.</li>
    <li><strong>Перевірка кешу</strong> — браузерний кеш → кеш ОС → файл `/etc/hosts`.</li>
    <li><strong>DNS-запит (Resolution)</strong> — резолвер → Root сервер → TLD (.com) → Authoritative DNS → IP-адреса.</li>
    <li><strong>TCP Handshake</strong> — SYN → SYN-ACK → ACK (трьохстороннє рукостискання на транспортному рівні).</li>
    <li><strong>TLS Handshake</strong> (HTTPS) — узгодження версії TLS, шифрів (Cipher Suite) та обмін сесійними ключами.</li>
    <li><strong>HTTP-запит</strong> — відправка клієнтського запиту GET/POST з заголовками (Host, User-Agent, Accept, Cookie).</li>
    <li><strong>Відповідь сервера</strong> — статус-код (200 OK) + заголовки відповіді + тіло (HTML документ).</li>
    <li><strong>Rendering Pipeline</strong> — HTML → DOM дерево, CSS → CSSOM дерево, об'єднання в Render Tree → Layout → Paint → Composite.</li>
    <li><strong>Додаткові підресурси</strong> — CSS стилі, JS скрипти, зображення, шрифти завантажуються паралельно через HTTP/2 або HTTP/3 мультиплексування.</li>
  </ol>

```text
// Браузерний пайплайн рендерингу (Critical Rendering Path):
HTML  ──>  DOM
            │
            ├──>  Render Tree  ──>  Layout (Reflow)  ──>  Paint  ──>  Composite
            │
CSS   ──>  CSSOM
```
