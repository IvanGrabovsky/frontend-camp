<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p><strong>HTTP (HyperText Transfer Protocol)</strong> — протокол прикладного рівня без збереження стану (stateless), за яким клієнт (браузер) і сервер спілкуються текстовими або бінарними повідомленнями за моделлю «запит — відповідь» (Request — Response).</p>
      <p><strong>HTTPS</strong> — це той самий HTTP, але загорнутий у криптографічний шар TLS/SSL (порт 443), що захищає трафік від перехоплення та модифікації.</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">🍽️</span> Аналогія з рестораном</div>
      <p>Клієнт — відвідувач, що передає офіціанту бланк замовлення (HTTP Request: метод «Принести», назва страви, побажання). Офіціант повертає страву з чеком (HTTP Response: статус `200 OK` або `404 Немає в меню`). HTTPS — це офіціант у броньованому сейфі, щоб шпигуни не підгледіли номер вашої картки.</p>
    </section>

    <section>
      <h2>Анатомія HTTP-запиту (Request)</h2>
      

```text
// 1. Стартовий рядок (Request Line): Метод · Шлях · Версія протоколу
POST /api/v1/users HTTP/1.1
// 2. Заголовки (Headers): Ключ-значення метаінформації
Host: api.example.com
User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7)
Accept: application/json
Content-Type: application/json; charset=utf-8
Content-Length: 48
Authorization: Bearer eyJhbGciOi...
// 3. Порожній рядок (обов'язковий розділювач)

// 4. Тіло запиту (Body) — опціонально для POST/PUT/PATCH
{"name": "Олександр", "email": "alex@dev.ua"}
```



      <h2>Анатомія HTTP-відповіді (Response)</h2>
      

```text
// 1. Статусний рядок (Status Line): Версія · Код статусу · Пояснення
HTTP/1.1 201 Created
// 2. Заголовки відповіді (Response Headers)
Date: Sun, 23 Aug 2026 18:30:00 GMT
Content-Type: application/json; charset=utf-8
Content-Length: 64
Set-Cookie: session_id=abc123xyz; HttpOnly; Secure; SameSite=Strict
Cache-Control: no-store
Access-Control-Allow-Origin: https://myfrontend.com

// 3. Тіло відповіді (Response Body)
{"id": 42, "name": "Олександр", "status": "active"}
```

            <tr><td>`Content-Type`</td><td>Запит / Відповідь</td><td>MIME-тип тіла повідомлення: `application/json`, `text/html`, `multipart/form-data`.</td></tr>

            <tr><td>`Cache-Control`</td><td>Запит / Відповідь</td><td>Директиви кешування: `max-age=3600`, `no-cache`, `no-store`, `immutable`.</td></tr>

      <h2>Еволюція: HTTP/1.1 vs HTTP/2 vs HTTP/3</h2>
      

```text
// HTTP/1.1 — Текстовий протокол, 1 TCP-з'єднання = 1 запит одночасно (Head-of-Line blocking на рівні HTTP)
// HTTP/2   — Бінарний, мультиплексування (сотні запитів через 1 TCP-з'єднання), HPACK стиснення заголовків
// HTTP/3   — Базується на QUIC (поверх UDP), усуває Head-of-Line blocking на рівні TCP, 0-RTT відновлення
```

    <section className="tip-block tip-block--warn">
      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Плутанина `401 Unauthorized` та `403 Forbidden`</strong> — 401 означає «хто ти такий? увійди в систему», 403 означає «я знаю хто ти, але тобі сюди заборонено».</li>
        <li><strong>Передача конфіденційних даних у GET-запиті</strong> — параметри URL (query string) зберігаються в історії браузера, логах провайдера та серверних логах! Завжди використовуйте POST з шифруванням HTTPS.</li>
        <li><strong>Плутанина `PUT` та `PATCH`</strong> — PUT замінює сутність повністю (якщо не передали поле, воно занулюється), а PATCH точково змінює лише вказані поля.</li>
        <li><strong>Ігнорування прапорців безпеки в Cookies</strong> — відсутність `HttpOnly` робить куку вразливою до викрадення через JS (XSS).</li>
      </ul>

          <p className="hw-review-item__good"><span className="hw-review-label">✅</span> Ідемпотентність означає, що багаторазове виконання одного й того ж запиту призводить до однакового стану системи на сервері, що й один запит.         <li>Статус `304 Not Modified` дозволяє не передавати тіло відповіді заново, якщо хеш ресурсу (ETag) у браузера збігається з серверним.</li>
