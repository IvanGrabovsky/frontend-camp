# 01. Числа: методи, Math та особливості float

<article className="lesson-card">
  <h2>Числа в JavaScript</h2>
  <p>У JavaScript для більшості числових значень використовується єдиний тип даних — <strong>Number</strong>. Він реалізований за міжнародним стандартом <strong>IEEE 754</strong> (64-бітне число з плаваючою комою подвійної точності — double precision float). Це означає, що як цілі числа (<code>42</code>), так і дробові (<code>3.14</code>) зберігаються в однаковому форматі.</p>
  <p>Для роботи з надвеликими цілими числами, що виходять за межі безпечного діапазону (понад $\pm 2^{53} - 1$), існує окремий примітивний тип — <strong>BigInt</strong> (наприклад, <code>9007199254740991n</code>).</p>
</article>

<section className="analogy-block">

  <p>Чому <code>1/3</code> у десятковій системі — це нескінченний дріб <code>0.3333...</code>? Тому що трійка не є степенем 10. Точно так само у комп'ютері, який працює у двійковій системі (степені двійки: 2, 4, 8, 16...), дріб <code>0.1</code> (1/10) є нескінченним двійковим дробом. Через це виникає знаменита похибка <code>0.1 + 0.2 === 0.30000000000000004</code>.</p>

  <h2>Основні способи запису чисел</h2>

```javascript
// 1. Звичайні десяткові числа та дроби
const itemsCount = 42;
const price = 19.99;

// 2. Експоненційний запис (наукова нотація: e або E)
const oneMillion = 1e6; // 1 * 10^6 = 1_000_000
const microsecond = 1e-6; // 0.000001

// 3. Розділювач розрядів для читабельності (numeric separator _)
const billion = 1_000_000_000;
const colorHex = 0xff_ec_d2; // Hexadecimal (шістнадцятковий)
const binaryFlags = 0b1010_0001; // Binary (двійковий)
```

  <h2>Парсинг рядків у числа: parseInt та parseFloat</h2>

```javascript
// parseInt зчитує ціле число до першого нечислового символу
console.log(parseInt('100px')); // 100
console.log(parseInt('12.5rem')); // 12
console.log(parseInt('0xff', 16)); // 255 (шістнадцятковий)
console.log(parseInt('1101', 2)); // 13 (двійковий)

// parseFloat зберігає дробову частину
console.log(parseFloat('19.99$')); // 19.99
console.log(parseFloat('3.14.15')); // 3.14 (зупиняється на другій крапці)

// Увага: якщо перший символ не є цифрою — повертається NaN
console.log(parseInt('price: 50')); // NaN
```

  <Callout type="warning" title="Різниця між Number(str) та parseInt(str)">
    <code>Number('100px')</code> поверне <code>NaN</code>, оскільки вимагає <em>повністю</em> числовий рядок. Натомість <code>parseInt('100px')</code> зчитає число <code>100</code>, ігноруючи текст у кінці. Завжди вказуйте основу (radix) для <code>parseInt(str, 10)</code> для уникнення старих багів.
  </Callout>

```javascript
// Корисні методи Math
console.log(Math.max(10, 45, 2, 99)); // 99
console.log(Math.min(10, 45, 2, 99)); // 2
console.log(Math.abs(-25)); // 25 (модуль числа)
console.log(Math.pow(2, 8)); // 256 (або оператор 2 ** 8)
console.log(Math.sqrt(144)); // 12

// Генерація випадкового цілого числа у діапазоні [min, max]
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
console.log('Кубик 1-6:', getRandomInt(1, 6));
```

  <h2>Форматування кількості знаків: num.toFixed(digits)</h2>

```javascript
const total = 12.3456;

// toFixed повертає РЯДОК, округлений до N знаків після коми
console.log(total.toFixed(2)); // "12.35" (рядок!)
console.log(total.toFixed(0)); // "12"

// Щоб знову перетворити результат на число — використовуйте унарний плюс:
const roundedPrice = +total.toFixed(2); // 12.35 (number)
```

  <Callout type="tip" title="Як безпечно порівнювати дробові числа?">
    Використовуйте константу <code>Number.EPSILON</code>:
    ```javascript
    const sum = 0.1 + 0.2;
    const areEqual = Math.abs(sum - 0.3) < Number.EPSILON;
    console.log(areEqual); // true!
    ```
  </Callout>
