# 05. Шаблонні рядки та Tagged Templates

<article className="lesson-card">
  <h2>Шаблонні рядки (Template Literals)</h2>
  <p>Шаблонні рядки (<strong>Template Literals</strong>), які зʼявилися в ES6 і позначаються зворотними лапками (<strong>`backticks`</strong>), докорінно змінили роботу з текстом у JavaScript. Вони дозволяють легко вставляти будь-які JS-вирази через синтаксис <code>${`{...}`}</code>, підтримують багаторядковий текст без символів <code>\n</code> та надають потужний механізм тегованих шаблонів (<strong>Tagged Templates</strong>).</p>
</article>

  <h2>3. Теговані шаблони (Tagged Templates)</h2>
  <p>Тегований шаблон — це виклик функції без круглих дужок, де функція першим аргументом отримує масив статичних частин рядка, а наступними аргументами — значення інтерпольованих виразів:</p>

```javascript
// Функція безпечного екранування HTML від XSS атак
function safeHtml(strings, ...values) {
  return strings.reduce((acc, str, i) => {
    let val = values[i] !== undefined ? values[i] : '';
    // Екрануємо небезпечні символи у значеннях користувача
    if (typeof val === 'string') {
      val = val
        .replaceAll('&', '&amp;')
        .replaceAll('<', '&lt;')
        .replaceAll('>', '&gt;')
        .replaceAll('"', '&quot;');
    }
    return acc + str + val;
  }, '');
}

const userInput = "<script>alert('взлом!')</script>";
const safeCard = safeHtml`<div>Привіт, ${userInput}!</div>`;
console.log(safeCard); // "<div>Привіт, &lt;script&gt;alert('взлом!')&lt;/script&gt;!</div>"
```

  <Callout type="tip" title="Де використовуються Tagged Templates у реальних бібліотеках?">
    Саме на цьому механізмі побудовані такі інструменти, як <code>styled.div`...`</code> у <strong>styled-components</strong>, <code>graphql`...`</code> у <strong>Relay/Apollo</strong> та безпечні SQL-запити <code>sql`SELECT * FROM users WHERE id = ${`id`}`</code>.
  </Callout>

  <h2>4. Сирі рядки: String.raw</h2>

```javascript
// Без String.raw: \n перетвориться на новий рядок
console.log("C:\\Users\\notes\\new.txt");

// З String.raw: бекслеші зберігаються як є
const windowsPath = String.raw`C:\Users\notes\new.txt`;
console.log(windowsPath); // "C:\Users\notes\new.txt"
```
