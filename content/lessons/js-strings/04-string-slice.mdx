  <h2>1. Вирізання: str.slice(start, end)</h2>

```javascript
const sentence = "Frontend Development";

// slice(start, end) — end НЕ включається у результат!
console.log(sentence.slice(0, 8)); // "Frontend"
console.log(sentence.slice(9));    // "Development" (від 9 до кінця)

// Підтримка від'ємних індексів (рахунок з кінця):
console.log(sentence.slice(-11));    // "Development"
console.log(sentence.slice(0, -12)); // "Frontend"
```

  <Callout type="info" title="Чому завжди обирають slice замість substring / substr?">
    Історично в JS існували три схожі методи: <code>slice</code>, <code>substring</code> та <code>substr</code> (застарілий). Сучасний стандарт та спільнота рекомендують завжди використовувати <strong>slice</strong>, оскільки він повністю підтримує від'ємні індекси і працює однаково як на рядках, так і на масивах.
  </Callout>

  <h2>2. Заміна підрядків: replace та replaceAll</h2>

```javascript
const text = "Я люблю JavaScript. JavaScript — це круто!";

// 1. replace замінює ТІЛЬКИ ПЕРШИЙ збіг:
console.log(text.replace("JavaScript", "TypeScript"));
// "Я люблю TypeScript. JavaScript — це круто!"

// 2. replaceAll замінює ВСІ збіги у всьому тексті:
console.log(text.replaceAll("JavaScript", "TypeScript"));
// "Я люблю TypeScript. TypeScript — це круто!"
```

  <h2>3. Розбиття на масив: str.split(delimiter, limit)</h2>

```javascript
const tags = "react, nextjs, typescript, tailwind";

// Розбиття за розділювачем:
const tagList = tags.split(", ");
console.log(tagList); // ["react", "nextjs", "typescript", "tailwind"]

// Розбиття по літерах:
const word = "Код";
console.log(word.split("")); // ["К", "о", "д"]
```
