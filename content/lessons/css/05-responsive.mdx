      <h2>Media Queries</h2>
      

```css
/* Mobile-first: базовий стиль для мобільних, потім розширюємо */
.card { padding: 16px; font-size: 14px; }

@media (min-width: 768px) {  /* tablet */
  .card { padding: 24px; font-size: 16px; }
}
@media (min-width: 1200px) { /* desktop */
  .card { padding: 32px; font-size: 18px; }
}

/* Інші умови */
@media (prefers-color-scheme: dark) { ... }   /* темна тема OS */
@media (prefers-reduced-motion: reduce) { ... } /* вимкнути анімації */
@media (orientation: landscape) { ... }        /* горизонтальна орієнтація */
@media print { ... }                            /* для друку */
```



      <h2>`clamp()` — fluid typography без media queries</h2>
      

```css
/* clamp(мін, ідеал, макс) */
h1 { font-size: clamp(24px, 5vw, 48px); }  /* від 24px до 48px плавно */
.container { width: clamp(320px, 90%, 1200px); margin: 0 auto; }
.card { padding: clamp(16px, 3vw, 32px); }

/* min() і max() */
.sidebar { width: min(300px, 30vw); }  /* менше з двох */
.content  { width: max(200px, 60%); }  /* більше з двох */
```



      <h2>Container Queries (CSS 2023)</h2>
      

```css
/* Компонент адаптується до свого контейнера, а не вікна */
.card-wrapper { container-type: inline-size; }

@container (min-width: 400px) {
  .card { display: flex; gap: 16px; }  /* горизонтальне розташування */
}
@container (max-width: 399px) {
  .card { display: block; }            /* вертикальне */
}
```

      <ul><li><strong>Desktop-first замість mobile-first</strong>: `max-width` у media queries складніше підтримувати. Починай з мобільного базового стилю і розширюй через `min-width`.</li><li><strong>Використовувати `px` замість `rem`</strong> для шрифтів — ламає налаштування розміру тексту в браузері, що важливо для accessibility.</li><li><strong>Забувати `meta viewport`</strong> у `<head>` — без нього mobile viewport буде 980px, і media queries не спрацюють.</li><li><strong>Використовувати `vh` на мобільних</strong> — адресний рядок мобільного браузера змінює висоту. Замість `height: 100vh` використовуй `height: 100dvh`.</li><li><strong>Ігнорувати `prefers-reduced-motion`</strong> — частина користувачів має вестибулярні порушення і важкі анімації викликають дискомфорт.</li></ul>
