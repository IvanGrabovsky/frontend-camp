<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p><strong>Flexbox</strong> (Flexible Box Layout) — одновимірна модель розкладки CSS для розміщення елементів у рядку або стовпці. Ідеальна для навігацій, карток, центрування вмісту та будь-яких компонентів, де потрібно розподілити простір між елементами.</p>
      <p>Ключова ідея: контейнер з `display: flex` керує розміщенням своїх прямих нащадків (flex-items).</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">🚄</span> Аналогія з вагонами поїзда</div>
      <p>Уяви поїзд на рейках. Flex-контейнер — це рейки, flex-items — вагони. Ти можеш вирішити: рівномірно розставити вагони (`space-between`), зрушити всі до початку (`flex-start`), або до центру (`center`). Вагони можуть також «розтягуватись» щоб заповнити місце (`flex-grow`).</p>
    </section>

    <section>
      <h2>Основні властивості контейнера</h2>
      

```css
.container {
  display: flex;               /* вмикає flexbox */
  flex-direction: row;         /* row | column | row-reverse | column-reverse */
  justify-content: flex-start; /* вісь: start|center|end|space-between|space-around|space-evenly */
  align-items: stretch;        /* поперечна вісь: stretch|center|flex-start|flex-end|baseline */
  flex-wrap: nowrap;           /* nowrap | wrap | wrap-reverse */
  gap: 16px;                   /* відстань між елементами (row-gap column-gap) */
}
```



      <h2>Властивості flex-item</h2>
      

```css
.item {
  flex-grow: 0;    /* наскільки може розрости (0 — не росте) */
  flex-shrink: 1;  /* наскільки може стиснутись */
  flex-basis: auto;/* базовий розмір перед grow/shrink */
  flex: 1;         /* shorthand: grow=1, shrink=1, basis=0 */
  align-self: auto;/* перевизначає align-items для цього item */
  order: 0;        /* порядок (default 0, менше = першим) */
}
```



      <h2>Практичні патерни</h2>
      

```css
/* Центрування по обох осях */
.centered { display: flex; justify-content: center; align-items: center; }

/* Навігація: лого вліво, посилання вправо */
.nav { display: flex; align-items: center; }
.nav__logo { margin-right: auto; } /* auto «відштовхує» решту вправо */

/* Картки однакової висоти рядками */
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
.card  { flex: 1 1 280px; } /* мін. 280px, розтягується */

/* Footer «прилипає» до низу */
body   { display: flex; flex-direction: column; min-height: 100vh; }
main   { flex: 1; } /* займає весь вільний простір */
```

      <ul>
        <li><strong>Плутати main axis і cross axis</strong>: `justify-content` керує основною віссю (горизонтально за замовчуванням), `align-items` — поперечною.</li><li><strong>Не задавати висоту контейнеру</strong> для вертикального центрування: `align-items: center` не центрує якщо контейнер не має висоти.</li><li><strong>Плутати `flex: 1` з `width: 100%`</strong>: `flex: 1` розтягує рівномірно між іншими flex-items, `width: 100%` ігнорує інші items.</li><li><strong>Забувати `flex-wrap: wrap`</strong> — без нього всі items стискаються в один рядок і можуть вийти за межі.</li><li><strong>Зловживати `margin` замість `gap`</strong>: `gap` додає відступ тільки між items, не на краях контейнера.</li>
