<article className="lesson-card">
  <h2>Що це таке?</h2>
  <p><strong>Селектор (Selector)</strong> — шаблон, яким CSS обирає цільові HTML-елементи на сторінці. <strong>Специфічність (Specificity)</strong> — строга математична система підрахунку «ваги» правил. При конфлікті двох правил виграє те, що має вищу специфічність або йде пізніше в коді (<em>Cascade</em>). Глибоке розуміння цього позбавляє від хаотичного додавання <code>!important</code>.</p>
</article>

<section className="analogy-block">
  <div className="analogy-block__title"><span className="analogy-block__icon">🎯</span> Аналогія зі знижками та рангами</div>
  <p>Кожне правило — картка клієнта. Специфічність — рівень картки: ID (золота) бʼє Class (срібну), Class бʼє Tag (бронзову). При однаковому рівні виграє <em>пізніша</em> в файлі (каскад). <code>!important</code> — VIP-дозвіл, яким не варто зловживати.</p>
</section>

  <h2>Типи селекторів та їхня вага</h2>

```css
/* Тег — 0-0-1 */
p { color: #4b5563; }

/* Клас — 0-1-0 */
.btn { padding: 8px 16px; border-radius: 8px; }

/* ID — 1-0-0 */
#header { position: sticky; top: 0; }

/* Атрибут — 0-1-0 */
input[type="email"] { border: 1px solid #d1d5db; }

/* Псевдоклас — 0-1-0 */
a:hover { text-decoration: underline; color: #2563eb; }
li:first-child { font-weight: bold; }

/* Псевдоелемент — 0-0-1 */
.btn::after { content: " →"; }

/* Комбінатори (не додають власної специфічності) */
.nav > li       { display: inline-block; }  /* direct child */
.card + .card   { margin-top: 1rem; }       /* adjacent sibling */
```
