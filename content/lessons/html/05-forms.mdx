<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p><strong>HTML-форми (`<form>`)</strong> — це фундамент інтерактивності вебу: авторизація, реєстрація, пошукові рядки, фільтри товарів, оформлення замовлень та зворотний зв'язок. Вони збирають дані користувача і відправляють їх на сервер або передають у JavaScript.</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">📋</span> Аналогія з бланком анкети</div>
      <p>`<form>` — це паперова папка з анкетою. `<label>` — це надрукований підпис поля («Введіть ваше ім'я:»). `<input>` — пусте поле для запису. `<select>` — список варіантів із галочкою. `<button type="submit">` — кнопка «Здати анкету адміністратору».</p>

      <h2>Анатомія форми (тег `<form>`)</h2>
      

```html
<form action="/api/login" method="POST" autocomplete="on">
  <!-- 1. Явний зв'язок label та input через id і for -->
  <div className="form-group">
    <label htmlFor="user-email">Електронна пошта:</label>
    <input type="email" id="user-email" name="email" required placeholder="name@example.com" />
  </div>

  <div className="form-group">
    <label htmlFor="user-pass">Пароль:</label>
    <input type="password" id="user-pass" name="password" required minlength="8" />
  </div>

  <button type="submit">Увійти в кабінет</button>
</form>
```

      <h2>Інші ключові елементи форми</h2>
      

```html
<!-- 1. Багаторядкове поле (textarea) -->
<label htmlFor="bio">Про себе:</label>
<textarea id="bio" name="bio" rows="4" cols="50" placeholder="Розкажіть про свій досвід..."></textarea>

<!-- 2. Випадаючий список (select + option + optgroup) -->
<label htmlFor="country">Країна:</label>
<select id="country" name="country">
  <optgroup label="Європа">
    <option value="ua" selected>Україна</option>
    <option value="pl">Польща</option>
  </optgroup>
</select>

<!-- 3. Групування блоків (fieldset + legend) -->
<fieldset>
  <legend>Спосіб доставки</legend>
  <label><input type="radio" name="delivery" value="courier" checked /> Кур'єр</label>
  <label><input type="radio" name="delivery" value="pickup" /> Самовивіз</label>
</fieldset>

<!-- 4. Підказки для введення (datalist) -->
<input list="browsers" name="browser" placeholder="Виберіть браузер..." />
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
</datalist>
```

    <section className="tip-block tip-block--warn">
      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Відсутність `<label>` або зв'язку через `for/id`</strong> — користувачі зі скрін-рідерами не знатимуть, що вводити в інпут, а користувачі миші не зможуть клікнути по тексту, щоб активувати поле.</li>
        <li><strong>Заміна `<label>` на `placeholder`</strong> — плейсхолдер зникає при введенні тексту і не озвучується багатьма асистивними технологіями як заголовок поля!</li>
        <li><strong>Відсутність атрибута `name`</strong> — значення інпуту без `name` взагалі <strong>не буде надіслано</strong> у формі на сервер або у `FormData`.</li>
        <li><strong>`<button>` всередині форми без `type="button"`</strong> — за замовчуванням кнопка має `type="submit"` і при кліку несподівано перезавантажить сторінку та відправить форму!</li>
        <li><strong>Забутий `enctype="multipart/form-data"`</strong> — при надсиланні файлів без цього атрибута сервер отримає лише текстову назву файлу замість бінарних даних.</li>
      </ul>

        <li>Атрибут `inputmode="numeric"` на `<input type="text">` відкриває зручну цифрову клавіатуру на iOS/Android без зайвих стрілочок зсуву, які з'являються при `type="number"` (ідеально для банківських карток та SMS-кодів).</li>
        <li>Атрибут `autocomplete="new-password"` або `current-password` допомагає менеджерам паролів автоматично генерувати та зберігати безпечні паролі.</li>
        <li>Атрибут `form="form-id"` дозволяє розмістити інпут або кнопку поза межами тегу `<form>` у DOM-дереві, і вони все одно належатимуть цій формі.</li>
