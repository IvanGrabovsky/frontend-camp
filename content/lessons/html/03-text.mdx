      <h2>Що це таке?</h2>
      <p><strong>Текстові елементи в HTML</strong> — це будівельні блоки для контенту: заголовки, параграфи, списки, цитати та інлайнове виділення. Кожен тег надає тексту специфічне семантичне значення, яке скрін-рідери озвучують з правильною інтонацією, а пошукові роботи використовують для аналізу структури матеріалу.</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">📰</span> Аналогія з друкованою книгою</div>
      <p>`<h1>`–`<h6>` — це назва книги, розділів та підрозділів. `<p>` — абзаци. `<strong>` — важливі терміни, що рятують життя або несуть ключову суть. `<em>` — авторський наголос на слові. `<blockquote>` — виділена цитата з іншого джерела.</p>
    </section>

    <section>
      <h2>Ієрархія заголовків (h1–h6)</h2>
      <p>Заголовки формують логічний каркас документа (outline). На кожній сторінці має бути рівно один `<h1>`, а рівні не можна перескакувати (наприклад, з `<h2>` одразу на `<h4>`).</p>

      

```html
<h1>Frontend Roadmap 2026</h1>       <!-- Головний заголовок сторінки -->
  <h2>Блок 1: Основи HTML</h2>       <!-- Розділ першого рівня -->
    <h3>Текстова розмітка</h3>       <!-- Підрозділ -->
      <h4>Форматування коду</h4>     <!-- Деталізація -->
```



      <h2>Параграфи, цитати та розділювачі</h2>

      <h2>Семантичне виділення тексту</h2>
      <div className="syntax-params">
        <table className="params-table">
          <thead><tr><th>Семантичний тег</th><th>Візуальний аналог</th><th>Різниця та призначення</th></tr></thead>
          <tbody>
            <tr><td>`<strong>`</td><td>`<b>`</td><td>`<strong>` означає високу важливість (скрін-рідер змінює тон). `<b>` — суто жирний текст без семантики (наприклад, ключові слова в резюме).</td></tr>
            <tr><td>`<em>`</td><td>`<i>`</td><td>`<em>` додає смисловий наголос на слові («Я <em>це</em> зробив»). `<i>` — технічний термін, думка персонажа чи латинська назва.</td></tr>
            <tr><td>`<mark>`</td><td>—</td><td>Виділення тексту маркером (наприклад, підсвічування знайденого пошукового запиту).</td></tr>
            <tr><td>`<small>`</td><td>—</td><td>Дрібний шрифт: копірайт, юридичні застереження, примітки ліцензії.</td></tr>
            <tr><td>`<del>` / `<ins>`</td><td>`<s>`</td><td>`<del>` — видалений текст, `<ins>` — доданий текст (для історії правок/цін). `<s>` — неактуальна інформація.</td></tr>
            <tr><td>`<code>`, `<pre>`, `<kbd>`</td><td>—</td><td>`<code>` — фрагмент коду. `<pre>` — збереження пробілів та переносів. `<kbd>` — клавіші клавіатури (<kbd>Ctrl</kbd> + <kbd>C</kbd>).</td></tr>
          </tbody>
        </table>
      </div>

      <h2>Списки: ul, ol, dl</h2>
      

```html
<!-- 1. Маркований список (порядок не важливий) -->
<ul>
  <li>HTML5</li>
  <li>CSS3</li>
</ul>

<!-- 2. Нумерований список (хронологія або пріоритет) -->
<ol start="1" type="1">
  <li>Встановити редактор</li>
  <li>Створити index.html</li>
</ol>

<!-- 3. Список описів / визначень (термін + пояснення, ключ + значення) -->
<dl>
  <dt>DNS</dt>
  <dd>Система доменних імен для резолвінгу IP-адрес.</dd>
  <dt>HTTP</dt>
  <dd>Протокол передачі гіпертексту.</dd>
</dl>
```

    <section className="tip-block tip-block--warn">
      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Кілька `<h1>` на сторінці</strong> — погіршує SEO та ламає навігацію скрін-рідерів. Завжди рівно один `<h1>`.</li>
        <li><strong>Вибір заголовка заради розміру шрифту</strong> — ніколи не ставте `<h4>` замість `<h2>` лише тому, що він «менший». Розмір задається в CSS!</li>
        <li><strong>Використання `<br>` для відступів</strong> — `<br><br>` між блоками — табу. Відступи робляться виключно через CSS `margin` / `gap`.</li>
        <li><strong>Прямий текст або теги всередині `<ul>` / `<ol>`</strong> — єдиним прямим дочірнім елементом списку може бути лише `<li>`.</li>
        <li><strong>Вкладання блочних елементів у `<p>`</strong> — розміщення `<div>` або `<ul>` всередині `<p>` змусить браузер автозакрити параграф і зламати верстку.</li>
      </ul>
