  <h2>Що це таке?</h2>
  <p><strong>HTML (HyperText Markup Language)</strong> — мова розмітки, якою описується структура і зміст веб-сторінки. Кожен HTML-документ має обов'язкову базову структуру. Відхилення не завжди призводить до помилки (браузери толерантні завдяки механізму <em>error recovery</em>), але це погана практика, яка ламає доступність (a11y) та SEO.</p>

  <h2>Мінімальна правильна структура</h2>

```html
<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Моя перша веб-сторінка</title>
  </head>
  <body>
    <h1>Привіт, світе!</h1>
    <p>Це мій перший валідний HTML5 документ.</p>
  </body>
</html>
```

  <h2>Кожна частина — детально</h2>

  <h3>`<!DOCTYPE html>`</h3>
  <p>Не тег — <strong>декларація типу документа (Document Type Declaration)</strong>, яка змушує браузер працювати у сучасному Standards mode. Завжди повинна бути першим рядком будь-якого HTML файлу.</p>

  <h3>`<html lang="uk">`</h3>
  <p>Кореневий елемент. Атрибут <code>lang</code> критично важливий для скрін-рідерів людей з порушенням зору (Accessibility / a11y) та для пошукових роботів Google.</p>

  <h3>`<head>` — мета-інформація</h3>
  <div className="syntax-params">
    <table className="params-table">

      <tbody>
        <tr><td><code>&lt;meta charset="UTF-8"&gt;</code></td><td>Кодування. Без нього кирилиця перетвориться на нечитабельні символи.</td><td>Так</td></tr>
        <tr><td><code>&lt;meta name="viewport"&gt;</code></td><td>Забезпечує правильне відображення масштабу 1:1 на смартфонах.</td><td>Так</td></tr>
        <tr><td><code>&lt;title&gt;</code></td><td>Назва вкладки у браузері та заголовок у пошуковій видачі Google.</td><td>Так</td></tr>
