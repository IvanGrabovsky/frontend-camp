<Callout type="tip" title="Особливості class у JS">
  Класи в JavaScript не мають hoisted поведінки (на відміну від `function declaration`), методи класу автоматично додаються до `Prototype`, а тіло класу завжди виконується в суворому режимі (<code>"use strict"</code>).
</Callout>

<section>
  <h2>1. Базова структура класу</h2>

```javascript
class User {
  // Конструктор викликається при new User(...)
  constructor(name, email) {
    this.name = name;
    this.email = email;
  }

  // Метод екземпляра (зберігається в User.prototype)
  sayHi() {
    return `Привіт, я ${this.name}!`;
  }
}

const user = new User("Андрій", "andriy@camp.ua");
console.log(user.sayHi()); // "Привіт, я Андрій!"
console.log(typeof User);  // "function"
```

  <h2>2. Геттери, Сеттери та Обчислювані поля</h2>

```javascript
class BankAccount {
  constructor(owner, initialBalance = 0) {
    this.owner = owner;
    this._balance = initialBalance; // умовна угода про захищене поле
  }

  // Геттер
  get balance() {
    return `$${this._balance.toFixed(2)}`;
  }

  // Сеттер з валідацією
  set balance(value) {
    if (value < 0) {
      throw new Error("Баланс не може бути від'ємним!");
    }
    this._balance = value;
  }
}
```
