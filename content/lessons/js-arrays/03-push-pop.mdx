<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p>Методи `push()` та `pop()` — базові інструменти для роботи з <strong>кінцем масиву</strong>. Вони моделюють поведінку структури даних <strong>Стек (Stack / LIFO — Last In, First Out)</strong>: останній доданий елемент дістається першим.</p>
      <p>Обидва методи <strong>мутують (змінюють)</strong> оригінальний масив на місці (in-place).</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">🥞</span> Аналогія зі стосом млинців</div>
      <p>`push()` — кухар пече новий гарячий млинець і кладе його на саму гору стосу. `pop()` — ти береш верхній млинець зі стосу, щоб з'їсти його. Ти завжди взаємодієш тільки з вершиною (кінцем) стосу.</p>
    </section>

    <section>
      <h2>Синтаксис та значення, що повертаються</h2>
      

```javascript
// 1. push() — додає елементи в кінець і ПОВЕРТАЄ НОВУ ДОВЖИНУ МАСИВУ (.length)
const tasks = ['верстка', 'стилі'];
const newLength = tasks.push('скрипти');
console.log(newLength); // 3 (число, нова довжина!)
console.log(tasks);     // ['верстка', 'стилі', 'скрипти']

// Можна додавати кілька елементів за один виклик:
tasks.push('тести', 'деплой');

// 2. pop() — видаляє ОСТАННІЙ елемент і ПОВЕРТАЄ ЙОГО ЗНАЧЕННЯ
const done = tasks.pop();
console.log(done);      // 'деплой' (видалений елемент!)
console.log(tasks);     // ['верстка', 'стилі', 'скрипти', 'тести']
```

      <h2>Чому push/pop такі швидкі (O(1))?</h2>
      <p>При роботі з кінцем масиву JavaScript не потрібно перераховувати індекси інших елементів. Він просто записує значення в наступну комірку пам'яті або видаляє останню. На відміну від `shift/unshift`, які змушують зміщувати весь масив (O(n)), `push/pop` є найшвидшими операціями.</p>

    <section className="tip-block tip-block--warn">
      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Очікування, що `push()` поверне новий масив</strong> — `const res = arr.push('x')` запише в `res` число (довжину), а не оновлений масив!</li>
        <li><strong>Вкладений масив замість елементів</strong> — `arr.push([1, 2])` додасть один вкладений масив як один елемент (`[['1, 2']]`). Якщо потрібно додати всі елементи, використовуйте spread: `arr.push(...[1, 2])`.</li>
        <li><strong>Мутація стану в React / Redux</strong> — прямий виклик `state.push()` порушує незмінність (immutability). У React замість push використовуйте spread: `setItems([...items, newItem])`.</li>
      </ul>
