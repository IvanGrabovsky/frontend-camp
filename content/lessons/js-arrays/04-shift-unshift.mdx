<article className="lesson-card">
      <h2>Що це таке?</h2>
      <p>Методи `unshift()` та `shift()` призначені для роботи з <strong>початком (нульовим індексом) масиву</strong>. Вони є дзеркальними аналогами до `push()` та `pop()`, але працюють з протилежного кінця.</p>
      <p>У комбінації `push()` + `shift()` вони утворюють класичну структуру даних <strong>Черга (Queue / FIFO — First In, First Out)</strong>: перший прийшов — перший пішов.</p>
    </article>

    <section className="analogy-block">
      <div className="analogy-block__title"><span className="analogy-block__icon">🎫</span> Аналогія з чергою до каси</div>
      <p>`unshift()` — позачерговий відвідувач стає на самий початок черги перед усіма, змушуючи кожного зробити крок назад. `shift()` — перша людина в черзі купує квиток і виходить, а вся черга робить крок уперед (всі індекси зміщуються).</p>
    </section>

    <section>
      <h2>Синтаксис та поведінка</h2>
      

```javascript
// 1. unshift() — додає елементи на ПОЧАТОК масиву і ПОВЕРТАЄ НОВУ ДОВЖИНУ
const queue = ['Ольга', 'Тарас'];
const len = queue.unshift('VIP-Гість');
console.log(len);   // 3 (число, нова довжина)
console.log(queue); // ['VIP-Гість', 'Ольга', 'Тарас']

// Можна передати кілька елементів одразу (вони вставляються блоком):
queue.unshift('Гість 1', 'Гість 2');

// 2. shift() — видаляє ПЕРШИЙ елемент (з індексом 0) і ПОВЕРТАЄ ЙОГО
const served = queue.shift();
console.log(served); // 'Гість 1' (видалене значення)
console.log(queue);  // ['Гість 2', 'VIP-Гість', 'Ольга', 'Тарас']
```

      <h2>Чому shift/unshift значно повільніші за push/pop?</h2>
      <p>Масиви в пам'яті зберігаються як послідовний блок індексів. Коли ви видаляєте або додаєте елемент на початок масиву розміром 100 000 елементів, JavaScript змушений <strong>пересунути кожен окремий елемент на один індекс у пам'яті ($O(n)$ операцій)</strong>. Саме тому на великих масивах завжди надають перевагу роботі з кінцем (`push/pop`).</p>

    <section className="tip-block tip-block--warn">
      <div className="tip-block__title"><span>⚠️</span> Типові помилки</div>
      <ul>
        <li><strong>Порядок при роздільному виклику unshift</strong> — `arr.unshift('A'); arr.unshift('B');` дасть `['B', 'A']`! Якщо викликати разом: `arr.unshift('A', 'B')`, порядок збережеться: `['A', 'B']`.</li>
        <li><strong>Використання `shift()` для перебору великого масиву</strong> — цикл `while(arr.length) { arr.shift(); }` має квадратичну складність $O(n^2)$ і «повісить» вкладку на великих даних. Використовуйте звичайний `for` або `for...of`.</li>
        <li><strong>Мутація стану в React</strong> — ніколи не робіть `state.unshift(item)`. Використовуйте новий масив: `setItems([newItem, ...items])`.</li>
      </ul>
