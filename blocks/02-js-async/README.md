# Асинхронний JavaScript & Event Loop

> Глибоке занурення в асинхронність JavaScript: Event Loop, мікротаски, комбінатори промісів, скасування запитів та Web Workers.

## Про підмодуль

Підмодуль курсу **JavaScript основи**. Розкриває внутрішню кухню виконання коду в браузері та навчає писати надійний неблокуючий код.

## Програма підмодуля

1. **Як працює Event Loop та Call Stack** — стек викликів, Web APIs, Task Queue
2. **Microtasks vs Macrotasks** — черги завдань, `queueMicrotask`, пріоритети виконання
3. **Promises: життєвий цикл та ланцюжки** — створення, обробка помилок `catch/finally`
4. **Комбінатори промісів** — `Promise.all`, `allSettled`, `race`, `any`
5. **Async/Await та генератори** — синтаксичний цукор, робота з `yield`
6. **Скасування запитів через AbortController** — переривання `fetch`, таймаути
7. **Багатопоточність: Web Workers** — фонові обчислення без фризів UI
8. **Паттерни конкурентності** — обмеження одночасних запитів, `debounce` та `throttle`
