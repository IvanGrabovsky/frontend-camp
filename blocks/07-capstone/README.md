## 💡 Ідеї для фінального проекту (Варіанти для вибору)

Оберіть одну з ідей нижче або створіть власний проект на базі схожої складності. Кожен проект розрахований на демонстрацію повного спектра навичок Junior+/Middle frontend/fullstack інженера.

---

### 1. 🚀 SaaS Платформа для розробників: «DevSnippet Hub»
* **Суть:** Хмарний менеджер для збереження, версіонування, організації та публічного шарингу сніпетів коду з AI-поясненнями та тегами.
* **Ключовий функціонал:**
  * Редактор коду (Monaco Editor або CodeMirror) із підсвіткою синтаксису для 20+ мов.
  * Теги, повнотекстовий пошук та колекції сніпетів.
  * Публічні посилання з Open Graph превʼю картками (`generateMetadata`).
  * Автентифікація (GitHub OAuth) + приватні/публічні рівні доступу.
* **Чому це круто для портфоліо:** Демонструє роботу зі складними сторонніми редакторами, SEO, Server Components та безпекою.

---

### 2. ⚡ Trello/Linear-подібний Kanban та трекер задач: «FlowCraft»
* **Суть:** Інтерактивна дошка управління проектами з drag-and-drop та оновленням у реальному часі.
* **Ключовий функціонал:**
  * Перетягування карток і колонок (dnd-kit або @hello-pangea/dnd).
  * Фільтрація за пріоритетами, виконавцями та дедлайнами.
  * Оптимістичні оновлення інтерфейсу (Optimistic UI) без затримок.
  * Real-time синхронізація між вкладками/користувачами через Supabase Realtime або WebSockets.
  * Темний / світлий режим та підтримка клавіатурних скорочень (shortcuts).
* **Чому це круто для портфоліо:** Показує володіння складним локальним станом (Zustand), drag-and-drop UX та оптимістичними мутаціями.

---

### 3. 🛍️ Headless E-Commerce маркетплейс: «Nova Store»
* **Суть:** Сучасний швидкісний інтернет-магазин цифрових товарів або мерчу з кошиком, фільтрами та чекаутом.
* **Ключовий функціонал:**
  * Каталог з багатовимірною фільтрацією (ціна, категорія, рейтинг) через URL search params.
  * Персистентний кошик покупця (LocalStorage + синхронізація з БД при логіні).
  * Інтеграція тестової оплати (Stripe / LiqPay sandbox).
  * Оптимізація Core Web Vitals (LCP < 1.5s, оптимізація картинок через next/image).
  * Панель адміністратора для додавання та редагування товарів.
* **Чому це круто для портфоліо:** Класичний комерційний кейс, що демонструє роботу з кешуванням, платежами та високою швидкодією.

---

### 4. 📚 Інтерактивна навчальна платформа / LMS: «SkillForge»
* **Суть:** Платформа для проходження курсів з інтерактивними тестами, відстеженням прогресу та гейміфікацією.
* **Ключовий функціонал:**
  * MDX-рендеринг навчальних матеріалів із динамічними компонентами.
  * Відстеження прогресу проходження (completion rate, збір балів/кристалів).
  * Вікторини та практичні завдання з миттєвою перевіркою відповідей.
  * Особистий кабінет студента зі статистикою та сертифікатом про завершення.
* **Чому це круто для портфоліо:** Показує вміння будувати складні контентні системи з кастомним рендерингом та аналітикою.

---

### 5. 📊 Real-time крипто/фінансовий дашборд: «Apex Analytics»
* **Суть:** Аналітична панель моніторингу активів з інтерактивними графіками, сповіщеннями та валютним калькулятором.
* **Ключовий функціонал:**
  * Візуалізація даних через Recharts або Chart.js (свічковий графік, об'єми, динаміка).
  * Real-time оновлення цін через WebSocket або Polling з CoinGecko/Binance API.
  * Кастомний трекер особистого портфелю (додавання купівель/продажів, розрахунок P&L).
  * Експорт звітів у CSV / PDF.
* **Чому це круто для портфоліо:** Демонструє вміння працювати з важкими графіками, потоковими даними та фінансовими розрахунками.

---

### 6. 🎧 Музичний веб-плеєр / Подкаст-хаб: «WaveStream»
* **Суть:** Повнофункціональний стрімінговий веб-плеєр аудіо з плейлистами та візуалізатором.
* **Ключовий функціонал:**
  * Глобальний аудіоплеєр (грає безперервно під час переходу між сторінками).
  * Робота з Web Audio API (еквалайзер або аудіо-візуалізатор хвиль).
  * Створення та редагування користувацьких плейлистів.
  * Черга відтворення, керування швидкістю (0.75x, 1x, 1.5x, 2x) та таймер сну.
* **Чому це круто для портфоліо:** Показує глибоку роботу з HTML5 Audio API, складним глобальним стейтом та фоновим відтворенням.

---

## 📋 Обов'язкові технічні критерії для будь-якого проекту

1. **Frontend:** Next.js 15 (App Router), TypeScript (strict mode), Tailwind CSS.
2. **State Management:** Серверний стан через React Server Components / TanStack Query, клієнтський стан через Zustand.
3. **Database & Auth:** PostgreSQL (Supabase / Neon) + ORM (Prisma / Drizzle), Auth (OAuth + Email).
4. **Тестування:** Мінімум 5 Unit/Integration тестів (Vitest) + 2 E2E сценарії (Playwright).
5. **CI/CD & Deploy:** GitHub Actions пайплайн (тести + лінт) + автоматичний деплой на Vercel.
6. **Оптимізація:** Lighthouse Score 90+ за категоріями Performance, Accessibility, Best Practices, SEO.
