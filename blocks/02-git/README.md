## Про блок

Сучасна фронтенд-розробка неможлива без вміння працювати з Git та платформою GitHub у команді. У цьому блоці розбирається робочий процес від першого комміту до налаштування автоматизованих пайплайнів.

## Заплановані теми

- **Основи Git:** життєвий цикл файлів, комміти, хеші, staging area (`git status`, `diff`, `log`)
- **Стратегії гілкування:** Feature Branching, Git Flow та Trunk-Based Development
- **Злиття гілок:** Merge vs Rebase, fast-forward та аналіз історії коммітів
- **Вирішення конфліктів:** merge conflicts, робота з `git stash`, `cherry-pick` та `reflog`
- **Командна робота на GitHub:** Fork, Pull Requests, Code Review, захищені гілки
- **Автоматизація якості:** Git Hooks, Husky, lint-staged та Conventional Commits
- **GitHub Actions:** налаштування CI/CD пайплайнів, автоматичний лінтинг і тести
