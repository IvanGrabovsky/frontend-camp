> Сучасний підхід до верстки інтерфейсів за допомогою утилітарних класів, токенів дизайну, адаптивності та бібліотек компонентів на кшталт Shadcn UI.

## Про підмодуль

Підмодуль курсу **CSS**. Навчає швидко і підтримувано будувати складні адаптивні інтерфейси без перевантаження кастомними CSS-файлами.

## Програма підмодуля

1. **Utility-First підхід та налаштування** — філософія Tailwind, JIT компілятор
2. **Адаптивність та брейкпоінти** — `sm:`, `md:`, `lg:`, `xl:`
3. **Стани елементів** — `hover:`, `focus-visible:`, `dark:`, `group` та `peer`
4. **Flexbox та Grid у Tailwind** — лейаути, позиціонування та вирівнювання
5. **Кастомізація теми** — `tailwind.config`, власні кольори, шрифти, CSS-змінні
6. **Транзишени та анімації** — плавні переходи, `animate-pulse`, кастомні keyframes
7. **Shadcn UI та Radix UI примітиви** — архітектура copy-paste компонентів, `cn()`, `cva`
8. **Сучасний Tailwind CSS v4** — `@theme`, `@utility` та CSS-first конфігурація
