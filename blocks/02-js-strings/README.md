# 2. Рядки та числа в JavaScript

![Статус: Доступно](https://img.shields.io/badge/Статус-Доступно-10b981)
![Рівень: Початківець](https://img.shields.io/badge/Рівень-Початківець-38bdf8)

> Робота з числами, методами `Math`, рядками, пошуком підрядків, регулярними виразами та форматуванням `Intl` за структурою uk.javascript.info.

## Програма підмодуля (8 уроків)

1. **Числа: методи, Math та особливості float** — `toFixed`, `Math.round/ceil/floor`, `parseInt`, `NaN`, `isFinite`
2. **Рядки: доступ до символів, довжина, регістр** — `length`, `at()`, `toUpperCase()`, `toLowerCase()`
3. **Пошук підрядків у тексті** — `indexOf()`, `includes()`, `startsWith()`, `endsWith()`
4. **Отримання частини рядка та заміна** — `slice()`, `substring()`, `replace()`, `replaceAll()`
5. **Шаблонні рядки та Tagged Templates** — інтерполяція `${}`, багаторядкові рядки, теговані шаблони
6. **Регулярні вирази в рядках** — `RegExp`, методи `test()`, `match()`, `matchAll()`, `split()`
7. **Міжнародне форматування (Intl)** — `Intl.NumberFormat`, `Intl.DateTimeFormat`, валюти
8. **Практикум: текстовий процесор** — обробка, валідація та нормалізація користувацького тексту
