# 5. Просунута робота з функціями у JavaScript

![Статус: Доступно](https://img.shields.io/badge/Статус-Доступно-10b981)
![Рівень: Середній → просунутий](https://img.shields.io/badge/Рівень-Середній_→_просунутий-f59e0b)

> Рекурсія, замикання (Closures), лексичне оточення, Rest/Spread, декоратори `call`/`apply`, прив'язка контексту `bind` за структурою uk.javascript.info.

## Програма підмодуля (8 уроків)

1. **Рекурсія та стек викликів** — база рекурсії, глибина стека, стек виконання
2. **Залишкові параметри (Rest) та Spread** — `...rest` у функціях, копіювання через `...spread`
3. **Замикання (Closures) та Лексичне оточення** — як функції пам'ятають свої змінні, Lexical Environment
4. **Застарілий var та обʼєкт globalThis** — hoisting змінних, `var` vs `let/const`, кросплатформний `globalThis`
5. **Іменовані Function Expressions та new Function** — NFE для внутрішньої рекурсії, створення функцій з рядка
6. **Планування викликів: setTimeout та setInterval** — таймаути, інтервали, скасування через `clearTimeout`
7. **Декоратори та переадресація: call / apply** — зміна поведінки функцій, перенаправлення `func.apply(this, arguments)`
8. **Привʼязка контексту: func.bind()** — вирішення проблеми втрати контексту `this`, каррування (partial application)
