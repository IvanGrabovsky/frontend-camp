> Статична типізація, інтерфейси, generics, utility types та надійна типізація в React/Next.js.

## Про блок

TypeScript є промисловим стандартом у розробці сучасних веб-додатків. Цей блок навчає використовувати систему типів для запобігання багів, самодокументування коду та побудови масштабованої архітектури.

## Заплановані теми

- **Основи типізації:** примітиви, type inference, `any` vs `unknown` vs `never`, union & intersection types
- **Інтерфейси (Interfaces) vs Type Aliases:** розширення, declaration merging, readonly та optional поля
- **Дженерики (Generics):** типізація універсальних функцій, інтерфейсів та generic constraints (`extends`, `keyof`)
- **Utility Types:** `Partial`, `Required`, `Readonly`, `Record`, `Pick`, `Omit`, `ReturnType`, `Parameters`
- **Типізація функцій та асинхронності:** callback-і, Promise/async та написання кастомних Type Guards (`is`)
- **TypeScript з DOM API:** обробники подій (`SyntheticEvent`), типізація сторонніх бібліотек (`@types`)
- **TypeScript у React:** типізація Props, State, кастомних хуків та Context API
- **Конфігурація tsconfig.json:** Strict Mode, path aliases та архітектура великих типізованих проектів
