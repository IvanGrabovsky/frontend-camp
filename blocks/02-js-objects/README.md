# 4. Обʼєкти та структури даних у JavaScript

![Статус: Доступно](https://img.shields.io/badge/Статус-Доступно-10b981)
![Рівень: Середній](https://img.shields.io/badge/Рівень-Середній-38bdf8)

> Об'єкти, посилання та копіювання, контекст `this`, конструктори `new`, Map/Set, деструктуризація та JSON за структурою uk.javascript.info.

## Програма підмодуля (8 уроків)

1. **Обʼєкти: літерали, властивості та for..in** — створення об'єктів, оператор `in`, видалення `delete`
2. **Посилання, копіювання та structuredClone** — мутабельність, `Object.assign`, spread, глибоке клонування
3. **Методи обʼєкта та контекст this** — динамічний `this`, методи-скорочення, втрата контексту
4. **Функції-конструктори та оператор new** — створення інстансів, `new.target`, повернення з конструктора
5. **Опціональний ланцюжок ?. та Nullish ??** — безпечний доступ до вкладених полів `?.`, `??` vs `||`
6. **Символи (Symbol) та дескриптори властивостей** — унікальні ключі `Symbol()`, `Object.defineProperty`
7. **Колекції Map, Set, WeakMap, WeakSet** — ключ-значення будь-якого типу, унікальні множини, збирання сміття
8. **Деструктуризація обʼєктів та JSON методи** — розпакування `{ a, b }`, `JSON.stringify()`, `JSON.parse()`
