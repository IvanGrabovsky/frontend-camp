> Повний курс сучасної мови JavaScript за структурою uk.javascript.info: від базового синтаксису до асинхронності, Event Loop, DOM та патернів ООП.

## Структура курсу (8 підмодулів / 80 уроків)

1. **[1. Основи JavaScript](README.md)** (11 уроків) — введення в JS, алгоритми, спецсимволи `\n`/`\t`, змінні, оператори, цикли, функції, об'єкти, DOM, async.
2. **[2. Рядки та числа](../02-js-strings/README.md)** (8 уроків) — методи чисел, форматування, пошук підрядків, регулярні вирази, `Intl`.
3. **[3. Масиви](../03-js-arrays/README.md)** (21 урок) — усі 21 метод масивів з інтерактивними пісочницями та практикою.
4. **[4. Обʼєкти та структури даних](../02-js-objects/README.md)** (8 уроків) — `this`, `new`, `structuredClone`, `Symbol`, `Map`, `Set`, `JSON`.
5. **[5. Просунуті функції та замикання](../02-js-functions/README.md)** (8 уроків) — рекурсія, Closures, `call`/`apply`/`bind`, планування `setTimeout`.
6. **[6. Прототипи, класи та ООП](../02-js-classes/README.md)** (8 уроків) — прототипне успадкування, синтаксис `class`, приватні поля `#`, `instanceof`.
7. **[7. Асинхронний JS, Promises & Event Loop](../02-js-async/README.md)** (8 уроків) — Event Loop, Microtasks, Promises, `async`/`await`, `AbortController`.
8. **[8. DOM, події та браузерні APIs](../02-js-dom/README.md)** (8 уроків) — DOM-дерево, `querySelector`, маніпуляція вузлами, спливання подій (Bubbling).

## Програма 1-го підмодуля: Основи JavaScript (11 уроків)

1. **Що таке JavaScript та запуск коду** — історія, V8, підключення `<script>`, DevTools, `console.log`.
2. **Основи алгоритмів та логічне мислення** — властивості алгоритму, лінійні/розгалужені/циклічні структури, псевдокод, Dry Run.
3. **Спецсимволи, екранування (\n, \t) та форматування** — `\n`, `\t`, `\\`, `\'`, `\"`, Unicode, шаблонні рядки.
4. **Змінні та типи даних** — `let`, `const`, примітивні типи, `typeof`.
5. **Оператори та вирази** — арифметичні, логічні, `===`, `??`, `?.`.
6. **Умовні оператори** — `if`/`else`, тернарний оператор, `switch`.
7. **Цикли** — `for`, `while`, `for...of`, `for...in`, `break`, `continue`.
8. **Функції** — function declaration, function expression, arrow functions `=>`, параметри за замовчуванням.
9. **Об'єкти** — літерали `{ ... }`, доступ до властивостей, деструктуризація.
10. **DOM та події** — `querySelector`, `classList`, `addEventListener`.
11. **Async/Await та Fetch** — проміси, робота з API, `try`/`catch`.
