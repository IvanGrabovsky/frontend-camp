> Автоматизація життєвого циклу розробки: запуск тестів, лінтинг коду, генерація прев'ю-деплоїв та безпека за допомогою GitHub Actions.

## Про підмодуль

Підмодуль курсу **Git & Командна розробка**. Навчає створювати надійні CI/CD пайплайни, які автоматично перевіряють якість коду перед кожним злиттям у `main`.

## Програма підмодуля

1. **Вступ до GitHub Actions та Workflows** — файлова структура `.github/workflows`, тригери `push/pull_request`
2. **Синтаксис Jobs, Steps та матриці** — паралельний запуск на Node 18/20/22, `runs-on: ubuntu-latest`
3. **Секрети, змінні середовища та безпека** — робота з `secrets.GITHUB_TOKEN`, захист від витоку API-ключів
4. **Автоматизований лінтинг, тести та type-check** — `npm run lint`, `vitest run`, `tsc --noEmit`
5. **Автоматичний деплой превʼю на Pull Request** — інтеграція з Vercel та GitHub Pages
6. **Створення власних Custom Actions** — Composite Actions та JS Actions для повторного використання
7. **Автоматичні релізи та Semantic Versioning** — автоматична генерація Changelog та Git Tags
8. **Сканування вразливостей (Dependabot & CodeQL)** — статичний аналіз коду (SAST) та оновлення залежностей
