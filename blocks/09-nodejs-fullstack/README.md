> Створення повноцінних бекенд-сервісів та REST API на Node.js, робота з базами даних PostgreSQL, Prisma ORM, автентифікація, WebSockets та Docker контейнеризація.

## Про блок

Цей блок розширює вашу експертизу від Frontend до **Fullstack розробника**. Ви навчитесь самостійно проектувати бекенд-архітектуру, працювати з базами даних та підключати сучасний фронтенд на React/Next.js до власного API.

## Програма блоку

1. **Node.js Runtime & Модульна система (ESM vs CJS)** — архітектура, libuv, Event Loop, Buffer, Streams
2. **Створення HTTP серверів** — нативний Node HTTP, фреймворки Hono та Express, роутинг
3. **Проектування RESTful API** — CRUD операції, статус-коди, REST стандарти
4. **Архітектура Middleware** — валідація з Zod, CORS, обробка помилок та логування
5. **Робота з базами даних** — підключення PostgreSQL, створення міграцій з Prisma/Drizzle ORM
6. **Автентифікація на бекенді** — хешування паролів (bcrypt), генерація та перевірка JWT, Auth Middleware
7. **Real-time комунікація** — WebSockets (ws, Socket.io) та Server-Sent Events (SSE)
8. **Docker контейнеризація та Fullstack деплой** — створення Dockerfile, docker-compose, деплой на VPS / Railway
