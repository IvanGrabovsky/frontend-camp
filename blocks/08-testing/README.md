> Повний спектр тестування веб-додатків: Unit-тести на Vitest, тестування компонентів з React Testing Library та E2E з Playwright.

## Про блок

Тести дають впевненість у стабільності коду під час рефакторингу та командної розробки. Блок охоплює написання надійних тестів, що перевіряють поведінку інтерфейсу без прив'язки до внутрішніх деталей реалізації.

## Заплановані теми

- **Піраміда тестування:** баланс Unit, Integration та E2E тестів
- **Unit-тестування:** Vitest / Jest, матчери, шпигуни (spies), моки (mocks) та тестування чистої бізнес-логіки
- **React Testing Library:** тестування UI через доступні ролі (`getByRole`), події `user-event`
- **Мокування API:** робота з Mock Service Worker (MSW) для перехоплення HTTP-запитів
- **Тестування стану та хуків:** `renderHook`, тестування Context та асинхронних сайд-ефектів
- **E2E тестування з Playwright:** кросбраузерні сценарії, screenshot testing, емуляція мобільних пристроїв
- **Accessibility testing:** автоматичний аудит доступності за допомогою `axe-core`
- **CI інтеграція:** запуск тестових наборів та звітів про покриття (coverage) у GitHub Actions
