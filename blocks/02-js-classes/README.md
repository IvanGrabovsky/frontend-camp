# 6. Прототипи, класи та ООП у JavaScript

![Статус: Доступно](https://img.shields.io/badge/Статус-Доступно-10b981)
![Рівень: Середній → просунутий](https://img.shields.io/badge/Рівень-Середній_→_просунутий-f59e0b)

> Прототипне успадкування, нативні прототипи, сучасний синтаксис `class`, успадкування `extends`, приватні поля `#` та патерн Mixins за структурою uk.javascript.info.

## Програма підмодуля (8 уроків)

1. **Прототипне успадкування та __proto__** — прихована властивість `[[Prototype]]`, пошук по ланцюжку прототипів
2. **Властивість F.prototype та конструктори** — зв'язок функцій-конструкторів з прототипами
3. **Нативні прототипи та додавання поліфілів** — `Array.prototype`, `Object.prototype`, безпечне розширення
4. **Синтаксис class: методи, конструктор, геттери** — базовий синтаксис класів, методи, `get` та `set`
5. **Успадкування класів: extends та super** — перевизначення методів, виклик батьківського конструктора `super()`
6. **Статичні методи та приватні поля (#private)** — методи класу `static`, справжня інкапсуляція з `#`
7. **Перевірка типу: instanceof** — перевірка ланцюжка прототипів `instanceof` та `Symbol.hasInstance`
8. **Домішки (Mixins) та патерни ООП** — підмішування функціоналу без множинного успадкування
