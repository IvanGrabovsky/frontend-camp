# Керування станом (State Management)

> Сучасний стек керування станом у React та Next.js додатках: Zustand, TanStack Query, оптимістичні оновлення та offline-синхронізація.

## Про підмодуль

Підмодуль курсу **Next.js**. Пояснює різницю між клієнтським та серверним станом і навчає будувати швидкі, реактивні інтерфейси без зайвих ререндерів.

## Програма підмодуля

1. **Архітектура стану: Server vs Client State** — Context API, коли потрібен глобальний стейт
2. **Zustand: легкий глобальний стейт** — селектори, атомарні оновлення
3. **Zustand Middleware** — `persist` (збереження в LocalStorage), `devtools`, `immer`
4. **TanStack Query (React Query)** — кешування, фонова синхронізація `staleTime`
5. **Мутації та автоматична інвалідація** — `useMutation`, інвалідація запитів
6. **Оптимістичні оновлення** — миттєвий відгук UI та rollback при помилках
7. **Пагінація та Infinite Scroll** — `useInfiniteQuery`, курсорна пагінація
8. **Offline-first стейт** — синхронізація між вкладками через `BroadcastChannel`
