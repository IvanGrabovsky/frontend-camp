> Розбір прихованих вразливостей сучасних API: fingerprinting, клієнтські DoS, UI spoofing та CSS-only атаки.

## Про блок

Курс розглядає безпеку з точки зору фронтенд-розробника. Як сучасні браузерні API (Web Locks, Web Share, Clipboard, Vibration) можуть бути використані зловмисниками і як від цього захищатися.

## Уроки

1. **Модель безпеки браузера:** SOP, CORS, CSP, Permissions API.
2. **APIs дозволів:** Web Locks (DoS), Web Share (Clickjacking), Clipboard (Pastejacking).
3. **Device APIs:** Vibration (Hardware fingerprinting, Scareware), Screen Wake Lock (фізична безпека, DoS), EyeDropper, Picture-in-Picture.
4. **CSS та Side-channel атаки:** CSS env(), lazy-loading history sniffing, smooth scroll timing attacks.
