# 🌐 Блок 0 — Як працює інтернет

> Від натискання Enter у браузері до рендеру пікселів на екрані.

Цей блок дає фундаментальне розуміння того, що відбувається «під капотом» коли ти відкриваєш веб-сторінку. Без цих знань фронтенд-розробка — це просто натискання кнопок.

---

## Модулі

### 01 — Що відбувається коли вводиш URL у браузер

Повний шлях запиту від натискання Enter до появи сторінки на екрані.

**Крок за кроком:**

1. **Парсинг URL** — браузер розбирає введений рядок на складові:
   - `https://` → протокол (scheme)
   - `example.com` → домен (host)
   - `/about` → шлях (path)
   - `?lang=ua` → параметри запиту (query string)

2. **DNS-запит** — браузер перетворює доменне ім'я на IP-адресу:
   - Перевіряє локальний кеш браузера
   - Перевіряє кеш операційної системи
   - Звертається до DNS-резолвера провайдера
   - Резолвер йде по ланцюжку: Root → TLD (.com) → Authoritative DNS
   - Отримує IP-адресу, наприклад `93.184.216.34`

3. **TCP-з'єднання** — встановлює надійний канал зв'язку:
   - **SYN** → клієнт надсилає запит на з'єднання
   - **SYN-ACK** → сервер підтверджує
   - **ACK** → клієнт підтверджує — з'єднання встановлено (3-way handshake)

4. **TLS Handshake** (якщо HTTPS):
   - Клієнт і сервер узгоджують версію TLS та алгоритми шифрування
   - Сервер надсилає свій SSL-сертифікат
   - Генерується спільний ключ для симетричного шифрування
   - Все подальше спілкування зашифроване

5. **HTTP-запит** — браузер формує та надсилає запит:
   ```
   GET /about HTTP/1.1
   Host: example.com
   User-Agent: Chrome/120
   Accept: text/html
   Accept-Language: uk-UA
   ```

6. **Відповідь сервера**:
   ```
   HTTP/1.1 200 OK
   Content-Type: text/html; charset=UTF-8
   Content-Length: 5842
   Cache-Control: max-age=3600

   <!DOCTYPE html>
   <html>...
   ```

7. **Рендеринг** — браузер обробляє отриманий HTML:
   - **Парсинг HTML** → побудова DOM-дерева
   - **Парсинг CSS** → побудова CSSOM
   - **DOM + CSSOM** → Render Tree (тільки видимі елементи)
   - **Layout** — обчислення позицій і розмірів кожного елемента
   - **Paint** — малювання пікселів (текст, кольори, тіні, зображення)
   - **Composite** — складання шарів у фінальне зображення на GPU

8. **Додаткові запити** — браузер знаходить в HTML посилання на:
   - CSS-файли (`<link rel="stylesheet">`)
   - JavaScript (`<script>`)
   - Зображення (`<img>`)
   - Шрифти (`@font-face`)
   - І кожен ресурс проходить подібний цикл запиту

**Ключові поняття:**
- Round Trip Time (RTT) — час на повну подорож запиту і відповіді
- Time to First Byte (TTFB) — час до першого байту відповіді
- First Contentful Paint (FCP) — момент коли щось вперше з'являється на екрані
- Largest Contentful Paint (LCP) — коли найбільший елемент відрендерився
