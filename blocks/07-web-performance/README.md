## Про блок

Швидкість роботи веб-сайту напряму впливає на конверсії користувачів та SEO-ранжування в Google. У цьому блоці ви навчитесь вимірювати та виправляти вузькі місця у швидкодії додатків.

## Заплановані теми

- **Core Web Vitals:** LCP (Largest Contentful Paint), INP (Interaction to Next Paint), CLS (Cumulative Layout Shift)
- **Профілювання швидкодії:** Chrome DevTools Performance Panel, Lighthouse та збір Real User Metrics (RUM)
- **Оптимізація медіа:** AVIF/WebP, responsive `srcset`, `font-display: swap`, мінімізація SVG
- **Оптимізація бандлу:** Code Splitting, Dynamic Imports, Tree Shaking та аналіз залежностей
- **React Performance:** `memo`, `useMemo`, `useCallback`, `useTransition`, віртуалізація довгих списків
- **Критичний шлях рендерингу (CRP):** `preload`, `prefetch`, `dns-prefetch`, усунення блокуючих ресурсів
- **Кешування на клієнті та CDN:** `Cache-Control`, `ETag`, `Stale-While-Revalidate`, Service Workers
