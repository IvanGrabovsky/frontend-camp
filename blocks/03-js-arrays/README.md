## Сучасні методи (ES2022–ES2025)

| Метод | Стандарт | Урок |
|-------|----------|------|
| `at()` | ES2022 | 02 |
| `findLast()`, `findLastIndex()` | ES2023 | 09 |
| `toSorted()`, `toReversed()`, `toSpliced()`, `with()` | ES2023 | 14, 15, 05, 20 |
| `Array.fromAsync()` | ES2024 | 18 |
| `Error.isError()` | ES2025 | 18, 21 |

Сімейство **change by copy** (`toSorted`, `toReversed`, `toSpliced`, `with`) — немутуючі аналоги класичних операцій; зручні, коли оригінальний масив має лишитися незмінним.
