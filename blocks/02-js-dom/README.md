# 8. DOM, події та взаємодія з браузером

![Статус: Доступно](https://img.shields.io/badge/Статус-Доступно-10b981)
![Рівень: Початківець → середній](https://img.shields.io/badge/Рівень-Початківець_→_середній-38bdf8)

> Браузерне оточення, DOM-дерево, ефективний пошук та маніпуляції з елементами, стилі, спливання подій (Bubbling) та делегування за структурою uk.javascript.info.

## Програма підмодуля (8 уроків)

1. **Браузерне оточення: BOM, DOM та window** — глобальний об'єкт `window`, `navigator`, `location`
2. **DOM-дерево: вузли, навігація та діти** — типи вузлів, навігація по DOM (`parentElement`, `children`)
3. **Пошук елементів: querySelector, closest, matches** — сучасні методи вибірки елементів за CSS-селекторами
4. **Властивості вузлів: innerHTML, textContent** — зміна тексту, `innerHTML`, дата-атрибути `dataset`
5. **Модифікація документа: createElement, append, remove** — динамічне створення та видалення вузлів
6. **Стилі та класи: classList та getComputedStyle** — робота з CSS-класами `classList.toggle()`, читання обчислених стилів
7. **Введення у події та addEventListener** — обробники подій, об'єкт події `event`, видалення обробників
8. **Спливання, занурення та делегування подій** — фази подій, `event.stopPropagation()`, патерн Event Delegation
