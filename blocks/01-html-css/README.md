> Перший блок повного frontend-курсу. Контент у розробці.

## Про блок

Фундамент веб-розробки: як збирати структуру сторінки в HTML і оформлювати її в CSS.

## Заплановані теми

- Семантичний HTML5 (`header`, `main`, `section`, `article`)
- Текст, посилання, зображення, форми
- CSS: каскад, специфічність, box model
- Flexbox та Grid
- Адаптивна верстка (mobile-first)
- Базова доступність (a11y)
