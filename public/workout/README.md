## 📚 Теоретичний довідник

### 1. Взаємодія з користувачем у браузері (`prompt`, `alert`, `confirm`)

* **`window.alert(message)`**:
  * Відображає модальне повідомлення з кнопкою «ОК».
  * Блокує виконання JavaScript, поки користувач не закриє вікно.
  * Повертає `undefined`.
  ```javascript
  alert("Увага! Скрипт успішно запущено.");
  ```

* **`window.prompt(title, [default])`**:
  * Запитує користувача ввести текст.
  * ⚠️ **ЗАВЖДИ повертає рядок (`string`)**, навіть якщо користувач ввів `42` (буде `"42"`).
  * Якщо користувач натиснув **«Скасувати» (Cancel)** або клавішу `Esc` — повертає `null`.
  * Якщо натиснув «ОК» без введення тексту — повертає порожній рядок `""`.
  ```javascript
  const ageInput = prompt("Скільки тобі років?"); // "17" або null
  const age = Number(ageInput); // обов'язково перетворюємо на число перед математикою
  ```

* **`window.confirm(question)`**:
  * Відображає вікно з двома кнопками: «ОК» (повертає `true`) та «Скасувати» (повертає `false`).
  ```javascript
  const isAgreed = confirm("Ви погоджуєтесь із правилами?");
  ```

### 2. Рядкові методи для очищення даних (`.trim()`, `.toLowerCase()`, `.toUpperCase()`)

Коли користувачі вводять дані в `prompt()` або у форми, вони часто випадково додають зайві пробіли на початку або в кінці (`"  Тарас  "`, `" 17 "`). Без очищення це призводить до помилок при порівнянні!

* **`str.trim()`**:
  * Видаляє пробіли, символи табуляції (`\t`) та переноси рядків (`\n`) з **ОБОХ кінців** рядка.
  * **Повертає новий рядок**, оригінальний рядок залишається незмінним (рядки в JS імутабельні).
  ```javascript
  const raw = "   Київ, Україна   ";
  const clean = raw.trim(); // "Київ, Україна"
  
  // Перевірка на порожнечу (якщо ввели лише пробіли):
  const input = "     ";
  if (input.trim() === "") {
    console.log("Користувач нічого не ввів!");
  }
  ```

* **`str.toLowerCase()` та `str.toUpperCase()`**:
  * Переводить усі літери в нижній або верхній регістр. Незамінно для порівняння промокодів, email чи логінів без урахування регістру:
  ```javascript
  const email = "  Ivan.Student@GMAIL.com  ".trim().toLowerCase();
  // Результат: "ivan.student@gmail.com"
  ```

### 3. Оголошення змінних (`const` vs `let`)

* **`const`**: використовується **за замовчуванням** для всіх значень, які не будуть переприсвоюватись через оператор `=`.
* **`let`**: використовується тільки тоді, коли значення змінної буде змінюватись (наприклад, лічильник, сума, статус, прапорець).
* **`var`**: застаріле ключове слово. У сучасному JavaScript **не використовується**.

---

### 4. Інкременти, декременти та вирази присвоєння

* **`n++` (постфіксний інкремент)**: спершу повертає поточне значення `n`, а потім збільшує його на 1.
* **`++n` (префіксний інкремент)**: спершу збільшує `n` на 1, а потім повертає нове значення.
* **Комбіновані оператори присвоєння**:
  * `n += 5` те саме, що `n = n + 5`
  * `n -= 2` те саме, що `n = n - 2`
  * `n *= 3` те саме, що `n = n * 3`
  * `n /= 2` те саме, що `n = n / 2`

---

### 5. Об'єкти та масиви: Швидка шпаргалка

Коли функція повинна повернути або прийняти кілька пов'язаних значень:

* **Об'єкт (`Object`)**:
  ```javascript
  // Створення об'єкта
  const user = { name: "Олександр", role: "admin", points: 150 };

  // Читання властивостей:
  console.log(user.name); // "Олександр"
  console.log(user["role"]); // "admin"

  // Зміна властивості:
  user.points += 50; // тепер 200

  // Повернення об'єкта з функції:
  return { isTruthy: true, originalType: "string" };
  ```

* **Масив (`Array`)**:
  ```javascript
  // Створення масиву
  const items = [10, 20, 30];

  // Доступ за індексом (з нуля):
  console.log(items[0]); // 10 (перший елемент)
  console.log(items.length); // 3 (довжина масиву)

  // Перевірка, чи значення є масивом:
  Array.isArray(items); // true
  ```

### 6. Явне та неявне приведення типів (Type Coercion)

#### 6 Falsy значень у JavaScript (всі інші значення — Truthy!):
1. `false`
2. `0` та `-0`
3. `""` (порожній рядок)
4. `null`
5. `undefined`
6. `NaN` (Not a Number)

> ⚠️ **Пастки:**  
> Рядки `"0"`, `"false"`, `" "` (пробіл), порожні масиви `[]` та порожні об'єкти `{}` — це **TRUTHY**!  
> `Boolean("0") === true`  
> `Boolean([]) === true`

#### Явне приведення:
* До рядка: `String(123)` або `` `${123}` ``
* До числа: `Number("42")` або унарний плюс `+"42"`
* До булевого: `Boolean(val)` або подвійне заперечення `!!val`

#### Неявне приведення (Implicit Coercion):
* Оператор `+`: якщо хоча б один операнд рядок — виконується **конкатенація**!
  * `"5" + 2 === "52"`
* Оператори `-`, `*`, `/`: завжди приводять обидва значення до **чисел**:
  * `"10" - 2 === 8`
  * `"6" * "3" === 18`
* Числове приведення `null` та `undefined`:
  * `Number(null) === 0` (небезпечно в арифметиці!)
  * `Number(undefined) === NaN`

### 7. Оператори порівняння (`===` vs `==`)

* **Строге порівняння (`===`, `!==`)**: порівнює значення **і тип** без неявних приведень. Рекомендовано використовувати завжди!
* **Нестроге порівняння (`==`, `!=`)**: неявно приводить типи. Небезпечно:
  * `0 == false` (true)
  * `"" == 0` (true)
  * `null == undefined` (true)
* **Порівняння рядків**: порівнюються за кодами Unicode посимвольно (`"2" > "12"` повертає `true`, бо `'2' > '1'`).

---

### 8. Логічні оператори (`&&`, `||`, `!`, `??`)

* **`&&` (Логічне І)**: повертає перший *Falsy* операнд, або останній операнд, якщо всі правдиві.
* **`||` (Логічне АБО)**: повертає перший *Truthy* операнд, або останній операнд.
* **`??` (Nullish Coalescing)**: повертає праве значення ТІЛЬКИ якщо ліве є `null` або `undefined`. Зберігає `0`, `false` та `""`!
* **`!` (Логічне НЕ)**: інвертує булеве значення (`!true === false`).

---

### 9. Тернарний оператор (`? :`)

Синтаксис: `умова ? значенняЯкщоІстина : значенняЯкщоХибність`
```javascript
const access = age >= 18 ? "Дозволено" : "Заборонено";

// Вкладені тернарні оператори:
const status =
  score >= 90 ? "Відмінно"
  : score >= 75 ? "Добре"
  : score >= 60 ? "Задовільно"
  : "Незадовільно";
```

## ❓ Часті запитання (FAQ) та вирішення проблем

#### 1. У терміналі пише: `'node' is not recognized as an internal or external command`
Ви ще не встановили Node.js або після встановлення не перезапустили термінал. Завантажте Node.js з [nodejs.org](https://nodejs.org/) та повністю перезапустіть VS Code.

#### 2. Помилка: `Port 5173 is already in use`
Це означає, що сервер уже запущений в іншій вкладці або терміналі. Vite автоматично запропонує відкрити інший порт (наприклад `http://localhost:5174/`), або зупиніть попередній процес натисканням `Ctrl + C` у терміналі.

#### 3. Як зупинити запущений сервер у терміналі?
Натисніть комбінацію клавіш `Ctrl + C` у вікні терміналу, де запущено сервер.
