Box model та позиціювання

margin padding border box-sizing position

Що це таке?

Box model — це фундаментальна модель, за якою браузер розраховує розмір і відступи кожного HTML-елемента. Кожен елемент — це прямокутна «коробка» з чотирма шарами.

Position визначає, як елемент розміщується в потоці документа: чи займає він своє «законне місце», чи може «вирватися» з нього.

📦 Аналогія з пакуванням

Уяви посилку: content — це сам товар, padding — пінопластова набивка навколо нього, border — стінки коробки, margin — відстань між коробкою та сусідніми коробками на складі.

Чотири шари Box model

/* Content — сам вміст (текст, картинка) */
width: 200px; height: 100px;

/* Padding — внутрішній відступ від вмісту до рамки */
padding: 16px;               /* всі боки */
padding: 8px 16px;           /* vertical | horizontal */
padding: 8px 12px 4px 16px; /* top right bottom left */

/* Border — рамка навколо padding */
border: 2px solid #333;
border-radius: 8px;          /* закруглені кути */

/* Margin — зовнішній відступ від рамки */
margin: 24px auto;           /* center horizontally */
margin-top: 0;

box-sizing — як рахується розмір

За замовчуванням width враховує тільки content. Padding і border додаються зверху — елемент стає ширшим ніж задано. Рятує box-sizing: border-box:

/* content-box (default): width = content only */
/* width:200 + padding:20 + border:2 → реальна ширина 244px */
.el { width: 200px; padding: 20px; border: 2px solid; }

/* border-box: width = content + padding + border */
/* width: 200px → реальна ширина ЗАВЖДИ 200px */
*, *::before, *::after { box-sizing: border-box; }
.el { width: 200px; padding: 20px; border: 2px solid; }

Значення position

ЗначенняОписПотік
staticСтандартний потік (за замовчуванням)так
relativeВідносно власної початкової позиціїтак
absoluteВідносно найближчого non-static предкані
fixedВідносно вікна браузерані
stickyПрокручується до порогу, потім фіксуєтьсятак
 
/* Absolute у контейнері — класичне центрування */
.parent { position: relative; width: 300px; height: 200px; }
.child  { position: absolute; top: 50%; left: 50%;
          transform: translate(-50%, -50%); }

/* Fixed — хедер завжди видимий при скролі */
.topbar { position: fixed; top: 0; left: 0; width: 100%; z-index: 100; }

/* Sticky — заголовок «липне» при скролі */
.title { position: sticky; top: 64px; background: white; }

⚠️ Типові помилки
  • Не застосовувати box-sizing: border-box глобально — елементи «розпухають» більше за задану ширину.
  • margin: auto центрує лише горизонтально і тільки блочні елементи з заданою шириною.
  • Плутати absolute і fixed: абсолютне позиціювання залежить від батька, фіксоване — від вікна.
  • z-index не працює без position (крім static) — спочатку задай relative/absolute.
  • Margin collapsing: вертикальні margin сусідніх блоків «зливаються» — менший поглинається більшим.
⚡ Практика

Відкрий CodePen або VS Code і виконай:

  1. Створиш <div> 200×200px із padding: 20px, border: 4px solid. Яка реальна ширина з content-box? Додай box-sizing: border-box — що змінилось?
  2. Зроби картку з position: relative і кнопку «×» у правому верхньому куті через position: absolute; top: 8px; right: 8px.
  3. Зроби хедер, що «прилипає» до верху при прокрутці (sticky).
  4. Поясни різницю між margin і padding задавши фоновий колір елементу.

📋 Типові помилки на співбесідах

Питання: «Яка різниця між margin і padding?»

❌ «Padding — зовнішній, margin — внутрішній» — переплутано.

✅ Padding — внутрішній відступ (між вмістом і рамкою), фон поширюється на нього. Margin — зовнішній відступ між рамкою і сусідами, прозорий.

Питання: «Що таке box-sizing?»

❌ «Не знаю, ніколи не використовував» — при верстці це базово.

✅ box-sizing: border-box означає, що width/height включають padding і border. Стандартний reset через *, *::before, *::after { box-sizing: border-box; }.

Питання: «Як зробити sticky header?»

❌ position: fixed — хедер вирвався з потоку, контент «залізе» під нього.

✅ position: sticky; top: 0 — залишається в потоці до порогу, потім «липне». Не треба окремо додавати margin-top до контенту.

✨ Цікаві фішки
  • outline — як border, але не займає місця в box model. Ідеальний для дебагу: * { outline: 1px solid red; }
  • margin: auto у Flexbox розтягується у обох напрямах — класичний спосіб «відштовхнути» елемент до краю контейнера.
  • Щоб убезпечитись від margin collapsing — використовуй Flexbox/Grid (де collapsing не відбувається).
  • inset: 0 — shorthand для top:0; right:0; bottom:0; left:0. Розтягне absolute/fixed на весь батьківський блок.
