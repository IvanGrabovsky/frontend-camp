flat() та flatMap()

flat() flatMap()

Що це таке?

flat(depth) «розгортає» вкладені масиви на вказану глибину (за замовчуванням 1). flatMap(callback) — це map + flat(1) в одному кроці: для кожного елемента викликає callback і одразу розгортає його результат на один рівень.

Callback у flatMap: (element, index, array) => …. Зазвичай повертає масив — тоді його елементи «вливаються» в результат (наприклад, s.split(' ') дає масив слів). Якщо поверне одне значення (число, рядок), воно потрапить у результат як один елемент, без розгортання.

🪆 Аналогія з життя

Це як матрьошка. flat(1) — розкрив одну матрьошку. flat(2) — ще одну всередині. flat(Infinity) — розкрив усі, поки не залишиться плоский список.

Синтаксис

array.flat(depth)              // depth за замовчуванням = 1
array.flat(Infinity)           // будь-яка глибина
array.flatMap((element, index, array) => [ ... ])  // callback → масив, flat(1)

Параметри методів

* У flatMap аргументи element, index, array — це параметри callback, а не самого методу. Callback зазвичай повертає масив; результат кожного виклику розгортається на 1 рівень і зливається в один масив.

Як це працює

  1. flat проходить масив і «витягує» вкладені масиви на один рівень (або більше, якщо вказано depth). Callback не потрібен.
  2. flatMap для кожного елемента викликає callback з аргументами (element, index, array).
  3. Callback має повернути масив — його елементи додаються в результат і розгортаються на 1 рівень (як flat(1)).
  4. Якщо callback поверне не масив, а одне значення — воно потрапить у результат як один елемент (як у map).
  5. flatMap ефективніший за map().flat(), бо робить обидві операції за один прохід. Оригінальний масив не змінюється.

Приклади

// Приклад 1: різна глибина flat
const nested = [1, [2, 3], [4, [5, 6]]];
console.log(nested.flat());       // [1, 2, 3, 4, [5, 6]]
console.log(nested.flat(2));      // [1, 2, 3, 4, 5, 6]
console.log(nested.flat(Infinity)); // [1, 2, 3, 4, 5, 6]
// Приклад 2: flatMap — розбити речення на слова
const sentences = ['Привіт світ', 'Добрий день'];
const words = sentences.flatMap(s => s.split(' '));
console.log(words); // ['Привіт', 'світ', 'Добрий', 'день']
// Приклад 3: категорії товарів → один плоский список
const categories = [
  ['молоко', 'сир'],
  ['хліб', 'булка'],
  ['яблуко', 'банан'],
];
console.log(categories.flat());
// ['молоко', 'сир', 'хліб', 'булка', 'яблуко', 'банан']

Необовʼязкові параметри в дії

depth у flat необовʼязковий (за замовчуванням 1). Збільшуй глибину, коли масив вкладений на кілька рівнів.

const nested = [1, [2, [3, [4]]]];
console.log(nested.flat());         // [1, 2, [3, [4]]] — depth 1
console.log(nested.flat(2));        // [1, 2, 3, [4]]   — depth 2
console.log(nested.flat(Infinity)); // [1, 2, 3, 4]     — усе

// flatMap: index — додати номер до кожного рядка
const lines = ['перший', 'другий'];
console.log(lines.flatMap((line, index) => [`${index + 1}.`, line]));
// ['1.', 'перший', '2.', 'другий']
⚠️ Типові помилки
  • Очікувати, що flat(1) розгорне глибоко вкладені масиви — потрібна більша глибина або Infinity.
  • Плутати flatMap з map: якщо callback не повертає масив, результат такий самий як у map.
  • Використовувати flat().map() замість flatMap, коли достатньо одного рівня — це зайве.
