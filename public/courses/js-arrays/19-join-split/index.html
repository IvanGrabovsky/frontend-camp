join() та String.split()

join() split()

Що це таке?

array.join(separator) зʼєднує елементи масиву в один рядок. string.split(separator, limit) розбиває рядок на масив. Це зворотні операції — як дві сторони однієї медалі.

📿 Аналогія з життя

join — нанизати намистини на нитку між ними. split — розрізати нитку в місцях розділювача і отримати окремі намистини назад.

Синтаксис

array.join(separator)           // масив → рядок
string.split(separator, limit)  // рядок → масив

Параметри методів

Метод / параметрОбовʼязковий?Опис
join(separator)необовʼязковийРозділювач між елементами (за замовчуванням ',')
split(separator)обовʼязковий*Рядок або regex для розбиття (*можна передати '' для символів)
limitнеобовʼязковийМаксимальна кількість частин у результаті

Офіційна документація (MDN)

Як це працює

  1. join вставляє separator між кожною парою елементів (за замовчуванням — кома).
  2. split шукає розділювач і «різе» рядок; порожні частини теж потрапляють у масив.
  3. Разом вони будують CSV, HTML, SQL-запити та URL-slug.
  4. split('') розбиває рядок на окремі символи — зручно для роботи з текстом.

Приклади

// Приклад 1: join — зʼєднати міста та дату
console.log(['Київ', 'Львів', 'Одеса'].join(', '));
// 'Київ, Львів, Одеса'
console.log(['2024', '01', '15'].join('-')); // '2024-01-15'
// Приклад 2: split — розбити рядок
console.log('Привіт, Світ!'.split(', ')); // ['Привіт', 'Світ!']
console.log('a,b,,c'.split(','));       // ['a', 'b', '', 'c']
// Приклад 3: slug з заголовка
const title = 'Hello World';
const slug = title.toLowerCase().split(' ').join('-');
console.log(slug); // 'hello-world'
// HTML-навігація
const nav = ['Home', 'About'].map(i => `<a>${i}</a>`).join(' | ');

Необовʼязкові параметри в дії

separator у join і limit у split необовʼязкові: без розділювача join зʼєднує комами; limit обрізає кількість частин.

// join() — separator за замовчуванням ','
console.log(['2026', '08', '08'].join());   // '2026,08,08'
console.log(['2026', '08', '08'].join('-')); // '2026-08-08'

// split(separator, limit) — limit = макс. частин
const path = 'users/ivan/posts/1/comments';
console.log(path.split('/'));      // усі 5 частин
console.log(path.split('/', 3));   // ['users', 'ivan', 'posts']

// Корисно: взяти лише домен і імʼя, без решти
⚠️ Типові помилки
  • split з порожнім рядком-розділювачем дає масив символів — це очікувано, але іноді дивує.
  • Забути, що join перетворює елементи в рядки: [1,2,3].join('') → '123'.
  • CSV з комами всередині полів потребує лапок — простий split(',') не завжди достатньо.
