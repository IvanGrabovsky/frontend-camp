filter() — відбір за умовою

filter()

Що це таке?

filter() створює новий масив лише з тих елементів, для яких callback повернув true. Оригінал не змінюється. Якщо нічого не пройшло — повертається порожній масив.

Callback: (element, index, array) => boolean — true залишає елемент, false відкидає.

☕ Аналогія з життя

Це кавовий фільтр: рідка кава проходить, а гуща залишається. Ти задаєш умову «що пропускати» — і на виході тільки потрібне. Наприклад, зі списку студентів залишити лише повнолітніх.

Синтаксис

const result = array.filter((element, index, array) => умова)
// умова повертає true → елемент лишається
// умова повертає false → елемент відкидається

Параметри filter()

* element, index, array — аргументи callback, а не методу масиву. У callback element завжди передається; index і array — за потреби.

ПараметрОбовʼязковий?Опис
callbackобовʼязковийФункція-умова: (element, index, array) => boolean — повертає true (залишити) або false (відкинути)
index, arrayнеобовʼязковіІндекс і посилання на масив — аргументи callback
thisArgнеобовʼязковийЗначення this всередині callback

Офіційна документація (MDN)

  • Array.prototype.filter() — MDN

Як це працює

  1. Метод проходить кожен елемент і викликає callback.
  2. Callback має повернути true (залишити) або false (прибрати).
  3. Усі «true»-елементи потрапляють у новий масив у тому ж порядку.
  4. Оригінальний масив залишається незмінним.

Ланцюжки методів (chaining)

Оскільки filter повертає масив, до нього можна одразу приєднати .map() чи .reduce() (уроки 11–12): arr.filter(...).map(...).

Приклади

// Приклад 1: товари в наявності
const products = [
  { name: 'Ноутбук', price: 25000, inStock: true },
  { name: 'Мишка', price: 500, inStock: false },
  { name: 'Клавіатура', price: 1200, inStock: true },
];
const available = products.filter(p => p.inStock);
console.log(available.length); // 2
// Приклад 2: доступні за ціною
const affordable = products.filter(p => p.price < 2000);
console.log(affordable.map(p => p.name)); // ['Мишка', 'Клавіатура']
// Приклад 3: прибрати «фальшиві» значення
const messy = [0, 1, '', 'текст', null, 5, undefined];
const clean = messy.filter(Boolean); // хитрий трюк
console.log(clean); // [1, 'текст', 5]

Необовʼязкові параметри в дії

У callback необовʼязковий index — зручно, коли умова залежить від позиції, а не лише від значення.

const nums = [10, 20, 30, 40, 50, 60];

// Залишити елементи на парних індексах (0, 2, 4…)
const evenPositions = nums.filter((_, index) => index % 2 === 0);
console.log(evenPositions); // [10, 30, 50]

// Пропустити перший елемент (наприклад, заголовок)
const rows = ['Імʼя', 'Аня', 'Борис', 'Вася'];
const names = rows.filter((_, index) => index > 0);
console.log(names); // ['Аня', 'Борис', 'Вася']
⚠️ Типові помилки
  • Плутати filter (кілька елементів) із find (один елемент).
  • Забути return у callback із фігурними дужками — тоді все відкидається.
  • Думати, що filter мутує масив — ні, він завжди повертає новий.
