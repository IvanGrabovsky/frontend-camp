sort() — сортування масивів

sort() toSorted() compareFn

Що це таке?

sort() сортує елементи масиву на місці (мутує оригінал) і повертає посилання на той самий масив. Без функції порівняння сортування лексикографічне — як у словнику, символ за символом.

Callback compareFn(a, b) порівнює два елементи і повертає число: < 0 — a раніше, > 0 — b раніше, 0 — порядок не важливий.

📚 Аналогія з життя

Це як сортування карток у бібліотеці — за алфавітом або за роком видання. Ти розкладаєш картки в потрібному порядку прямо на полиці, змінюючи їх розташування.

Синтаксис

array.sort()                    // лексикографічне (не для чисел!)
array.sort((a, b) => a - b)     // числа за зростанням
array.sort((a, b) => b - a)     // числа за спаданням
array.toSorted((a, b) => a - b) // новий масив, без мутації (ES2023)
array.sort((a, b) => a.localeCompare(b, 'uk')) // рядки українською

Параметри sort()

* compareFn(a, b) — callback порівняння: отримує два елементи масиву й повертає число (< 0, 0 або > 0), а не boolean.

Як це працює

  1. compareFn(a, b) повертає відʼємне число, якщо a має бути раніше за b.
  2. Повертає додатне — якщо b має бути раніше.
  3. Повертає 0 — якщо порядок не важливий.
  4. Для чисел найпростіше: (a, b) => a - b (зростання).

Стабільне сортування

У сучасному JavaScript (ES2019+) sort є стабільним: елементи з однаковим ключем зберігають свій відносний порядок.

toSorted() — без мутації (ES2023)

toSorted(compareFn) приймає той самий callback, що й sort, але повертає новий відсортований масив. Оригінал не змінюється — зручно для ДЗ «не мутуй масив» і для ланцюжків методів.

Приклади

// Приклад 1: ПАСТКА — sort без compareFn для чисел
console.log([10, 9, 2, 1, 100].sort());
// [1, 10, 100, 2, 9] ← НЕПРАВИЛЬНО!

// ПРАВИЛЬНО:
console.log([10, 9, 2, 1, 100].sort((a, b) => a - b));
// [1, 2, 9, 10, 100]
// Приклад 2: рядки за алфавітом (українською)
const names = ['Борис', 'Аня', 'Галя'];
names.sort((a, b) => a.localeCompare(b, 'uk'));
console.log(names); // ['Аня', 'Борис', 'Галя']
// Приклад 3: сортування обʼєктів за полем
const users = [
  { name: 'Вася', age: 25 },
  { name: 'Аня', age: 20 },
  { name: 'Борис', age: 30 },
];
users.sort((a, b) => a.age - b.age);
console.log(users.map(u => u.name)); // ['Аня', 'Вася', 'Борис']

Необовʼязкові параметри в дії

compareFn синтаксично необовʼязковий: для рядків часто достатньо sort() без аргументів, але для чисел і обʼєктів без нього результат буде некоректним.

// Без compareFn — рядки сортуються нормально
const fruits = ['банан', 'апельсин', 'яблуко'];
console.log([...fruits].sort()); // ['апельсин', 'банан', 'яблуко']

// Без compareFn — числа сортуються як рядки!
console.log([10, 2, 30].sort()); // [10, 2, 30] — не за зростанням

// З compareFn — правильно
console.log([10, 2, 30].sort((a, b) => a - b)); // [2, 10, 30]
⚠️ Типові помилки
  • Сортувати числа без compareFn — результат буде лексикографічним, не числовим.
  • Забути, що sort мутує оригінал. Для копії: [...arr].sort(...).
  • Сортувати рядки без localeCompare — може бути некоректно для українських літер.
