splice() — видалення, вставка, заміна

splice() toSpliced()

Що це таке?

splice() — універсальний метод, який дозволяє видаляти, вставляти та замінювати елементи в будь-якому місці масиву. Він мутує оригінал і повертає масив видалених елементів.

🎬 Аналогія з життя

Це як ножиці та клей для монтажу відео. Ти можеш вирізати фрагмент (видалення), вставити новий кліп у певне місце (додавання) або замінити старий шматок новим (заміна) — усе на тій самій «стрічці».

Синтаксис

array.splice(start, deleteCount, ...items)
// start        — з якого індексу почати
// deleteCount  — скільки елементів видалити
// ...items     — що вставити на це місце (необовʼязково)

Параметри splice()

ПараметрОбовʼязковий?Опис
startобовʼязковийІндекс, з якого почати зміни
deleteCountнеобовʼязковийСкільки елементів видалити (0 = лише вставка)
...itemsнеобовʼязковийПотрібен лише для вставки або заміни (при чистому видаленні не передають)

Офіційна документація (MDN)

  • Array.prototype.splice() — MDN
  • Array.prototype.toSpliced() — MDN (ES2023)

Як це працює

  1. Тільки видалення: splice(2, 1) — прибрати 1 елемент з індексу 2.
  2. Тільки вставка: splice(2, 0, 'нове') — deleteCount = 0, вставляємо без видалення.
  3. Заміна: splice(2, 1, 'нове') — видалити 1 і на його місце вставити нове.
  4. Повертає масив видалених елементів (порожній, якщо нічого не видалили).

Приклади

// Приклад 1: видалення
const playlist = ['рок', 'поп', 'джаз', 'класика'];
const removed = playlist.splice(1, 1); // видалили 'поп'
console.log(playlist); // ['рок', 'джаз', 'класика']
console.log(removed);  // ['поп']
// Приклад 2: вставка без видалення
const playlist = ['рок', 'джаз', 'класика'];
playlist.splice(1, 0, 'електро'); // вставили на індекс 1
console.log(playlist); // ['рок', 'електро', 'джаз', 'класика']
// Приклад 3: заміна
const playlist = ['рок', 'електро', 'джаз', 'класика'];
playlist.splice(2, 1, 'хіп-хоп'); // замінили 'джаз'
console.log(playlist); // ['рок', 'електро', 'хіп-хоп', 'класика']

Необовʼязкові параметри в дії

deleteCount і ...items можна не передавати — але тоді splice поводиться інакше. Без ...items лише видаляє; без deleteCount видаляє до кінця масиву.

// Лише видалення — ...items не потрібен
const nums = [1, 2, 3, 4, 5];
nums.splice(1, 2); // видалили 2 і 3
console.log(nums); // [1, 4, 5]

// ПASTKA: deleteCount пропущено — видалить усе від індексу 2
const arr = ['a', 'b', 'c', 'd', 'e'];
arr.splice(2);
console.log(arr); // ['a', 'b'] — 'c', 'd', 'e' зникли
⚠️ Типові помилки
  • Плутати splice (мутує, розглядаємо зараз) зі slice (копіює, урок 06). Назви схожі — дії різні!
  • Забути deleteCount: splice(2) видалить усе від індексу 2 до кінця.
  • Очікувати, що метод поверне оновлений масив — він повертає лише видалені елементи.
