shift() та unshift() — робота з початком масиву

shift() unshift()

Що це таке?

unshift() додає елементи на початок масиву й повертає нову довжину. shift() видаляє перший елемент і повертає його.

Це «дзеркальні» методи до push/pop, але працюють з іншого кінця. Обидва мутують масив.

🎫 Аналогія з життя

Уяви чергу в касу. unshift — хтось із терміновою справою залазить на самий початок. shift — перша людина обслужилась і пішла, а вся черга посунулась уперед.

Синтаксис

array.unshift(item)        // додати на початок → нова довжина
const first = array.shift() // видалити перший → його значення

Параметри методів

Метод / параметрОбовʼязковий?Опис
unshift(...items)обовʼязковийХоча б один елемент для вставки на початок (виклик без аргументів нічого не додасть)
shift()—Без параметрів — видаляє перший елемент

Офіційна документація (MDN)

  • Array.prototype.unshift() — MDN
  • Array.prototype.shift() — MDN

Як це працює

  1. unshift вставляє елемент(и) перед поточним першим.
  2. Усі інші елементи «зсуваються» на одну позицію праворуч (їхні індекси зростають).
  3. shift прибирає перший елемент, а решта зсувається ліворуч.
  4. Саме через це зсування shift/unshift повільніші за push/pop.

Порівняння з push / pop (продуктивність)

МетодКінець масиву?СкладністьЧому
push / popТакO(1)Нічого не зсувається
unshift / shiftНі (початок)O(n)Треба перенумерувати всі елементи

Приклади

// Приклад 1: черга підтримки
const queue = ['Аліна', 'Богдан'];
queue.unshift('Термінове питання'); // VIP попереду
const served = queue.shift();       // обслужили першого
console.log(served);  // 'Термінове питання'
console.log(queue);   // ['Аліна', 'Богдан']
// Приклад 2: unshift повертає нову довжину
const days = ['вт', 'ср'];
const len = days.unshift('пн');
console.log(len);   // 3
console.log(days);  // ['пн', 'вт', 'ср']
// Приклад 3: shift у циклі обробки задач
const tasks = ['A', 'B', 'C'];
while (tasks.length > 0) {
  const current = tasks.shift();
  console.log('Виконую:', current);
}
⚠️ Типові помилки
  • Використовувати shift/unshift у великих масивах у циклі — це повільно (O(n) на кожен виклик).
  • Плутати напрямок: shift — з початку, pop — з кінця.
  • Очікувати, що unshift поверне масив — він повертає число.

Завдання 1 — черга клієнтів

        
❌ «Обслужити першого» через pop() — це останній у списку, не перший.

        
✅ Додавання в кінець: push. Обслуга першого: shift(). Покажи масив до і після.

      

      

        
Завдання 2 — вставка на початок без unshift

        
❌ Плутають аргументи splice: забувають deleteCount = 0 і випадково видаляють елементи.

        
✅ arr.splice(0, 0, 'новий') або arr = ['новий', ...arr] — обидва варіанти зараховуються.

      

      

        
Завдання 3 — shift vs pop

        
❌ Пишуть, що обидва «видаляють елемент», не вказуючи з якого кінця.

        
✅ shift — перший (індекс 0), pop — останній. Обидва повертають видалене значення.

      

      

    


    

      
✨ Цікаві фішки

      
    
        
  • unshift і shift повільніші на великих масивах — перенумеровують усі індекси.
    • 
        
  • Черга (FIFO): push + shift. Стек: push + pop.
    • 
        
  • На маленьких масивах різниця не помітна — для навчання використовуй що зручніше.
