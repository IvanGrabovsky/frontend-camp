indexOf(), lastIndexOf(), includes()

indexOf() lastIndexOf() includes()

Що це таке?

Ці методи відповідають на питання «де» і «чи є». indexOf повертає індекс першого входження значення (або -1). lastIndexOf — індекс останнього входження. includes повертає true/false.

📖 Аналогія з життя

Ти шукаєш слово в книзі. indexOf — «на якій сторінці воно вперше зустрічається?». lastIndexOf — «а де востаннє?». includes — «а воно взагалі є в книзі?».

Синтаксис

array.indexOf(value, fromIndex)  // перший індекс або -1
array.lastIndexOf(value)         // останній індекс або -1
array.includes(value)            // true / false

Як це працює

  1. indexOf шукає зліва направо й повертає перший знайдений індекс.
  2. Необовʼязковий fromIndex — з якої позиції почати пошук.
  3. lastIndexOf шукає справа наліво.
  4. Порівняння відбувається строго (===), тому '2' і 2 — різні.

Особливість з NaN

indexOf не знаходить NaN (бо NaN === NaN завжди false), а includes — знаходить. Це головна практична відмінність між ними.

Приклади

// Приклад 1: пошук фрукта
const fruits = ['яблуко', 'банан', 'апельсин', 'банан'];
console.log(fruits.indexOf('банан'));     // 1
console.log(fruits.lastIndexOf('банан')); // 3
console.log(fruits.includes('кавун'));    // false
// Приклад 2: перевірка наявності перед дією
const cart = ['молоко', 'хліб'];
if (!cart.includes('яйця')) {
  cart.push('яйця');
}
console.log(cart); // ['молоко', 'хліб', 'яйця']
// Приклад 3: різниця з NaN
const nums = [1, NaN, 3];
console.log(nums.indexOf(NaN));   // -1 (не знайшов!)
console.log(nums.includes(NaN));  // true (знайшов)

Необовʼязкові параметри в дії

fromIndex необовʼязковий — з ним пошук починається не з нуля, а з указаної позиції. Корисно для дублікатів і «наступного входження».

const tags = ['js', 'css', 'js', 'html', 'js'];
console.log(tags.indexOf('js'));     // 0 — перше
console.log(tags.indexOf('js', 1));  // 2 — друге (після індексу 0)
console.log(tags.indexOf('js', 3));  // 4 — третє

// includes теж приймає fromIndex
console.log(tags.includes('js', 2)); // true — є після індексу 2
⚠️ Типові помилки
  • Забути, що indexOf повертає -1, а не false, коли нічого не знайдено.
  • Шукати обʼєкти: [{}].indexOf({}) → -1, бо це різні посилання. Для обʼєктів використовуй find (урок 09).
  • Плутати перевірку: if (arr.indexOf(x)) хибне, коли x на індексі 0. Краще includes або !== -1.
