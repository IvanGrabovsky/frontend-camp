map() — трансформація елементів

map()

Що це таке?

map() створює новий масив тієї ж довжини, де кожен елемент — результат перетворення відповідного елемента оригіналу. Оригінал не змінюється.

Callback: (element, index, array) => newValue — повернуте значення стає елементом нового масиву на тій самій позиції.

🏭 Аналогія з життя

Уяви конвеєр на заводі: кожна деталь проходить через одну й ту саму операцію та виходить перетвореною. Кількість деталей на виході така сама, як і на вході — просто кожна змінилась.

Синтаксис

const result = array.map((element, index, array) => новеЗначення)

Параметри map()

* element, index, array — аргументи callback, а не методу масиву. У callback element завжди передається; index і array — за потреби.

Як це працює

  1. Метод перебирає кожен елемент і викликає callback.
  2. Те, що повертає callback, стає новим елементом.
  3. Довжина результату завжди дорівнює довжині оригіналу.
  4. Порядок елементів зберігається.

map vs forEach

Головна різниця: map повертає новий масив, а forEach (урок 13) нічого не повертає й потрібен лише для побічних дій. Якщо тобі потрібен результат-масив — це map.

Приклади

// Приклад 1: додати податок до цін
const prices = [100, 200, 300];
const withTax = prices.map(p => p * 1.2);
console.log(withTax); // [120, 240, 360]
// Приклад 2: витягти одне поле з обʼєктів
const users = [{ name: 'Аня' }, { name: 'Борис' }];
const names = users.map(u => u.name);
console.log(names); // ['Аня', 'Борис']
// Приклад 3: згенерувати HTML-розмітку
const users = [{ name: 'Аня' }, { name: 'Борис' }];
const cards = users.map(u => `<div>${u.name}</div>`);
console.log(cards.join(''));

Необовʼязкові параметри в дії

У callback необовʼязковий index — часто використовують для нумерації, чергування стилів або формування ключів.

const tasks = ['Купити молоко', 'Зробити ДЗ', 'Повторити map'];
const numbered = tasks.map((task, index) => `${index + 1}. ${task}`);
console.log(numbered);
// ['1. Купити молоко', '2. Зробити ДЗ', '3. Повторити map']

// Чергування класів для UI
const cssClasses = tasks.map((_, index) =>
  index % 2 === 0 ? 'row-even' : 'row-odd'
);
console.log(cssClasses); // ['row-even', 'row-odd', 'row-even']
⚠️ Типові помилки
  • Використовувати map, коли результат не потрібен — тоді краще forEach.
  • Забути return у callback із фігурними дужками → масив із undefined.
  • Очікувати іншу довжину: map завжди повертає стільки ж елементів. Для відсіву використовуй filter.

📋 Розбір ДЗ — типові помилки

      
Ніби ревʼю після здачі домашки: що часто плутають і як виправити. Як рахуються кристали →

      

      

        
Завдання 1 — Цельсій → Фаренгейт

        
❌ Забувають дужки в формулі: c * 9/5 + 32 ок, але іноді пишуть c * 9/5 + 32 з цілим діленням помилково або мутують celsius.

        
✅ celsius.map(c => c * 9 / 5 + 32) — новий масив, вихідний без змін.

      

      

        
Завдання 2 — велика літера

        
❌ Роблять тільки toUpperCase() для всього рядка → 'АНЯ' замість 'Аня'.

        
✅ n[0].toUpperCase() + n.slice(1) або перевір, що перша літера велика, решта — малі.

      

      

        
Завдання 3 — «Прізвище Імʼя»

        
❌ Плутають порядок полів: firstName + lastName без пробілу або навпаки.

        
✅ people.map(p => `${p.lastName} ${p.firstName}`) — шаблонний рядок з пробілом.
