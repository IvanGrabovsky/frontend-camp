concat() — обʼєднання масивів

concat() spread ...

Що це таке?

concat() зʼєднує два або більше масивів у новий масив. Оригінали не змінюються. Можна передавати як масиви, так і окремі значення.

🧾 Аналогія з життя

Уяви, що ти та твій сусід склали окремі списки покупок. Перед походом у магазин ви зшиваєте їх в один великий список — це і є concat.

Синтаксис

array1.concat(array2)              // два масиви
array1.concat(array2, array3)      // кілька масивів
array1.concat('окремий елемент')   // і навіть значення

Параметри concat()

ПараметрОбовʼязковий?Опис
...itemsнеобовʼязковийБез аргументів поверне копію масиву; зазвичай передають хоча б один масив або значення

Офіційна документація (MDN)

  • Array.prototype.concat() — MDN
  • Spread syntax (...) — MDN

Як це працює

  1. Створюється новий масив, куди по черзі копіюються елементи всіх аргументів.
  2. Якщо аргумент — масив, його елементи «розпаковуються» на один рівень.
  3. Якщо аргумент — окреме значення, воно додається як є.
  4. Оригінальні масиви залишаються незмінними.

Альтернатива: spread-оператор

Сучасний і дуже читабельний спосіб — spread [...arr1, ...arr2] (детально в уроці 20). Результат такий самий, тому обирай, що подобається.

Приклади

// Приклад 1: обʼєднання двох груп
const juniors = ['Аня', 'Борис'];
const seniors = ['Вася', 'Галя'];
const all = juniors.concat(seniors);
console.log(all); // ['Аня', 'Борис', 'Вася', 'Галя']
// Приклад 2: те саме через spread
const juniors = ['Аня', 'Борис'];
const seniors = ['Вася', 'Галя'];
const all = [...juniors, ...seniors, 'Куратор'];
console.log(all);
// Приклад 3: concat НЕ розгортає вкладені масиви глибоко
const a = [1, 2];
const b = [[3, 4]];
console.log(a.concat(b)); // [1, 2, [3, 4]] — вкладений лишився

Необовʼязкові параметри в дії

...items необовʼязковий: виклик concat() без аргументів повертає копію масиву — зручно перед змінами.

const original = [1, 2, 3];
const copy = original.concat(); // без ...items
copy.push(4);
console.log(original); // [1, 2, 3] — не змінився
console.log(copy);     // [1, 2, 3, 4]
⚠️ Типові помилки
  • concat розпаковує масиви лише на один рівень. Для глибокого розгортання є flat (урок 16).
  • Думати, що concat змінює перший масив — ні, він повертає новий.
  • Не присвоїти результат: a.concat(b); без збереження — результат втрачається.
