find() та findIndex()

find() findIndex() findLast()

Що це таке?

find() повертає перший елемент, для якого callback повернув true, або undefined. findIndex() повертає його індекс (або -1).

Callback: (element, index, array) => boolean — true означає «знайшов», false — «продовжуй пошук».

На відміну від indexOf, тут ти задаєш власну умову — тому це ідеально для обʼєктів і складних перевірок.

🗂️ Аналогія з життя

Уяви базу клієнтів. Ти не просто питаєш «чи є клієнт», а кажеш: «знайди мені першого клієнта старшого за 18 років» — і отримуєш сам обʼєкт клієнта з усіма даними.

Синтаксис

array.find((element, index, array) => умова)
array.findIndex((element) => умова)
array.findLast((element) => умова)       // з кінця (ES2023)
array.findLastIndex((element) => умова)  // індекс з кінця

Параметри callback

* element, index, array — аргументи callback, а не методу масиву. У callback element завжди передається; index і array — за потреби.

ПараметрОбовʼязковий?Опис
callbackобовʼязковийФункція-умова: (element, index, array) => boolean
indexнеобовʼязковийІндекс поточного елемента
arrayнеобовʼязковийПосилання на весь масив
thisArgнеобовʼязковийЗначення this всередині callback

Як це працює

  1. Метод перебирає елементи й викликає для кожного твій callback.
  2. Як тільки callback поверне true — пошук зупиняється (коротке замикання).
  3. find повертає сам елемент, findIndex — його позицію.
  4. findLast/findLastIndex роблять те саме, але з кінця масиву.

Коли find, а коли indexOf?

Використовуй indexOf/includes для простих значень (число, рядок). Використовуй find/findIndex, коли шукаєш обʼєкт або маєш складну умову.

Приклади

// Приклад 1: перший повнолітній користувач
const users = [
  { id: 1, name: 'Аня', age: 20 },
  { id: 2, name: 'Борис', age: 17 },
  { id: 3, name: 'Вася', age: 25 },
];
const adult = users.find(u => u.age >= 18);
console.log(adult); // { id: 1, name: 'Аня', age: 20 }
// Приклад 2: індекс першого неповнолітнього
const minorIdx = users.findIndex(u => u.age < 18);
console.log(minorIdx); // 1
// Приклад 3: нічого не знайдено
const found = users.find(u => u.age > 100);
console.log(found); // undefined
// Тому перед використанням перевіряй результат:
if (found) { console.log(found.name); }

Необовʼязкові параметри в дії

У callback необовʼязковий index — знадобиться, коли шукаєш не перше, а наступне входження або елемент після певної позиції.

const prices = [100, 250, 180, 250, 90];

// find — перший дорогий товар
console.log(prices.find(p => p > 200)); // 250

// findIndex + index — другий товар > 200
const secondIdx = prices.findIndex((p, i) => p > 200 && i > 0);
console.log(secondIdx); // 3
⚠️ Типові помилки
  • Не перевірити результат find на undefined перед зверненням до його полів → помилка.
  • Плутати find (повертає елемент) із findIndex (повертає число).
  • Використовувати find там, де треба всі збіги — для цього є filter (урок 10).
