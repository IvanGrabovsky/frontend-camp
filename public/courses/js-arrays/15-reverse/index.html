reverse() та toReversed()

reverse() toReversed()

Що це таке?

reverse() розвертає масив на місці — перший стає останнім, останній — першим. Мутує оригінал. Сучасний toReversed() (ES2023) повертає новий розвернутий масив, не чіпаючи оригінал.

🃏 Аналогія з життя

Це як перегорнути стос карток догори дном. Верхня картка опиняється внизу, а нижня — зверху. У reverse ти перевертаєш сам стос; у toReversed — робиш копію перевернутого стосу, а оригінал лишається як був.

Синтаксис

array.reverse()              // мутує оригінал
array.toReversed()           // новий масив (ES2023)
const copy = [...array].reverse() // безпечна альтернатива
'привіт'.split('').reverse().join('') // перевернути рядок

Параметри методів

МетодОбовʼязковий?Опис

Як це працює

  1. reverse змінює порядок елементів у тому самому масиві.
  2. Повертає посилання на той самий (вже змінений) масив.
  3. toReversed або копія через spread — коли оригінал має залишитися незмінним.
  4. Для рядків: split('') → reverse() → join('').

Сімейство «change by copy» (ES2023)

Разом із toReversed у сучасному JS є «немутуючі» аналоги інших методів:

Приклади

// Приклад 1: reverse мутує масив
const arr = [1, 2, 3, 4, 5];
arr.reverse();
console.log(arr); // [5, 4, 3, 2, 1] — оригінал змінився!
// Приклад 2: безпечний варіант без мутації
const original = [1, 2, 3];
const reversed = [...original].reverse();
console.log(original); // [1, 2, 3] — не змінився
console.log(reversed); // [3, 2, 1]
// Приклад 3: перевернути рядок (перевірка паліндрому)
const word = 'радар';
const reversed = word.split('').reverse().join('');
console.log(word === reversed); // true — паліндром
⚠️ Типові помилки
  • Викликати reverse, коли потрібен оригінальний порядок — він зникне назавжди (якщо не збережена копія).
  • Думати, що reverse повертає новий масив — він повертає той самий, але змінений.
  • Перевернути рядок через reverse без split — у рядків немає методу reverse.
