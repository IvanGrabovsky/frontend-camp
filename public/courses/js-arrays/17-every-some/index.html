every() та some()

every() some()

Що це таке?

every(callback) повертає true, якщо всі елементи проходять тест. some(callback) — якщо хоча б один проходить. Обидва зупиняються раніше (коротке замикання), коли результат уже відомий.

Callback: (element, index, array) => boolean — every очікує true від кожного; some — хоча б одного true.

🎓 Аналогія з життя

every — «УСІ студенти склали іспит?». some — «ХОЧА Б ОДИН студент склав?». Перше вимагає 100% успіху, друге — достатньо одного позитивного результату.

Синтаксис

array.every((element, index, array) => умова)  // всі true?
array.some((element, index, array) => умова)   // хоча б один true?

Параметри callback

* element, index, array — аргументи callback, а не методу масиву. У callback element завжди передається; index і array — за потреби.

ПараметрОбовʼязковий?Опис
callbackобовʼязковий(element, index, array) => boolean — every: усі true; some: хоча б один true
index, arrayнеобовʼязковіІндекс і посилання на масив
thisArgнеобовʼязковийЗначення this всередині callback

Як це працює

  1. every перебирає елементи; якщо хоч один callback поверне false — одразу false.
  2. some перебирає елементи; якщо хоч один callback поверне true — одразу true.
  3. На порожньому масиві: every → true (вакuous truth), some → false.
  4. Ідеально для валідації форм і перевірки умов у колекціях.

Приклади

// Приклад 1: оцінки студентів
const grades = [75, 82, 91, 68, 88];
const allPassed = grades.every(g => g >= 60);   // true
const anyExcellent = grades.some(g => g >= 90); // true
console.log(allPassed, anyExcellent);
// Приклад 2: перевірка кошика
const cart = [{ inStock: true }, { inStock: false }];
console.log(cart.every(i => i.inStock));  // false
console.log(cart.some(i => !i.inStock));  // true
// Приклад 3: валідація паролів
const passwords = ['abc12345', 'short', 'securePass99'];
const allValid = passwords.every(p => p.length > 8);
console.log('Усі паролі довші за 8?', allValid); // false

Необовʼязкові параметри в дії

У callback необовʼязковий index — зручно, коли перший елемент особливий (пробний тест, заголовок таблиці тощо).

const scores = [50, 85, 90, 78]; // 50 — пробний тест, не рахуємо

// every з index — пропустити перший елемент
const allRealPassed = scores.every((score, index) =>
  index === 0 || score >= 60
);
console.log(allRealPassed); // true

// some — чи є хоч одна відмінна оцінка після першої?
const hasExcellent = scores.some((s, i) => i > 0 && s >= 90);
console.log(hasExcellent); // true
⚠️ Типові помилки
  • Плутати every і some — логіка протилежна.
  • На порожньому масиві every дає true — це може здивувати, але логічно («немає контрприкладу»).
  • Використовувати filter, коли достатньо булевої відповіді — every/some ефективніші.
