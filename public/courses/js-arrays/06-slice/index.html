slice() — копіювання частини масиву

slice()

Що це таке?

slice() повертає новий масив — копію частини оригіналу від індексу start до end (кінець не включається). Оригінал не змінюється.

🥪 Аналогія з життя

Уяви, що ти відрізаєш шматочок від батона. Ти береш собі скибку, а сам батон залишається цілим на столі. Так само slice дає тобі копію частини масиву, не чіпаючи оригінал.

Синтаксис

array.slice(start, end)  // end НЕ включається
array.slice(2)           // від індексу 2 до кінця
array.slice(-2)          // останні 2 елементи
array.slice()            // копія всього масиву

Параметри slice()

ПараметрОбовʼязковий?Опис
startнеобовʼязковийІндекс початку (за замовчуванням 0)
endнеобовʼязковийІндекс кінця, не включається (за замовчуванням — до кінця)

Офіційна документація (MDN)

  • Array.prototype.slice() — MDN

Як це працює

  1. start — індекс, з якого починається копія (включно).
  2. end — індекс, перед яким копія завершується (не включається).
  3. Відʼємні індекси відлічуються від кінця: -1 — останній елемент.
  4. Виклик без аргументів робить повну копію (поверхневу).

Приклади

// Приклад 1: перші три
const students = ['Аня', 'Борис', 'Вася', 'Галя', 'Діма'];
const firstThree = students.slice(0, 3);
console.log(firstThree); // ['Аня', 'Борис', 'Вася']
// Приклад 2: останні два (відʼємний індекс)
const students = ['Аня', 'Борис', 'Вася', 'Галя', 'Діма'];
const lastTwo = students.slice(-2);
console.log(lastTwo); // ['Галя', 'Діма']
// Приклад 3: копія не впливає на оригінал
const original = [1, 2, 3];
const copy = original.slice();
copy.push(99);
console.log(original); // [1, 2, 3] — не змінився
console.log(copy);     // [1, 2, 3, 99]

Необовʼязкові параметри в дії

start і end необовʼязкові: без них — копія всього масиву; без end — від start до кінця.

// slice() — без аргументів: повна копія
const data = [10, 20, 30, 40, 50];
console.log(data.slice());    // [10, 20, 30, 40, 50]

// slice(2) — без end: від індексу 2 до кінця
console.log(data.slice(2));   // [30, 40, 50]

// slice(-2) — без end: останні 2 елементи
console.log(data.slice(-2));  // [40, 50]
⚠️ Типові помилки
  • Очікувати, що end включається. slice(0, 3) дає елементи 0, 1, 2 — без 3-го.
  • Плутати зі splice: slice не змінює оригінал.
  • Пам’ятай: копія поверхнева. Вкладені масиви/обʼєкти залишаються спільними (детальніше в уроці 20).
