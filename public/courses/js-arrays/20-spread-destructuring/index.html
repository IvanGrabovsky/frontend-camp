Spread оператор та деструктуризація масивів

... [a, b] ...rest with()

Що це таке?

Spread (...) «розпаковує» масив — для копіювання, обʼєднання або передачі елементів у функцію. Деструктуризація робить навпаки: «розкладає» масив у окремі змінні за одним рядком.

🧺 Аналогія з життя

Spread — висипати вміст кошика на стіл. Деструктуризація — взяти перший предмет в одну руку, другий — в іншу, а решту покласти в окремий пакет (...rest).

Синтаксис

const copy = [...original]           // копія
const merged = [...arr1, ...arr2]    // обʼєднання
const [first, second, ...rest] = arr // деструктуризація
const [a, , c] = arr                 // пропуск елемента
[x, y] = [y, x]                      // swap без temp
array.with(index, value)             // новий масив, один елемент змінено (ES2023)

Як це працює

  1. [...arr] створює поверхневу копію — вкладені масиви/обʼєкти залишаються спільними.
  2. Деструктуризація присвоює елементи зліва направо змінним.
  3. ...rest збирає «залишок» масиву в новий масив (rest має бути останнім).
  4. Можна задавати значення за замовчуванням: const [a = 0] = [].
  5. with(index, value) — замість arr[i] = x на копії: повертає новий масив з одним зміненим елементом (ES2023).

with() — оновлення без мутації

Коли потрібно замінити один елемент, не чіпаючи оригінал:

const scores = [10, 20, 30];
const updated = scores.with(1, 99);
console.log(scores);  // [10, 20, 30] — без змін
console.log(updated); // [10, 99, 30]
console.log(scores.with(-1, 100)); // [10, 20, 100] — підтримує відʼємні індекси

Приклади

// Приклад 1: spread — копія та обʼєднання
const original = [1, 2, 3];
const copy = [...original];
const merged = [...original, 99, ...[4, 5]];
console.log(copy, merged);
// Приклад 2: деструктуризація з rest
const [first, second, ...rest] = [10, 20, 30, 40, 50];
console.log(first);  // 10
console.log(second); // 20
console.log(rest);   // [30, 40, 50]
// Приклад 3: swap та результат функції
let x = 1, y = 2;
[x, y] = [y, x];
console.log(x, y); // 2 1

function getMinMax(nums) {
  return [Math.min(...nums), Math.max(...nums)];
}
const [min, max] = getMinMax([5, 2, 9, 1]);
console.log(min, max); // 1 9

Необовʼязкові параметри в дії

У деструктуризації необовʼязкові змінні та = defaultValue — якщо елемента немає або він undefined, підставляється значення за замовчуванням.

const [first = 'Гість', second = 'Анонім'] = ['Аня'];
console.log(first, second); // 'Аня', 'Анонім'

const [head, ...rest] = [1, 2, 3, 4];
console.log(head, rest); // 1, [2, 3, 4]

// defaults для обʼєкта з масиву
const users = [{ name: 'Борис' }];
const [{ name = 'Невідомий', role = 'студент' }] = users;
console.log(name, role); // 'Борис', 'студент'
⚠️ Типові помилки
  • Spread робить лише поверхневу копію. Для вкладених масивів потрібен structuredClone або JSON.parse(JSON.stringify(...)).
  • ...rest має бути останнім у деструктуризації — інакше синтаксична помилка.
  • Плутати spread у масивах [...a] і в обʼєктах {...o} — це різні контексти.

Завдання 1 — shallow copy

        
❌ Пишуть «скопіював», але змінюють лише верхній рівень — не чіпають вкладений масив для демонстрації.

        
✅ Після const copy = [...original] зміни copy[1][0] — побачиш зміну і в original[1].

      

      

        
Завдання 2 — getMinMax + деструктуризація

        
❌ Функція повертає обʼєкт, а розпаковують як масив, або min/max переплутані місцями.

        
✅ return [Math.min(...arr), Math.max(...arr)]; потім const [min, max] = getMinMax(arr);

      

      

        
Завдання 3 — rest у деструктуризації

        
❌ Без rest: const [title, ...items] = arr пишуть окремі змінні для кожного пункту.

        
✅ const [title, ...items] = ['Заголовок', 'пункт 1', 'пункт 2']; — items = два рядки.
