reduce() — найпотужніший метод

reduce() reduceRight()

Що це таке?

reduce() «згортає» весь масив в одне значення: число, рядок, обʼєкт чи навіть новий масив. Це найгнучкіший метод — через нього можна виразити майже всі інші.

Callback: (acc, cur, index, array) => newAcc — на кожному кроці повертає оновлений акумулятор; останнє повернене значення — результат усього reduce.

❄️ Аналогія з життя

Снігова куля, що котиться з гори. Вона збирає весь сніг, який зустрічає, і стає дедалі більшою. Акумулятор — це сама куля, а кожен елемент масиву — новий сніг, що до неї налипає.

Синтаксис

array.reduce((acc, cur, idx, arr) => новийAcc, initialValue)
// acc          — накопичене значення (куля)
// cur          — поточний елемент (новий сніг)
// initialValue — початкове значення акумулятора

Параметри reduce()

* acc, cur, index, array — аргументи callback, а не методу масиву. У callback acc і cur завжди передаються; index і array — за потреби.

ПараметрОбовʼязковий?Опис
callbackобовʼязковий(acc, cur, index, array) => newAcc — повертає оновлений акумулятор
index, arrayнеобовʼязковіІндекс і посилання на масив — аргументи callback
initialValueрекомендованийСинтаксично необовʼязковий, але без нього на порожньому масиві буде помилка — завжди вказуй

Як це працює

  1. Акумулятор починається зі значення initialValue.
  2. Для кожного елемента callback повертає нове значення акумулятора.
  3. Це значення передається в наступну ітерацію.
  4. Останнє значення акумулятора — результат усього reduce.

Важливість initialValue

Завжди задавай initialValue. Без нього перший елемент стає початковим акумулятором, а виклик на порожньому масиві кине помилку. Є ще reduceRight — те саме, але справа наліво.

Приклади

// Приклад 1: сума чисел
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce((acc, n) => acc + n, 0);
console.log(sum); // 15
// Приклад 2: підрахунок частоти слів
const words = ['кіт', 'пес', 'кіт', 'кіт', 'пес'];
const freq = words.reduce((acc, w) => {
  acc[w] = (acc[w] || 0) + 1;
  return acc;
}, {});
console.log(freq); // { кіт: 3, пес: 2 }
// Приклад 3: групування за віком
const users = [{ age: 20 }, { age: 15 }, { age: 30 }];
const byAge = users.reduce((acc, u) => {
  const key = u.age >= 18 ? 'adults' : 'minors';
  acc[key].push(u);
  return acc;
}, { adults: [], minors: [] });
console.log(byAge.adults.length); // 2

Необовʼязкові параметри в дії

initialValue синтаксично необовʼязковий, але без нього перший елемент стає початковим акумулятором, а на порожньому масиві буде помилка.

// Без initialValue — перший елемент = acc
console.log([1, 2, 3, 4].reduce((acc, n) => acc + n)); // 10

// З initialValue — безпечніше і зрозуміліше
console.log([1, 2, 3, 4].reduce((acc, n) => acc + n, 0)); // 10
console.log([].reduce((acc, n) => acc + n, 0));           // 0 — порожній OK

// index у callback — наприклад, сума з вагою позиції
const weighted = [10, 20, 30].reduce((sum, n, index) => sum + n * (index + 1), 0);
console.log(weighted); // 10*1 + 20*2 + 30*3 = 140
⚠️ Типові помилки
  • Забути повернути акумулятор з callback → acc стане undefined.
  • Не задати initialValue → несподівана поведінка або помилка на порожньому масиві.
  • Мутувати initialValue-обʼєкт ззовні, використовуючи його повторно між викликами.
