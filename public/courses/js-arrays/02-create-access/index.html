Створення масивів та доступ до елементів

arr[i] arr[i] = x at() matrix[i][j]

Що це таке?

Створити масив — це лише половина справи. Найчастіше нам потрібно звертатися до окремих елементів, змінювати їх, а іноді працювати з масивами масивів (матрицями).

Доступ відбувається за індексом у квадратних дужках: array[0]. Той самий синтаксис використовується і для читання, і для запису.

🏢 Аналогія з життя

Уяви багатоповерховий будинок. Квартира [0] — на першому доступному поверсі, квартира [1] — вище, і так далі. Щоб потрапити в конкретну квартиру, ти називаєш її номер. У масиві «номер квартири» — це індекс.

Синтаксис

array[0]                   // перший елемент
array[array.length - 1]    // останній елемент
array[array.length - 2]    // передостанній елемент
array.at(-1)               // останній (ES2022)
array.at(-2)               // передостанній
array[1] = 'нове значення'  // зміна елемента
matrix[0][1]               // елемент вкладеного масиву

Параметри доступу

ПараметрОбовʼязковий?Опис
indexобовʼязковийЧисловий індекс елемента: array[0], matrix[1][2]
value (при записі)обовʼязковийНове значення: array[1] = 'нове'

Як це працює

  1. Пишеш назву масиву й у квадратних дужках вказуєш індекс.
  2. Щоб отримати останній елемент, не знаючи довжини — використовуй array[array.length - 1].
  3. Присвоєння array[i] = ... замінює елемент на місці.
  4. У матриці matrix[i][j]: перший індекс — рядок, другий — стовпець.

Приклади

// Приклад 1: доступ до елементів
const group = ['Аня', 'Борис', 'Вася', 'Галя'];
console.log(group[0]);                 // 'Аня'
console.log(group[group.length - 1]);  // 'Галя' — останній
// Приклад 2: зміна елемента на місці
const group = ['Аня', 'Борис', 'Вася'];
group[1] = 'Богдан';       // замінили другий елемент
console.log(group);        // ['Аня', 'Богдан', 'Вася']
// Приклад 3: матриця 3×3
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
];
console.log(matrix[1][2]); // 6 — 2-й рядок, 3-й стовпець
⚠️ Типові помилки
  • Плутанина індексу й порядкового номера: group[2] — це третій елемент.
  • Спроба звернутися до matrix[0][5], коли у рядку лише 3 елементи → undefined.
  • Забути - 1 у length: array[array.length] завжди undefined.

  • at(-1) і at(-2) — сучасна альтернатива length - 1 / length - 2 (ES2022).
