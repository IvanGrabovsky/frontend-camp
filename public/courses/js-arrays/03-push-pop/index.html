push() та pop() — робота з кінцем масиву

push() pop()

Що це таке?

push() додає один або кілька елементів у кінець масиву й повертає нову довжину. pop() видаляє останній елемент і повертає його значення.

Обидва методи змінюють оригінальний масив (кажуть — вони «мутують» масив).

🍽️ Аналогія з життя

Уяви стос тарілок. push — ти кладеш чисту тарілку зверху. pop — береш верхню тарілку, щоб покласти на неї їжу. Ти завжди працюєш лише з верхом стосу, тобто з кінцем масиву.

Синтаксис

array.push(item)               // додати в кінець → нова довжина
array.push(item1, item2)       // можна кілька одразу
const last = array.pop()       // видалити останній → його значення

Параметри методів

Метод / параметрОбовʼязковий?Опис
push(...items)обовʼязковийХоча б один елемент для додавання в кінець (виклик без аргументів нічого не додасть)
pop()—Без параметрів — видаляє останній елемент

Офіційна документація (MDN)

  • Array.prototype.push() — MDN
  • Array.prototype.pop() — MDN

Як це працює

  1. push ставить новий елемент після поточного останнього.
  2. Повертає нову довжину масиву (число), а не сам масив.
  3. pop прибирає останній елемент і повертає його, зменшуючи довжину на 1.
  4. Якщо масив порожній, pop повертає undefined.

Приклади

// Приклад 1: кошик покупок
const cart = ['молоко', 'хліб'];
cart.push('яйця');            // додали товар
const removed = cart.pop();   // прибрали останній
console.log(cart);            // ['молоко', 'хліб']
console.log(removed);         // 'яйця'
// Приклад 2: push повертає нову довжину
const nums = [1, 2, 3];
const newLength = nums.push(4, 5);  // додали два одразу
console.log(newLength);             // 5
console.log(nums);                  // [1, 2, 3, 4, 5]
// Приклад 3: стос як стек «Undo»
const actions = [];
actions.push('надрукував текст');
actions.push('вставив картинку');
const undo = actions.pop();  // скасували останню дію
console.log('Скасовано:', undo);
⚠️ Типові помилки
  • Думати, що push повертає масив. Насправді він повертає число (нову довжину).
  • Забути, що методи мутують оригінал. Якщо потрібна копія — спершу скопіюй масив (розглянемо slice в уроці 06).
  • Викликати pop на порожньому масиві та очікувати помилку — буде undefined.

  1. Почни з stack = [], додай числа 10, 20, 30 через push — виведи масив. 💎 10
  2. З stack = [10, 20, 30, 40] зніми останній елемент через pop і виведи те, що повернув метод. 💎 10
  3. До stack = [1, 2] додай 3 і 4 одним викликом push(3, 4). 💎 10
  4. З stack = ['a', 'b', 'c'] викликай pop у циклі, поки масив не стане порожнім — виводь кожен результат. 💎 10

Завдання 2 — «Назад» через pop

        
❌ Використовують shift (знімає з початку) або не зберігають результат pop().

        
✅ const last = history.pop(); console.log('Зняли:', last, history); — pop змінює масив і повертає видалений елемент.

      

      

        
Завдання 3 — push трьох елементів

        
❌ Три окремі push замість одного виклику або очікують, що push поверне новий масив.

        
✅ history.push('a', 'b', 'c'); — повертає нову length, масив змінюється на місці.
