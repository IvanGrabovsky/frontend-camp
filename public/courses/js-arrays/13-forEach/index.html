forEach() — перебір елементів

forEach()

Що це таке?

forEach() виконує вказану дію для кожного елемента масиву. Він нічого не повертає (undefined) і призначений для побічних ефектів: вивести в консоль, оновити DOM, накопичити щось у зовнішній змінній.

Callback: (element, index, array) => void — виконує дію для поточного елемента; повернене значення ігнорується.

✅ Аналогія з життя

Це як пройтися по списку справ і виконати кожну по черзі. Ти не створюєш новий список — просто робиш дію для кожного пункту й ставиш галочку.

Синтаксис

array.forEach((element, index, array) => {
  // дія для кожного елемента
});

Параметри forEach()

* element, index, array — аргументи callback, а не методу масиву. У callback element завжди передається; index і array — за потреби.

Офіційна документація (MDN)

  • Array.prototype.forEach() — MDN

Як це працює

  1. Метод по черзі викликає callback для кожного елемента.
  2. Повертає undefined — тому його не можна присвоїти для отримання результату.
  3. Його не можна зупинити через break. Щоб вийти раніше — використай some/every (урок 17) або for...of з break.
  4. Ідеальний, коли потрібна дія, а не новий масив.

forEach чи map?

Якщо потрібен новий масив — бери map. Якщо потрібна лише дія (без результату) — бери forEach.

Приклади

// Приклад 1: пронумерований список задач
const tasks = ['Зробити ДЗ', 'Почитати книгу', 'Тренування'];
tasks.forEach((task, i) => {
  console.log(`${i + 1}. ${task}`);
});
// Приклад 2: накопичення суми в зовнішній змінній
const prices = [100, 250, 50];
let total = 0;
prices.forEach(p => { total += p; });
console.log('Разом:', total); // 400
// Приклад 3: побічний ефект — оновлення DOM
const tasks = ['A', 'B'];
tasks.forEach(task => {
  const li = document.createElement('li');
  li.textContent = task;
  list.appendChild(li); // list — елемент <ul> на сторінці
});

Необовʼязкові параметри в дії

У callback необовʼязкові index і array. index — для нумерації; array — коли в циклі потрібен доступ до всього масиву (рідше).

const menu = ['Головна', 'Курси', 'Контакти'];
menu.forEach((item, index) => {
  console.log(`${index + 1}) ${item}`);
});

// array — порівняти з сусідом (останній без наступного)
const temps = [18, 22, 19, 25];
temps.forEach((t, i, arr) => {
  const next = arr[i + 1];
  if (next !== undefined && next > t) console.log(`↑ з ${t} до ${next}`);
});
⚠️ Типові помилки
  • Намагатися отримати результат: const r = arr.forEach(...) завжди дає undefined.
  • Пробувати break/continue усередині — вони не працюють у forEach.
  • Використовувати forEach для трансформації замість map.
⚡ Практика на занятті

Виконай у пісочниці нижче або в окремій пісочниці. Дані для кожного завдання — у формулюванні. За кожне своєчасно виконане завдання — кристали.

  1. Завдання ['Зробити ДЗ', 'Почитати книгу', 'Тренування'] — виведи нумерований список через forEach (1. …). 💎 10
  2. Числа [5, 10, 15, 20] — порахуй суму через forEach (змінна ззовні callback). 💎 10
  3. Перевір: const r = [1, 2, 3].forEach(x => x) — виведи r і поясни в коментарі. 💎 10
  4. Для ['a', 'b', 'c'] порівняй: коли потрібен forEach, а коли map — один рядок висновку в консоль. 💎 10
