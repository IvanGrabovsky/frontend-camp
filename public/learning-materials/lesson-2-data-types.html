Розділ 1. Унарні та бінарні оператори ⏱️ ~25 хв
💡 Основи операторів та операндів

Знаки дій (+, -, =) називаються операторами, а значення, над якими вони працюють — операндами.

Усі оператори у програмуванні поділяються за кількістю учасників: унарні працюють з одним операндом, бінарні — з двома.

📚 Академічна теорія: Класифікація за кількістю операндів
  • 1. Унарні оператори (1 операнд):
    • Унарний плюс (+x) — швидкий та лаконічний спосіб перетворити рядок у число: +"10" дає число 10!
    • Унарний мінус (-x) — змінює знак числа на протилежний: -(-5) дає 5.
    • Логічне заперечення (!x) — перевертає булеве значення: !true стає false.
    • Інкремент / декремент (++, --) — збільшують чи зменшують змінну на 1.
  • 2. Бінарні оператори (2 операнди): Знаходяться МІЖ двома значеннями: додавання a + b, множення a * b, ділення a / b.
  • 3. Оператор присвоювання (=): Бере значення СПРАВА і записує його в коробку ЗЛІВА: let score = 100;. (Не плутати з суворою рівністю ===!).
Розділ 2. Особливості примітивів: undefined, null, NaN та баг 1995 року ⏱️ ~20 хв
⚡ Експерименти з примітивами 
let a;
console.log(a);        // undefined (коробку створили, але значення не надали)
console.log(typeof a); // "undefined"

let user = null;
console.log(user);     // null (свідомо зафіксовано: "порожньо")
console.log(typeof user); // "object" (відомий баг 1995 року в рушії JS!)

let calc = "Привіт" * 3;
console.log(calc);        // NaN (Not-a-Number — не число)
console.log(typeof calc); // "number" (Парадокс: тип у NaN — це number!)
console.log(NaN === NaN); // false! (NaN не дорівнює навіть самому собі!)
console.log(Number.isNaN(calc)); // true (надійний спосіб перевірки)

Розділ 4. Головні висновки уроку ⏱️ ~10 хв
💡 Підсумковий конспект

1) Оператори бувають унарні (для 1 операнда) та бінарні (для 2).
2) Унарний плюс +"10" — улюблений прийом розробників для приведення типів.
3) null — це усвідомлена порожнеча, а undefined — коли про значення забули.
4) NaN — спеціальне значення з типом number, яке не дорівнює навіть самому собі.
