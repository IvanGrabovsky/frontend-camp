Розділ 1. Оператори розгалужень та Тернарний оператор (? :) ⏱️ ~20 хв
💡 Ухвалення рішень у коді

Досі наші програми йшли строго лінійно: оголосили, порахували, вивели. Але реальні додатки вміють аналізувати дані та обирати шлях виконання за допомогою операторів розгалужень.

А ще в JavaScript є єдиний у всій мові тернарний оператор. Йому потрібно три операнди: УМОВА ➔ ? ЗНАЧЕННЯ_ЯКЩО_ТАК ➔ : ЗНАЧЕННЯ_ЯКЩО_НІ.

📚 Академічна теорія: if/else проти Тернарного оператора

1. Класичний оператор розгалуження (if / else):

let age = 17;
let access;

if (age >= 18) {
  access = "Доступ дозволено";
} else {
  access = "Доступ обмежено";
}

2. Тернарний оператор (умова ? вираз1 : вираз2):

let access = (age >= 18) ? "Доступ дозволено" : "Доступ обмежено";
console.log(access); // "Доступ обмежено"
Розділ 2. Проєкт «Профіль користувача» та Блок-схема ⏱️ ~25 хв
🛠️ Практика за ПК: Файл userProfile.js 
const name = "Alex";
const age = 17;
const city = "Kyiv";
const isStudent = true;
const favoriteNumber = 7;

// Використання тернарного оператора для статусу:
const statusText = isStudent ? "Студент денної форми" : "Не студент";

console.log("Name: " + name + "\nAge: " + age + "\nCity: " + city + "\nStatus: " + statusText);

// Перевірка кожного поля через typeof:
console.log(typeof name);     // "string"
console.log(typeof age);      // "number"
console.log(typeof isStudent);// "boolean"
📐 Побудова алгоритму мовою блок-схем
  • Овал: Початок
  • Паралелограм (Ввід): Отримати дані name, age, isStudent
  • Ромб (Умова розгалуження): age >= 18?
  • Стрілка ТАК ➔ Прямокутник: access = "Повний доступ"
  • Стрілка НІ ➔ Прямокутник: access = "Батьківський контроль"
  • Паралелограм (Вивід): Надрукувати картку профілю
  • Овал: Кінець
Розділ 3. Лабораторний баг-фіксинг: Помилки джуніора ⏱️ ~15 хв
⚠️ Зламаний код: знайдіть синтаксичні та логічні помилки! 
Const user-score = "100";
let bonus = 50;
user-score = user-score + bonus;
console.log("Рахунок: " + user-score);

💡 Відповіді та пояснення приховані за замовчуванням. Натисніть на будь-який рядок або наведіть курсор, щоб перевірити себе.

Помилка Тип помилки Виправлення
Const з великої літери Синтаксична (SyntaxError) Писати з малої let userScore (бо значення змінюється).
user-score з дефісом Синтаксична (SyntaxError) Дефіс сприймається як мінус. Стиль camelCase: userScore.
"100" у лапках Логічна (Logical Error) Склеїться в "10050" замість 150. Прибрати лапки: 100.
Перезапис const Помилка виконання (TypeError) Оголосити як let, оскільки значення змінюється.
