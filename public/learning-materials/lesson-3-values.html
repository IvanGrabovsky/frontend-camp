Розділ 1. Поведінка значень: Рядки проти Чисел ⏱️ ~20 хв
💡 Конкатенація проти додавання

Знак + у мові JS виконує дві різні операції залежно від типів: для чисел він рахує математичну суму, а якщо хоч один операнд рядок — він склеює їх докупи (конкатенація)!

console.log(5 + 5);     // 10 (число)
console.log("5" + "5"); // "55" (рядок)
console.log("5" + 5);   // "55" (рядок: число 5 автоматично стало рядком!)
Розділ 2. Скорочені форми операторів (Compound Assignment) ⏱️ ~20 хв
📚 Академічна теорія: Комбіноване присвоювання та інкремент

У реальних проєктах розробники уникають довгих записів score = score + 10;. Для цього існують скорочені форми:

  • x += 5; ➔ те саме, що x = x + 5; (додати 5 до поточного значення).
  • x -= 3; ➔ те саме, що x = x - 3; (зменшити на 3).
  • x *= 2; ➔ те саме, що x = x * 2; (подвоїти значення).
  • x /= 4; ➔ те саме, що x = x / 4; (поділити на 4).
  • x %= 2; ➔ знайти залишок від ділення і зберегти.

Інкремент (++) та Декремент (--):

  • score++; ➔ збільшити на 1 (постфіксний інкремент).
  • score--; ➔ зменшити на 1 (постфіксний декремент).
  • Різниця префіксної та постфіксної форми: ++x спочатку збільшує значення і одразу повертає нове, а x++ спочатку повертає старе значення, а збільшує вже після виконання поточної дії!
🛠️ Міні-практика: «Оновлення балансу гравця» 
let playerHp = 100;
playerHp -= 20; // Отримав удар, HP стало 80
playerHp++;     // Випив зілля регенерації, HP стало 81
playerHp *= 2;  // Отримав бафф сили, стало 162
console.log("Поточне HP: " + playerHp); // 162

Розділ 4. Практика: Чек у кафе та Бліц-самоперевірка ⏱️ ~20 хв
🛠️ Практичний міні-проєкт: «Розрахунок чеку зі знижкою» 
const pizzaPrice = 180;
let pizzaCount = 2;
const colaPrice = 40;
let colaCount = 3;

let total = (pizzaPrice * pizzaCount) + (colaPrice * colaCount); // 360 + 120 = 480
total -= 50; // Застосували купон на знижку 50 грн (скорочена форма!)
console.log("До сплати зі знижкою: " + total + " грн"); // 430 грн
