💡 Інтуїція та аналогія (Пам'ять та коробки)

Змінна — це іменована коробка в оперативній пам'яті комп'ютера, на яку наклеєно стікер з назвою (ідентифікатор), а всередині зберігаються дані.

У сучасному JavaScript є два ключові слова: let (коробка, вміст якої можна змінювати) та const (запечатана коробка-константа, значення якої заборонено змінювати після створення). Застарілий var більше не використовується через проблеми з областями видимості та hoisting.

📚 Академічна теорія: Типи даних за стандартом ECMAScript
  • 1. Цілі числа (Integers): Числа без дробової частини: 10, 0, -42.
  • 2. Речовинні числа (Floating point): Числа з плаваючою крапкою: 3.14, 0.5.
    Нюанс JS: На відміну від мов C++ чи Java, де є окремі типи int та double, у JavaScript усі числа належать до єдиного типу number (64-бітний стандарт IEEE-754).
  • 3. Розмір та діапазон значень: Безпечний діапазон цілих чисел у JS лежить у межах від $-(2^{53} - 1)$ до $+(2^{53} - 1)$ (від -9007199254740991 до 9007199254740991). У JS є константа Number.MAX_SAFE_INTEGER.
  • 4. Символьний vs Строковий тип: В інших мовах один символ — це тип char. У JS окремого символьного типу немає! Будь-який окремий символ (наприклад, "A" або "%") — це просто рядок (string) довжиною 1.
  • 5. Логічний тип (boolean): Тільки два значення: true (істина) та false (хибність).
📚 Правила іменування змінних (Code Style)
  • Заборонено: починати з цифри (let 1user; ❌), використовувати дефіси (user-name ❌ — це знак мінуса!), використовувати зарезервовані слова (let class; ❌).
  • Обов'язковий стандарт: стиль camelCase (наприклад: userAge, isHeroAlive, totalScorePoints).

Тип помилки Коли виникає? Приклад у коді
1. Синтаксична (SyntaxError) Порушено правила граматики мови. Код взагалі не стартує! let 1player = "Ivan"; або незакрита лапка "Hello.
2. Помилка виконання (TypeError / ReferenceError) Код синтаксично коректний, але під час роботи виникає неприпустима дія. const city = "Lviv"; city = "Kyiv"; ➔ TypeError: Assignment to constant variable.
3. Логічна помилка (Logical Error) Найпідступніша! Код працює без збоїв у консолі, але результат обчислень хибний. Хотіли додати 50 + 100, але написали "50" + 100 ➔ вийшло "50100" замість 150.
Розділ 3. Практикум: Паспорт розробника та Блок-схема ⏱️ ~20 хв
🛠️ Завдання 1: «Паспорт розробника»

Оголосіть змінні про себе та виведіть їх разом із типами:

const firstName = "Ivan";     // string (текст)
const symbolTest = "A";       // string (у JS окремого char немає!)
let age = 17;                 // number (ціле число)
let height = 1.78;            // number (речовинне / дробове число)
let isStudent = true;         // boolean (логічний)

console.log("Ім'я: " + firstName + " | тип: " + typeof firstName);
console.log("Вік: " + age + " | тип: " + typeof age);
console.log("Зріст: " + height + " | тип: " + typeof height);
console.log("Студент: " + isStudent + " | тип: " + typeof isStudent);
📐 Блок-схема програми зі змінними

Як змінні та перевірки відображаються у блок-схемах алгоритмів:

  • Овал: Початок
  • Паралелограм (Введення): Отримати name, age, height
  • Прямокутник (Обчислення): Зберегти isAdult = age >= 18
  • Паралелограм (Виведення): Надрукувати паспорт на екран
  • Овал: Кінець

1 Чи є в JS окремий тип для чисел з комою (float)? Ні, єдиний тип number І цілі, і дробові числа — це 64-бітний float IEEE-754.
2 Який тип має символ "$" у JS? "string" У JS немає типу char, окремий символ — це рядок довжиною 1.
3 let user-name = "Max"; — яка це помилка? Синтаксична (SyntaxError) Дефіс заборонений, він трактується як знак мінуса.
4 const a = 10; a = 20; — яка це помилка? Помилка виконання (TypeError) Заборонено перезаписувати константу під час роботи.
5 Хотіли порахувати площу $S = a \cdot b$, але написали $S = a + b$. Що це? Логічна помилка (Logical Error) Код працює без виключень, але бізнес-результат хибний.
6 Що поверне typeof (10 > 5)? "boolean" Вираз у дужках дорівнює true.
7 Як за стандартом назвати змінну для максимальної кількості спроб? maxAttemptsCount Стиль camelCase, зрозуміла самодокументована назва.
8 Що поверне typeof Number.MAX_SAFE_INTEGER? "number" Це найбільше безпечне ціле число: $9007199254740991$.
9 Що виведе let x; console.log(typeof x);? "undefined" Змінну створили, але значення не присвоїли.
10 Яка різниця між "false" та false? Перше — рядок, друге — boolean Лапки завжди створюють рядок (string).
